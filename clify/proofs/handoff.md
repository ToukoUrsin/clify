## Final answer

The top result is **hyper**. Its latest version is **1.12.0** and it has **1,018,998,457** total downloads, a little over 1.01 billion.

I got this from `clify crates search-crates --q "http client" --sort downloads`. The latest release, the default version and the highest stable version are all 1.12.0, and the crate was last updated on 2026-10-06.

The search matches text, not just dedicated HTTP clients. hyper is a lower-level library that handles both client and server. Second place is **rustls**, a TLS library, with 1,013,494,260 downloads, and third is **h2**, an HTTP/2 implementation, with 892,248,050. If you meant the most popular crate built mainly to be an HTTP client, that's probably `reqwest`, and I can look up its numbers too.
