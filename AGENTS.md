# clify

JSON command-line tool and hosted MCP that calls websites' own HTTP endpoints.

- Hosted MCP: `https://bold-cloud-h4u6s.run.mcp-use.com/mcp` (`clify_sites`, `clify_help`, `clify_run`).
- `clify/` is the CLI (its AGENTS.md is the user guide that ships with it): `cd clify && npm install && npm test` (offline); `clify/test/real/` and `clify/test/sites/` are live suites. `mcp/` is the hosted server.
