# clify

JSON command-line tool and hosted MCP that calls websites' own HTTP endpoints.

- Hosted MCP: `https://bold-cloud-h4u6s.run.mcp-use.com/mcp` (`clify_sites`, `clify_help`, `clify_run`).
- `mcp/` is the hosted server; `test/real/` and `test/sites/` are live suites. `npm install`, `npm test` (offline).
