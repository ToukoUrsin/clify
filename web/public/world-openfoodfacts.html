world-openfoodfacts API for agents (unofficial) — JSON over curl

Open Food Facts (world.openfoodfacts.org) is an open, crowd-sourced food products database. This CLI reads product detail pages and their related data (Robotoff questions, folksonomy tags), the reference lists (countries, food-preference attribute groups, preference levels, external knowledge sources) and the bulk data-dump links.

Host: world.openfoodfacts.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

get-product

Get a food product's name, common name and Nutri-Score breakdown by barcode (EAN/UPC), parsed from its product page Params: barcode* Read-only

curl 'https://clify-dev.netlify.app/world-openfoodfacts/get-product?barcode=3046920029759'

get-product-questions

List the Robotoff machine-generated questions (for example a suggested category or label to confirm) that are pending for a product barcode Params: barcode*, lang Read-only

curl 'https://clify-dev.netlify.app/world-openfoodfacts/get-product-questions?barcode=3046920029759&lang=en'

list-countries

List the countries Open Food Facts supports, as a map from country code (e.g. us, fr) to English country name Params: none Read-only

curl 'https://clify-dev.netlify.app/world-openfoodfacts/list-countries'

list-attribute-groups

List the product attribute groups used for personalized ranking (nutritional quality, processing, allergens, environment, …) with their attributes and allowed values Params: none Read-only

curl 'https://clify-dev.netlify.app/world-openfoodfacts/list-attribute-groups'

list-preference-levels

List the importance levels a user can assign to a product attribute (not important, important, very important, mandatory) with their scoring factors Params: none Read-only

curl 'https://clify-dev.netlify.app/world-openfoodfacts/list-preference-levels'

list-external-sources

List the external knowledge-panel providers (for example the animal-welfare Suffering Footprint) and the product filters each one applies to Params: lc Read-only

curl 'https://clify-dev.netlify.app/world-openfoodfacts/list-external-sources?lc=en'

list-data-exports

List the nightly database dump and export downloads (MongoDB dump, CSV, JSONL, …) with their download and checksum links Params: none Read-only

curl 'https://clify-dev.netlify.app/world-openfoodfacts/list-data-exports'
