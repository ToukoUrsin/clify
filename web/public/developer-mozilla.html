developer-mozilla API for agents (unofficial) — JSON over curl | clify

MDN Web Docs (developer.mozilla.org) is Mozilla's web developer documentation. This CLI searches the docs, fetches any doc page as structured JSON, lists every doc title/URL for a locale, and looks up browser compatibility data.

Host: developer.mozilla.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-docs

Full-text search of MDN documentation, 10 results per page, optionally limited to one locale Params: q*, page, locale

curl 'https://clify-dev.netlify.app/developer-mozilla/search-docs?q=fetch&page=1&locale=en-US'

get-doc

Get one MDN doc page as structured JSON: title, summary, body sections (HTML), TOC, parents, translations, and BCD keys Params: locale, path*

curl 'https://clify-dev.netlify.app/developer-mozilla/get-doc'

list-docs

List every doc in a locale as {title, url}, ordered by popularity (MDN's quick-search index) Params: locale

curl 'https://clify-dev.netlify.app/developer-mozilla/list-docs'

get-browser-compat

Get browser compatibility data (support per browser/version, status, spec URL) for a BCD feature key such as api.fetch or html.elements.details Params: feature*

curl 'https://clify-dev.netlify.app/developer-mozilla/get-browser-compat'
