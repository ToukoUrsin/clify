bundlephobia API for agents (unofficial) — JSON over curl

Bundlephobia shows the bundle-size cost of npm packages. This CLI searches packages and looks up minified/gzipped size, dependency composition, version history, similar packages, exports, recent searches and download/star trends. It can also fetch a GitHub repo's package.json to scan its dependencies.

Host: bundlephobia.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-packages

Autocomplete/search npm package names (npms.io suggestions used by the Bundlephobia search box) Params: q* Read-only

curl 'https://clify-dev.netlify.app/bundlephobia/search-packages?q=react'

get-package-size

Get minified and gzipped bundle size, dependency count and module flags for an npm package (optionally a specific version) Params: package* Read-only

curl 'https://clify-dev.netlify.app/bundlephobia/get-package-size?package=react'

get-package-history

List a package's recent versions with their bundle sizes and publish dates, plus major/minor release markers Params: package*, api_limit Read-only

curl 'https://clify-dev.netlify.app/bundlephobia/get-package-history?package=%40grida%2Ftransparency-grid'

get-similar-packages

Find alternative or similar packages in the same category as a given package Params: package* Read-only

curl 'https://clify-dev.netlify.app/bundlephobia/get-similar-packages?package=react'

list-recent-searches

List packages recently searched on Bundlephobia by all users, keyed by package name Params: api_limit Read-only

curl 'https://clify-dev.netlify.app/bundlephobia/list-recent-searches?api_limit=5'

compare-trends

Compare download, star and size trends over time for several packages (the data behind the /trends page) Params: packages*, range Read-only

curl 'https://clify-dev.netlify.app/bundlephobia/compare-trends?packages=react%2Cpreact&range=last-year'

get-github-package-json

Fetch the package.json of a GitHub repo (default branch) to list its dependencies for scanning with get-package-size Params: owner*, repo* Read-only

curl 'https://clify-dev.netlify.app/bundlephobia/get-github-package-json'
