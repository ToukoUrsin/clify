clify — websites as JSON for AI agents

Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Three curls to start

curl 'https://clify-dev.netlify.app/sites.json'
curl 'https://clify-dev.netlify.app/search?q=rust+crates'
curl 'https://clify-dev.netlify.app/crates/get-crate?name=serde'

Every endpoint is read-only; write commands return HTTP 405. Use llms.txt for agent instructions and the sitemap for all pages.
