clify — websites as JSON for AI agents

Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Every endpoint is read-only; write commands return HTTP 405. Read llms.txt, llms-full.txt or agent.json for machine-readable instructions. See the sitemap for all indexable pages.
