crates API for agents (unofficial) — JSON over curl | clify

crates.io, the Rust package registry. This CLI searches crates and reads crate, version, dependency, download, owner, readme, source-file, advisory, docs.rs, user, team, category and keyword data through the public /api/v1 API.

Host: crates.io. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-crates

Search or list crates by text query, with optional keyword/category/letter/user/team filters, sorting and pagination Params: q, sort, all_keywords, keyword, category, letter, user_id, team_id, page, per_page

curl 'https://clify-dev.netlify.app/crates/search-crates?q=http+client&sort=downloads&all_keywords=serde'

get-crate

Get a crate's details: description, links, download totals, keywords, categories and default version Params: name*

curl 'https://clify-dev.netlify.app/crates/get-crate'

list-versions

List all published versions of a crate, with downloads, yanked status, license and MSRV Params: name*, sort, per_page

curl 'https://clify-dev.netlify.app/crates/list-versions'

get-version

Get details of one crate version: features, license, checksum, MSRV, edition, publisher Params: name*, version*

curl 'https://clify-dev.netlify.app/crates/get-version'

list-dependencies

List the dependencies of a specific crate version, with version requirement, kind (normal/dev/build), optional flag and target Params: name*, version*

curl 'https://clify-dev.netlify.app/crates/list-dependencies'

list-reverse-dependencies

List crates that depend on a crate (dependents), sorted by the dependents' downloads Params: name*, page, per_page

curl 'https://clify-dev.netlify.app/crates/list-reverse-dependencies'

get-crate-downloads

Get daily download counts for a crate over roughly the last 90 days, broken down by version id Params: name*

curl 'https://clify-dev.netlify.app/crates/get-crate-downloads'

get-version-downloads

Get daily download counts for one specific crate version Params: name*, version*

curl 'https://clify-dev.netlify.app/crates/get-version-downloads'

list-owners

List the owners (users and GitHub teams) of a crate Params: name*

curl 'https://clify-dev.netlify.app/crates/list-owners'

get-readme

Get the rendered README (HTML) of a specific crate version Params: name*, version*

curl 'https://clify-dev.netlify.app/crates/get-readme'

list-source-files

List the files in a published crate version's source package, with sizes and sha256 Params: name*, version*

curl 'https://clify-dev.netlify.app/crates/list-source-files'

get-advisories

List RustSec security advisories (OSV format) affecting a crate Params: name*

curl 'https://clify-dev.netlify.app/crates/get-advisories'

get-docs-status

Check whether docs.rs built documentation successfully for a crate version Params: name*, version*

curl 'https://clify-dev.netlify.app/crates/get-docs-status'

get-user

Get a crates.io user's public profile (numeric id, name, GitHub link) by login Params: login*

curl 'https://clify-dev.netlify.app/crates/get-user'

get-team

Get a crate-owning GitHub team's profile (numeric id, name, org URL) by team login Params: team*

curl 'https://clify-dev.netlify.app/crates/get-team'

list-categories

List all crate categories with their slugs, descriptions and crate counts Params: sort, page, per_page

curl 'https://clify-dev.netlify.app/crates/list-categories?sort=alpha'

get-category

Get one category's details, including subcategories, parent categories and crate count Params: slug*

curl 'https://clify-dev.netlify.app/crates/get-category'

list-keywords

List crate keywords with crate counts, sorted by popularity or alphabetically Params: sort, page, per_page

curl 'https://clify-dev.netlify.app/crates/list-keywords?sort=crates'

get-summary

Get the home-page summary: total crates and downloads, new, most-downloaded and just-updated crates, popular keywords and categories Params: none

curl 'https://clify-dev.netlify.app/crates/get-summary'
