crates API for agents (unofficial) — JSON over curl

crates.io, the Rust package registry. This CLI searches crates and reads crate, version, dependency, download, owner, readme, source-file, advisory, docs.rs, user, team, category and keyword data through the public /api/v1 API.

Host: crates.io. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-crates

Search or list crates by text query, with optional keyword/category/letter/user/team filters, sorting and pagination Params: q, sort, all_keywords, keyword, category, letter, user_id, team_id, page, per_page Read-only

curl 'https://clify-dev.netlify.app/crates/search-crates?q=http+client&sort=downloads&all_keywords=serde'

get-crate

Get a crate's details: description, links, download totals, keywords, categories and default version Params: name* Read-only

curl 'https://clify-dev.netlify.app/crates/get-crate?name=reqwest'

curl 'https://clify-dev.netlify.app/crates/list-versions?name=reqwest'
