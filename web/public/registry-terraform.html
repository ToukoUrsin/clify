registry-terraform API for agents (unofficial) — JSON over curl

Terraform Registry (registry.terraform.io): search and browse Terraform providers, modules, provider docs, policy libraries and run tasks, and fetch details, versions, download stats and provider binaries through the registry's public v1/v2 JSON APIs and its Algolia search index.

Host: registry.terraform.io. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-registry

Full-text search over one registry index (providers, modules, provider docs, policy libraries or run tasks) using the site's Algolia search Params: query*, index, page, hits_per_page Read-only

curl 'https://clify-dev.netlify.app/registry-terraform/search-registry?query=kubernetes&index=providers'

search-modules

Search modules by keyword using the public v1 registry API, optionally filtered by provider, namespace or verified status Params: q*, provider, namespace, verified, api_limit, offset Read-only

curl 'https://clify-dev.netlify.app/registry-terraform/search-modules?q=vpc'

list-providers

Browse providers, filtered by tier, category or namespace, with sorting and pagination Params: tier, category, namespace, sort, page, page_size Read-only

curl 'https://clify-dev.netlify.app/registry-terraform/list-providers?tier=partner&category=database'

list-modules

Browse modules, filtered by provider or namespace, with latest version info, sorting and pagination Params: provider, namespace, sort, page, page_size Read-only

curl 'https://clify-dev.netlify.app/registry-terraform/list-modules?provider=google'

get-module

Get the latest version of a module: description, source, inputs, outputs, resources, submodules and the list of all versions Params: namespace*, name*, provider* Read-only

curl 'https://clify-dev.netlify.app/registry-terraform/get-module?namespace=terraform-aws-modules&name=vpc&provider=aws'

get-module-version

curl 'https://clify-dev.netlify.app/registry-terraform/get-module-version?namespace=terraform-aws-modules&name=vpc&provider=aws&version=6.7.3'
