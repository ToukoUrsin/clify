registry-terraform API for agents (unofficial) — JSON over curl | clify

Terraform Registry (registry.terraform.io): search and browse Terraform providers, modules, provider docs, policy libraries and run tasks, and fetch details, versions, download stats and provider binaries through the registry's public v1/v2 JSON APIs and its Algolia search index.

Host: registry.terraform.io. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-registry

Full-text search over one registry index (providers, modules, provider docs, policy libraries or run tasks) using the site's Algolia search Params: query*, index, page, hits_per_page

curl 'https://clify-dev.netlify.app/registry-terraform/search-registry'

search-modules

Search modules by keyword using the public v1 registry API, optionally filtered by provider, namespace or verified status Params: q*, provider, namespace, verified, api_limit, offset

curl 'https://clify-dev.netlify.app/registry-terraform/search-modules?q=vpc'

list-providers

Browse providers, filtered by tier, category or namespace, with sorting and pagination Params: tier, category, namespace, sort, page, page_size

curl 'https://clify-dev.netlify.app/registry-terraform/list-providers?tier=partner&category=database'

list-modules

Browse modules, filtered by provider or namespace, with latest version info, sorting and pagination Params: provider, namespace, sort, page, page_size

curl 'https://clify-dev.netlify.app/registry-terraform/list-modules?provider=google'

get-module

Get the latest version of a module: description, source, inputs, outputs, resources, submodules and the list of all versions Params: namespace*, name*, provider*

curl 'https://clify-dev.netlify.app/registry-terraform/get-module'

get-module-version

Get one specific version of a module, including its submodules (v2 API) Params: namespace*, name*, provider*, version*

curl 'https://clify-dev.netlify.app/registry-terraform/get-module-version'

list-module-versions

List all published versions of a module Params: namespace*, name*, provider*

curl 'https://clify-dev.netlify.app/registry-terraform/list-module-versions'

get-module-downloads

Get a module's download counts (week, month, year, total) by its numeric module id Params: module_id*

curl 'https://clify-dev.netlify.app/registry-terraform/get-module-downloads'

get-provider

Get provider details plus all of its provider-versions (the included versions carry the numeric provider-version ids that list-provider-docs needs) Params: namespace*, name*

curl 'https://clify-dev.netlify.app/registry-terraform/get-provider'

list-provider-versions

List every version of a provider with its supported protocols and OS/arch platforms (public v1 API) Params: namespace*, name*

curl 'https://clify-dev.netlify.app/registry-terraform/list-provider-versions'

get-provider-downloads

Get a provider's download counts (week, month, year, total) by its numeric provider id Params: provider_id*

curl 'https://clify-dev.netlify.app/registry-terraform/get-provider-downloads'

list-provider-docs

List the documentation pages (resources, data sources, guides, functions) of one provider version Params: version_id*

curl 'https://clify-dev.netlify.app/registry-terraform/list-provider-docs'

find-provider-doc

Look up a provider doc page by provider-version id, category and slug (e.g. the aws_vpc resource) to get its doc id Params: provider_version*, slug*, category, language

curl 'https://clify-dev.netlify.app/registry-terraform/find-provider-doc?provider_version=113259&slug=vpc&category=resources'

get-provider-doc

Get the full markdown content of one provider documentation page by doc id Params: doc_id*

curl 'https://clify-dev.netlify.app/registry-terraform/get-provider-doc'

get-provider-download

Get the download URL, SHA256 sum and signing keys for a provider binary for a given version, OS and architecture Params: namespace*, name*, version*, os*, arch*

curl 'https://clify-dev.netlify.app/registry-terraform/get-provider-download'

list-policies

Browse Sentinel/OPA policy libraries, optionally by namespace, with pagination Params: namespace, page, page_size

curl 'https://clify-dev.netlify.app/registry-terraform/list-policies?page=1'

get-policy-library

Get a policy library's details and its versions Params: namespace*, name*

curl 'https://clify-dev.netlify.app/registry-terraform/get-policy-library'

get-policy-library-version

Get one version of a policy library together with the individual policies it contains Params: namespace*, name*, version*

curl 'https://clify-dev.netlify.app/registry-terraform/get-policy-library-version'

list-run-tasks

Browse HCP Terraform run-task integrations, optionally filtered by category Params: category, page, page_size

curl 'https://clify-dev.netlify.app/registry-terraform/list-run-tasks?page=1'

list-categories

List categories (id, name, slug) used to filter providers, policy libraries or run tasks Params: resource

curl 'https://clify-dev.netlify.app/registry-terraform/list-categories?resource=providers'

get-namespace-profile

Get the GitHub profile (name, avatar, location, website, bio) behind a registry namespace Params: namespace*

curl 'https://clify-dev.netlify.app/registry-terraform/get-namespace-profile'
