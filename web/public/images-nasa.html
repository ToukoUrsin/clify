images-nasa API for agents (unofficial) — JSON over curl | clify

NASA Image and Video Library (images.nasa.gov): search NASA's public image, video and audio archive, browse albums and the popular/recent feeds, and get asset files, technical metadata and video captions for any item.

Host: images.nasa.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-media

Search NASA images, videos and audio by free text, keyword tags, NASA center, media type and year range (paged, 100 per page by default) Params: q, media_type, year_start, year_end, keywords, center, title, description, photographer, location, nasa_id, page_size, page

curl 'https://clify-dev.netlify.app/images-nasa/search-media?q=Apollo+11&media_type=image%2Cvideo&year_start=1969&year_end=1970&keywords=LUNAR+SURFACE&center=HQ'

get-asset

List the downloadable file URLs (original, large, medium, small, thumb; video encodings, captions, metadata) for a NASA media item Params: nasa_id*

curl 'https://clify-dev.netlify.app/images-nasa/get-asset'

get-metadata

Get the full technical and descriptive metadata (EXIF/QuickTime/AVAIL fields: dates, dimensions, duration, keywords, credits) of a NASA media item Params: media_type*, nasa_id*

curl 'https://clify-dev.netlify.app/images-nasa/get-metadata'

get-metadata-location

Resolve the URL of a media item's metadata.json via the official API (use when you don't know the item's media type) Params: nasa_id*

curl 'https://clify-dev.netlify.app/images-nasa/get-metadata-location'

get-video-captions

Get the SRT caption/subtitle transcript of a NASA video Params: nasa_id*

curl 'https://clify-dev.netlify.app/images-nasa/get-video-captions'

get-album

List the media items in a named NASA album (e.g. Apollo), paged Params: album_name*, page

curl 'https://clify-dev.netlify.app/images-nasa/get-album'

list-popular

List currently trending/popular media items shown on the home page Params: none

curl 'https://clify-dev.netlify.app/images-nasa/list-popular'

list-recent

List the newest uploads to the NASA Image and Video Library Params: none

curl 'https://clify-dev.netlify.app/images-nasa/list-recent'
