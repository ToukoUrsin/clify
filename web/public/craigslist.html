craigslist API for agents (unofficial) — JSON over curl

San Francisco Bay Area Craigslist: search listings by keyword, category, area, price, distance and other filters through Craigslist's JSON search API, look up postings by id, and get category counts and search suggestions.

Host: sfbay.craigslist.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-listings

Search SF Bay Area Craigslist listings by keyword, category, area/subarea/city, price range, zip+distance, sort and category-specific filters. Returns the first batch of compact results plus decode ta Params: query, cat, searchPath, min_price, max_price, postal, radius, sort, hasPic, purveyor, min_bedrooms, no_smoking, auto_make_model, userpostingid Read-only

curl 'https://clify-dev.netlify.app/craigslist/search-listings?query=bicycle&cat=sss&searchPath=area%2Fsfbay&min_price=100&max_price=800&postal=94110&sort=priceasc'

search-listings-more

Fetch the next batch of results for a search already run with search-listings (the site has no page 2; it loads more batches as you scroll). Params: batch*, cacheId* Read-only

curl 'https://clify-dev.netlify.app/craigslist/search-listings-more?batch=0-1080-1080-6-0-1792566210-1792566336&cacheId=MToBizevob6RIBxqY6JQ22iOs2AaYUg7mb8KBWJVniCnn6oTSgxpoO34H2aBNcMUXihn3uRwyrJ_zjH_NPwvgOrS25SME_clhB8CeFPy4Suo4t2FaOn3BlXjdOt_QRckIPX5XVbN4WqUnhH80U82LgHzjHKkv-qBbS_hCriBXP5bLPvM_sTCIoDPSC3y1G8'

get-postings

Look up full posting records (title, price, location, neighborhood, images, seo slug, posted date) by posting id. This is how the site loads the favorites list. Params: ids* Read-only

curl 'https://clify-dev.netlify.app/craigslist/get-postings?ids=aXRlbXM6Nzk4Njk3MjkxOA%3D%3D'

get-category-counts

Count matching listings per category for a Craigslist search URL. Useful to pick a category abbreviation (cat) for a query. Params: searchUrl*, include_types Read-only

curl 'https://clify-dev.netlify.app/craigslist/get-category-counts?searchUrl=https%3A%2F%2Fwww.craigslist.org%2Fsearch%2Farea%2Fsfbay%3Fcat%3Dsss%26query%3Dbicycle'

suggest-search

Autocomplete search keywords for the SF Bay Area, optionally within one category. Params: query*, cat Read-only

curl 'https://clify-dev.netlify.app/craigslist/suggest-search?query=bicycle'

get-likely-categories

Guess which category abbreviations (cat) best match a keyword query in the SF Bay Area. Params: query* Read-only

curl 'https://clify-dev.netlify.app/craigslist/get-likely-categories?query=bicycle'

suggest-make-model

Autocomplete car make/model names for the auto_make_model filter of search-listings (cars+trucks). Params: query* Read-only

curl 'https://clify-dev.netlify.app/craigslist/suggest-make-model?query=toyota+tacoma'
