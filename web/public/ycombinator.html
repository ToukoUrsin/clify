ycombinator API for agents (unofficial) — JSON over curl

Y Combinator public site (ycombinator.com): search the YC startup directory (via YC's Algolia index), look up companies, their jobs and job postings, Launch YC posts, the jobs board, and YC people.

Host: ycombinator.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

list-directory-categories

List the directory's industry and location categories with their URL slugs, plus links to hiring-by-location pages Params: industry, location Read-only

curl 'https://clify-dev.netlify.app/ycombinator/list-directory-categories?industry=Developer+Tools&location=san-francisco-bay-area'

get-company

Get a YC company's profile page by slug (title/tagline and summary description with founders, team size, location, hiring) Params: slug* Read-only

curl 'https://clify-dev.netlify.app/ycombinator/get-company'

list-company-jobs

List the open job postings of a YC company Params: slug* Read-only

curl 'https://clify-dev.netlify.app/ycombinator/list-company-jobs'

get-job

Get a job posting (title, description, salary range, location, remote type, date posted) from its structured JobPosting data Params: slug*, jobId* Read-only

curl 'https://clify-dev.netlify.app/ycombinator/get-job'

get-launch

Get a Launch YC post: title, tagline, upvote count, author, company link and posting date Params: id* Read-only

curl 'https://clify-dev.netlify.app/ycombinator/get-launch'

list-jobs

List featured jobs at YC startups from the Work at a Startup jobs board Params: none Read-only

curl 'https://clify-dev.netlify.app/ycombinator/list-jobs'

list-jobs-by-role

List jobs at YC startups for one role (e.g. product-manager, software-engineer) Params: role* Read-only

curl 'https://clify-dev.netlify.app/ycombinator/list-jobs-by-role'

list-jobs-by-role-location

List jobs at YC startups for one role in a given location or remote Params: role*, location* Read-only

curl 'https://clify-dev.netlify.app/ycombinator/list-jobs-by-role-location'

list-people

List YC people (president, partners, staff) with short bios and profile links Params: none Read-only

curl 'https://clify-dev.netlify.app/ycombinator/list-people'

get-person

Get a YC person's profile (name, role, bio) by slug Params: slug* Read-only

curl 'https://clify-dev.netlify.app/ycombinator/get-person'
