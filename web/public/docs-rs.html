docs-rs API for agents (unofficial) — JSON over curl | clify

docs.rs is the documentation host for Rust crates. This CLI searches crates, resolves the best match, reads crate pages (build status, builds, features, versions, source files), reads rustdoc pages and item lists, and browses release listings, failures, the build queue and the Atom feed.

Host: docs.rs. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-crates

Search Rust crates on docs.rs by keyword, optionally sorted by downloads or recency Params: query*, sort, paginate

curl 'https://clify-dev.netlify.app/docs-rs/search-crates?query=serde&sort=downloads'

resolve-crate

I'm Feeling Lucky: jump to the best-matching crate for a query and return its exact name and latest version Params: query*

curl 'https://clify-dev.netlify.app/docs-rs/resolve-crate?query=reqwest'

get-crate

Get a crate's docs.rs overview page: title, description, documentation link and coverage Params: name*, version

curl 'https://clify-dev.netlify.app/docs-rs/get-crate'

get-crate-status

Check whether docs built successfully for a crate version (JSON: doc_status, resolved version) Params: name*, version

curl 'https://clify-dev.netlify.app/docs-rs/get-crate-status'

list-crate-builds

List the docs build history of a crate version: rustc version, date, duration, memory, result Params: name*, version

curl 'https://clify-dev.netlify.app/docs-rs/list-crate-builds'

list-crate-features

List the Cargo feature flags of a crate version Params: name*, version

curl 'https://clify-dev.netlify.app/docs-rs/list-crate-features'

list-crate-versions

List all published versions of a crate with their release dates Params: name*, version, target

curl 'https://clify-dev.netlify.app/docs-rs/list-crate-versions'

list-source-files

List the files and folders in a crate's published source package (root or a subfolder) Params: name*, version, dir

curl 'https://clify-dev.netlify.app/docs-rs/list-source-files'

get-source-file

Read the contents of one file in a crate's source package, e.g. Cargo.toml or src/lib.rs Params: name*, version, path*

curl 'https://clify-dev.netlify.app/docs-rs/get-source-file'

get-crate-docs

Read a crate's rustdoc landing page: crate docs text, version, permalink Params: name*, version, crate*

curl 'https://clify-dev.netlify.app/docs-rs/get-crate-docs'

list-crate-items

List every public item (structs, enums, traits, functions, types, constants) of a crate, with links to their doc pages Params: name*, version, crate*

curl 'https://clify-dev.netlify.app/docs-rs/list-crate-items'

get-doc-item

Read the rustdoc page of one item (struct, trait, fn...) inside a crate Params: name*, version, crate*, item_path*

curl 'https://clify-dev.netlify.app/docs-rs/get-doc-item'

list-releases

Browse docs.rs release listings: recent releases, top crates by GitHub stars, recent build failures, or failures sorted by stars Params: kind, page

curl 'https://clify-dev.netlify.app/docs-rs/list-releases'

get-releases-feed

Get the Atom feed of the most recently built crate releases (structured JSON) Params: none

curl 'https://clify-dev.netlify.app/docs-rs/get-releases-feed'

list-build-queue

List the crate releases waiting in the docs.rs build queue Params: none

curl 'https://clify-dev.netlify.app/docs-rs/list-build-queue'

list-builds-in-progress

List the crate docs builds currently running and how long they have been running Params: none

curl 'https://clify-dev.netlify.app/docs-rs/list-builds-in-progress'
