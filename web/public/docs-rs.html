docs-rs API for agents (unofficial) — JSON over curl

docs.rs is the documentation host for Rust crates. This CLI searches crates, resolves the best match, reads crate pages (build status, builds, features, versions, source files), reads rustdoc pages and item lists, and browses release listings, failures, the build queue and the Atom feed.

Host: docs.rs. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-crates

Search Rust crates on docs.rs by keyword, optionally sorted by downloads or recency Params: query*, sort, paginate Read-only

curl 'https://clify-dev.netlify.app/docs-rs/search-crates?query=serde&sort=downloads'

resolve-crate

I'm Feeling Lucky: jump to the best-matching crate for a query and return its exact name and latest version Params: query* Read-only

curl 'https://clify-dev.netlify.app/docs-rs/resolve-crate?query=reqwest'

get-crate

Get a crate's docs.rs overview page: title, description, documentation link and coverage Params: name*, version Read-only

curl 'https://clify-dev.netlify.app/docs-rs/get-crate?name=serde'

get-crate-status

Check whether docs built successfully for a crate version (JSON: doc_status, resolved version) Params: name*, version Read-only

curl 'https://clify-dev.netlify.app/docs-rs/get-crate-status?name=tokio'

list-crate-builds

List the docs build history of a crate version: rustc version, date, duration, memory, result Params: name*, version Read-only

curl 'https://clify-dev.netlify.app/docs-rs/list-crate-builds?name=serde'

list-crate-features

List the Cargo feature flags of a crate version Params: name*, version Read-only

curl 'https://clify-dev.netlify.app/docs-rs/list-crate-features?name=tokio'

list-crate-versions

List all published versions of a crate with their release dates Params: name*, version, target Read-only

curl 'https://clify-dev.netlify.app/docs-rs/list-crate-versions?name=serde'

list-source-files

List the files and folders in a crate's published source package (root or a subfolder) Params: name*, version, dir Read-only

curl 'https://clify-dev.netlify.app/docs-rs/list-source-files?name=tokio'

get-source-file

Read the contents of one file in a crate's source package, e.g. Cargo.toml or src/lib.rs Params: name*, version, path* Read-only

curl 'https://clify-dev.netlify.app/docs-rs/get-source-file?name=tokio&path=Cargo.toml'

get-crate-docs

Read a crate's rustdoc landing page: crate docs text, version, permalink Params: name*, version, crate* Read-only

curl 'https://clify-dev.netlify.app/docs-rs/get-crate-docs?name=tokio&crate=tokio'

list-crate-items

List every public item (structs, enums, traits, functions, types, constants) of a crate, with links to their doc pages Params: name*, version, crate* Read-only

curl 'https://clify-dev.netlify.app/docs-rs/list-crate-items?name=reqwest&crate=reqwest'

get-doc-item

Read the rustdoc page of one item (struct, trait, fn...) inside a crate Params: name*, version, crate*, item_path* Read-only

curl 'https://clify-dev.netlify.app/docs-rs/get-doc-item?name=tokio&crate=tokio&item_path=task%2Fstruct.JoinHandle.html'

list-releases

Browse docs.rs release listings: recent releases, top crates by GitHub stars, recent build failures, or failures sorted by stars Params: kind, page Read-only

get-releases-feed

list-build-queue

List the crate releases waiting in the docs.rs build queue Params: none Read-only

curl 'https://clify-dev.netlify.app/docs-rs/list-build-queue'

list-builds-in-progress
