funcheap API for agents (unofficial) — JSON over curl

Funcheap SF (sf.funcheap.com): hand-picked free and cheap San Francisco Bay Area events. This CLI lists events by date, today or weekend, category, region or neighborhood, venue and recurring series, and fetches event details. Each result has title, date/time, cost, venue and URL.

Host: sf.funcheap.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

list-events-by-date

List events happening on a specific calendar date (WordPress date archive). The details field holds date, time, cost and venue text. Params: year*, month*, day* Read-only

curl 'https://clify-dev.netlify.app/funcheap/list-events-by-date?year=2026&month=10&day=24'

list-events-by-region

List upcoming events in a region or neighborhood, e.g. san-francisco, east-bay, peninsula, south-bay, north-bay, soma-san-francisco. Paginated. Params: region*, page Read-only

curl 'https://clify-dev.netlify.app/funcheap/list-events-by-region?region=soma-san-francisco&page=2'

list-events-by-category

List upcoming events in an event-type category such as live music, comedy, eating & drinking, art & museums or movies. Paginated. Params: category*, page Read-only

curl 'https://clify-dev.netlify.app/funcheap/list-events-by-category?category=live-music-event&page=2'

list-today-events

List events happening today in San Francisco and the Bay Area. Params: none Read-only

curl 'https://clify-dev.netlify.app/funcheap/list-today-events'

list-weekend-events

List events for this weekend. Pass --next 1 for the following weekend. Params: next Read-only

curl 'https://clify-dev.netlify.app/funcheap/list-weekend-events?next=1'

list-free-events

List upcoming free events in San Francisco and the Bay Area. Params: none Read-only

curl 'https://clify-dev.netlify.app/funcheap/list-free-events'

list-top-picks

List the editors' *Top Pick* events of the week. Params: none Read-only

curl 'https://clify-dev.netlify.app/funcheap/list-top-picks'

list-calendar-events

Day-by-day calendar of upcoming events for a calendar region (san-francisco, east-bay). Rows without a url are date headings. Paginated. Params: calendar*, page Read-only

curl 'https://clify-dev.netlify.app/funcheap/list-calendar-events?calendar=san-francisco&page=2'

get-event

Get an event's detail page metadata (name, description, URL, image) by its slug, the path segment of an event url. Params: slug* Read-only

curl 'https://clify-dev.netlify.app/funcheap/get-event?slug=chowder-fest-sfs-clam-chowder-showdown-fishermans-wharf'

list-venue-events

List upcoming events at a venue, by venue slug (from /venue/{slug}/ links). Params: venue* Read-only

curl 'https://clify-dev.netlify.app/funcheap/list-venue-events?venue=underdogs-cantina'

list-series-dates

List all upcoming dates of a recurring event series, by series slug (from /event-series/{slug}/ links). Params: series* Read-only

curl 'https://clify-dev.netlify.app/funcheap/list-series-dates?series=1-wing-wednesdays-underdogs-cantina'

list-new-events

RSS feed of recently added events, site-wide only (per-region feeds redirect here), with title, link, publish date and categories. Params: none Read-only

curl 'https://clify-dev.netlify.app/funcheap/list-new-events'
