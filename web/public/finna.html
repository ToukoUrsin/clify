finna API for agents (unofficial) — JSON over curl

Finna.fi is the Finnish national search service for libraries, archives and museums. This CLI searches and reads records and authority data through the public read-only Finna REST API (api.finna.fi) and gets citations, exports and holdings from www.finna.fi.

Host: finna.fi. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-records

Keyword search over Finna's index of books, images, archive material and museum objects, with filters, sorting and paging (public Finna API) Params: lookfor*, type, filter, sort, page, api_limit, lng Read-only

curl 'https://clify-dev.netlify.app/finna/search-records?lookfor=sibelius&filter=format%3A%220%2FBook%2F%22&sort=main_date_str+desc'

get-record

Get full metadata for one record by its Finna id (public Finna API), optionally choosing which fields to return Params: id*, field, lng Read-only

curl 'https://clify-dev.netlify.app/finna/get-record?id=helmet.1830976&field=title'

get-facets

List facet values with counts (formats, organisations, languages, years, ...) for a search or for the whole index; the values can be used as search-records filters Params: facet*, lookfor, filter, lng Read-only

curl 'https://clify-dev.netlify.app/finna/get-facets?facet=format&lookfor=sibelius'

list-organisations

List the organisations (libraries, archives, museums) whose material is in Finna, with record counts, from the building facet Params: lookfor, lng Read-only

curl 'https://clify-dev.netlify.app/finna/list-organisations?lng=en-gb'

search-authorities

Search authority records for people and organisations (public Finna API) Params: lookfor*, type, filter, page, api_limit, lng Read-only

curl 'https://clify-dev.netlify.app/finna/search-authorities?lookfor=sibelius'

get-authority

Get one authority record (person or organisation) by id, using an id from search-authorities (public Finna API) Params: id*, lng Read-only

curl 'https://clify-dev.netlify.app/finna/get-authority?id=melinda.%28FI-ASTERI-N%29000030333'

get-citation

Get ready-made citations (APA, Chicago, MLA, Harvard) for a record Params: id* Read-only

curl 'https://clify-dev.netlify.app/finna/get-citation?id=helmet.1830976'

export-record

Export a record as a citation-manager file (RIS, BibTeX, EndNote, RefWorks, MARC ...) and return the raw text Params: id*, style* Read-only

curl 'https://clify-dev.netlify.app/finna/export-record?id=helmet.1830976&style=RIS'
