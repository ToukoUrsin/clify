kalshi API for agents (unofficial) — JSON over curl

Kalshi prediction-market exchange: search public markets and read prices, volume, order books, trades, price history and close dates from Kalshi's public v1 API (no login needed).

Host: kalshi.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-markets

Search or browse prediction markets (series/events with their markets, prices and volume) by keyword, category, status and frequency, sorted by relevance, trending, volume, newest or closing soon. Params: query, order_by, status, frequency, category, excluded_categories, page_size, cursor Read-only

curl 'https://clify-dev.netlify.app/kalshi/search-markets?query=bitcoin&order_by=querymatch&frequency=daily&category=Economics'

get-event

Get an event and all its markets: title, rules, settlement sources, and per-market bid/ask/last price, volume, open interest, open/close/expiration dates and status. Comma-separate several event ticke Params: eventTicker* Read-only

curl 'https://clify-dev.netlify.app/kalshi/get-event?eventTicker=CONTROLH-2026'

get-market

Get one market's current price (yes bid/ask/last in dollars), volume, open interest, status and open/close/expiration dates by market ticker. Params: marketTicker* Read-only

curl 'https://clify-dev.netlify.app/kalshi/get-market?marketTicker=CONTROLH-2026-D'

get-event-summary

Compact card view of an event: series/event titles, total event and series volume, and each market's title, ticker, yes bid/ask, price, open and close dates. Params: eventTicker* Read-only

curl 'https://clify-dev.netlify.app/kalshi/get-event-summary?eventTicker=CONTROLH-2026'

get-order-book

Get the live order book (yes and no price levels with resting quantity, prices in dollars) for one or more markets. Params: marketTicker* Read-only

curl 'https://clify-dev.netlify.app/kalshi/get-order-book?marketTicker=CONTROLH-2026-D'

list-trades

List recent public trades in a series: market ticker, price, contract count, taker side and time. Params: seriesTicker* Read-only

curl 'https://clify-dev.netlify.app/kalshi/list-trades?seriesTicker=CONTROLH'

get-event-forecast-history

Chart history of an event's forecast (implied probability or implied value) over a time range at a chosen candle interval. Params: seriesTicker*, eventTicker*, start_ts*, end_ts*, period_interval Read-only

curl 'https://clify-dev.netlify.app/kalshi/get-event-forecast-history?seriesTicker=KXBTCD&eventTicker=KXBTCD-26OCT2117&start_ts=1792530000&end_ts=1792569600&period_interval=1'

get-market-price-history

Price/probability history of a single market (by market UUID 'id' from get-event or get-market) over a time range. Params: seriesTicker*, marketId*, start_ts*, end_ts*, period_interval Read-only

curl 'https://clify-dev.netlify.app/kalshi/get-market-price-history?seriesTicker=CONTROLS&marketId=028a3af5-3b39-4e37-942f-35f7c7d1d48e&start_ts=1730908800&end_ts=1792656000&period_interval=1440'

get-series

Get series metadata: title, category, frequency, tags, total series volume, fee type, settlement sources and contract rules URL. Comma-separate several tickers. Params: seriesTicker* Read-only

curl 'https://clify-dev.netlify.app/kalshi/get-series?seriesTicker=CONTROLS%2CKXMLB%2CKXFEDDECISION'

list-related-markets

List series/events related to a given event ticker (recommendations), with their markets, prices and volume. Params: eventTicker*, api_limit Read-only

curl 'https://clify-dev.netlify.app/kalshi/list-related-markets?eventTicker=KXBTCD-26OCT2117'

get-milestone-volume

Total dollar volume of a milestone (a group of related events, e.g. an election or Fed meeting) broken down per event; milestone_id comes from get-event-summary. Params: milestoneId* Read-only

curl 'https://clify-dev.netlify.app/kalshi/get-milestone-volume?milestoneId=fa891339-a321-48fb-bbcc-186fa3acf525'

get-live-data

Live real-world data for milestones (e.g. election vote counts, reporting %, race call status, game scores) shown on the calendar. Params: milestoneId* Read-only

curl 'https://clify-dev.netlify.app/kalshi/get-live-data?milestoneId=ec826780-20ba-4d06-9a52-f6010c39da3c'

list-perps

List active perpetual/margin markets (crypto etc.) with bid, ask, price, 24h volume, open interest and leverage. Params: none Read-only

curl 'https://clify-dev.netlify.app/kalshi/list-perps'

list-topics

List topic keywords (tags) with how many events each covers; useful for discovering search terms. Params: api_limit, cursor Read-only

curl 'https://clify-dev.netlify.app/kalshi/list-topics?api_limit=50'

get-exchange-status

Check whether the Kalshi exchange and trading are currently active. Params: none Read-only

curl 'https://clify-dev.netlify.app/kalshi/get-exchange-status'
