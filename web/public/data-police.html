data-police API for agents (unofficial) — JSON over curl

data.police.uk is the UK's open police data API. This CLI covers forces and senior officers, street-level crimes and outcomes, neighbourhood teams, events and priorities, stop and search records, data availability dates, and the custom CSV download form.

Host: data.police.uk. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

list-forces

List all police forces (id and name). Use the id in other commands. Params: none Read-only

curl 'https://clify-dev.netlify.app/data-police/list-forces'

get-force

Get one police force's details: website, phone number and engagement channels such as social media. Params: force* Read-only

curl 'https://clify-dev.netlify.app/data-police/get-force'

list-force-officers

List the senior officers of a police force, with rank and bio. Params: force* Read-only

curl 'https://clify-dev.netlify.app/data-police/list-force-officers'

list-crime-categories

List the crime categories (url slug and name) that were valid for a given month. Params: date Read-only

curl 'https://clify-dev.netlify.app/data-police/list-crime-categories?date=2024-01'

list-dates

List the months that have street-level data available, and which forces published stop and search data for each month. Params: none Read-only

curl 'https://clify-dev.netlify.app/data-police/list-dates'

get-last-updated

Get the date the crime data was last updated (this is the latest month available). Params: none Read-only

curl 'https://clify-dev.netlify.app/data-police/get-last-updated'

street-crimes

Street-level crimes for one month, either within a 1-mile radius of a lat/lng point or inside a custom polygon. Can be limited to one category. Params: category, lat, lng, poly, date Read-only

curl 'https://clify-dev.netlify.app/data-police/street-crimes?lat=52.629729&lng=-1.131592&poly=52.268%2C0.543%3A52.794%2C0.238%3A52.130%2C0.478&date=2024-01'

crimes-at-location

Crimes recorded at the anonymised location nearest to a lat/lng point, or at a specific street location id, for one month. Params: date, lat, lng, location_id Read-only

curl 'https://clify-dev.netlify.app/data-police/crimes-at-location?date=2024-01&lat=52.629729&lng=-1.131592&location_id=1738423'

crimes-no-location

Crimes a force recorded in one month that could not be mapped to a location. Params: force*, category, date Read-only

curl 'https://clify-dev.netlify.app/data-police/crimes-no-location?force=leicestershire&category=all-crime&date=2024-01'

outcomes-at-location

Case outcomes recorded in one month near a lat/lng point, at a street location id, or inside a polygon. Each outcome includes the crime it relates to. Params: date, lat, lng, location_id, poly Read-only

curl 'https://clify-dev.netlify.app/data-police/outcomes-at-location?date=2024-01&lat=52.629729&lng=-1.131592&location_id=1738423&poly=52.268%2C0.543%3A52.794%2C0.238%3A52.130%2C0.478'

get-crime-outcomes

Get the full outcome history of one crime, looked up by its persistent_id. Params: persistent_id* Read-only

curl 'https://clify-dev.netlify.app/data-police/get-crime-outcomes'

list-neighbourhoods

Get a neighbourhood's boundary as a list of lat/lng points. These can be joined as lat,lng:lat,lng for the poly param of other commands. Params: force*, neighbourhood* Read-only

curl 'https://clify-dev.netlify.app/data-police/get-neighbourhood-boundary'

Stop and searches in one month within a 1-mile radius of a lat/lng point, or inside a polygon. Params: lat, lng, poly, date Read-only
