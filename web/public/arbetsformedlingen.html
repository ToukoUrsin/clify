arbetsformedlingen API for agents (unofficial) — JSON over curl

Platsbanken (Arbetsförmedlingen, the Swedish Public Employment Service job board): search job ads by keyword and municipality, read full ad details, list popular occupations, look up location and occupation taxonomy IDs, and get search suggestions.

Host: arbetsformedlingen.se. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-jobs

Free-text search of Platsbanken job ads (title, employer, occupation, workplace, dates), sorted by relevance or date Params: q*, order, source, maxRecords, startIndex Read-only

curl 'https://clify-dev.netlify.app/arbetsformedlingen/search-jobs'

search-jobs-in-municipality

Free-text job search limited to one Swedish municipality (municipality ID from get-taxonomy-tree --type LOCATION) Params: q*, municipality*, order, source, maxRecords, startIndex Read-only

curl 'https://clify-dev.netlify.app/arbetsformedlingen/search-jobs-in-municipality'

get-job

Full details of one job ad: HTML description, employer, workplace address, employment type, working hours, salary type, how to apply Params: id* Read-only

curl 'https://clify-dev.netlify.app/arbetsformedlingen/get-job'

suggest-search-terms

Typeahead suggestions (completions) for a partial job-search query Params: q* Read-only

curl 'https://clify-dev.netlify.app/arbetsformedlingen/suggest-search-terms?q=sjuksk'

list-popular-occupations

Occupations with the most open job ads right now, with ad counts Params: api_limit Read-only

curl 'https://clify-dev.netlify.app/arbetsformedlingen/list-popular-occupations?api_limit=20'

get-taxonomy-tree

Taxonomy tree with IDs used for search filters: LOCATION = regions (län) and their municipalities, OCCUPATION = occupation fields and groups Params: type* Read-only

curl 'https://clify-dev.netlify.app/arbetsformedlingen/get-taxonomy-tree?type=LOCATION'
