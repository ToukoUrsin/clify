tidesandcurrents-noaa API for agents (unofficial) — JSON over curl

NOAA Tides & Currents (CO-OPS): find tide, current and observation stations and fetch tide predictions, water levels, weather, current predictions, datums, harmonic constituents, sea level trends and storm surge alerts through NOAA's public metadata and data APIs.

Host: tidesandcurrents.noaa.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-tide-stations

Search tide prediction stations by name (e.g. 'Boston'); returns station IDs, state, region and coordinates Params: q* Read-only

curl 'https://clify-dev.netlify.app/tidesandcurrents-noaa/search-tide-stations?q=Boston'
