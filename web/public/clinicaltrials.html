clinicaltrials API for agents (unofficial) — JSON over curl | clify

ClinicalTrials.gov (NIH/NLM registry of over 600k clinical studies). The CLI searches studies, fetches full study records and their version history, autocompletes conditions, interventions, sponsors and facilities, and returns registry statistics and field metadata, all through the site's internal /api/int endpoints.

Host: clinicaltrials.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-studies

Search or list clinical studies by condition, keyword, intervention, sponsor, location or NCT IDs, with facet filters, sorting and offset paging. Returns compact study hits. Params: cond, term, intr, spons, locStr, ids, aggFilters, sort, api_fields, from, api_limit

curl 'https://clify-dev.netlify.app/clinicaltrials/search-studies?cond=breast+cancer&ids=NCT00001372'

count-studies

Get the total number of matching studies and per-facet counts (status, sex, phase, study type, …) for a search, without listing studies. Params: cond, term, intr, spons, locStr, ids, aggFilters

curl 'https://clify-dev.netlify.app/clinicaltrials/count-studies?ids=NCT00001372'

get-study

Get the full record of one study by NCT ID: protocol (description, eligibility, arms, outcomes, locations, contacts), results if posted, and derived data. Uses the public REST API v2. Params: nctId*, api_fields, markupFormat

curl 'https://clify-dev.netlify.app/clinicaltrials/get-study'

suggest

Autocomplete or normalize a condition, intervention, lead sponsor or facility name before searching. Params: input*, dictionary*

curl 'https://clify-dev.netlify.app/clinicaltrials/suggest?input=breast+cancer&dictionary=Condition'

get-field-metadata

Get the study data structure: every field with its piece name (used in fields/sort/AREA[] expressions), type, description and rules. Params: includeIndexedOnly, includeHistoricOnly

curl 'https://clify-dev.netlify.app/clinicaltrials/get-field-metadata'

list-search-areas

List the search areas (term, cond, intr, …), their query param names, and the weighted fields each one searches. Params: none

curl 'https://clify-dev.netlify.app/clinicaltrials/list-search-areas'

get-stats

Get registry statistics: total studies, recruiting and registered counts by location and study type, registrations and results by year, and the last update date. Params: none

curl 'https://clify-dev.netlify.app/clinicaltrials/get-stats'

get-api-spec

Get the OpenAPI 3 (YAML) spec of the public ClinicalTrials.gov REST API v2, the reference for query syntax, filters and field names. Params: none

curl 'https://clify-dev.netlify.app/clinicaltrials/get-api-spec'
