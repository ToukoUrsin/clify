anilist API for agents (unofficial) — JSON over curl

AniList (anilist.co) is an anime and manga database and tracker. This CLI sends read-only queries to AniList's public GraphQL API (https://graphql.anilist.co), the same API the web app uses. It covers searching and filtering anime and manga, media details, characters, staff, relations, reviews, recommendations, stats, character, staff and studio lookups, and the genre and tag lists.

Host: anilist.co. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-media

Search or browse anime/manga by keyword, with filters for type, format, status, season, year, genre and tag, plus sorting. Covers trending, popular, this-season and top-100 lists via sort and season. Params: search, type, format, status, season, seasonYear, genre, tag, isAdult, sort, page, perPage Read-only

curl 'https://clify-dev.netlify.app/anilist/search-media'

get-media

Get full details of one anime or manga by AniList id, or the best match for a title: titles, synopsis, dates, episodes/chapters, genres, tags, scores, studios, next airing episode, links. Params: id, search, type Read-only

curl 'https://clify-dev.netlify.app/anilist/get-media'

list-media-characters

List the characters of an anime or manga (the Characters tab), with role (MAIN/SUPPORTING/BACKGROUND) and voice actors in the chosen language. Params: id*, language, page, perPage Read-only

curl 'https://clify-dev.netlify.app/anilist/list-media-characters'

list-media-staff

List the staff of an anime or manga (the Staff tab) with their roles, e.g. Original Story, Director. Params: id*, page, perPage Read-only

curl 'https://clify-dev.netlify.app/anilist/list-media-staff'

get-media-relations

List the media related to an anime or manga (adaptations, sequels, prequels, side stories, spin-offs) with the relation type. Params: id* Read-only

curl 'https://clify-dev.netlify.app/anilist/get-media-relations'

list-media-recommendations

List the titles users recommend for a given anime or manga, ranked by recommendation rating. Params: id*, page, perPage Read-only

curl 'https://clify-dev.netlify.app/anilist/list-media-recommendations'

list-media-reviews

List user reviews of an anime or manga (the Reviews tab): summary, the reviewer's score and how many users found it helpful. Params: id*, sort, page, perPage Read-only

curl 'https://clify-dev.netlify.app/anilist/list-media-reviews'

get-media-stats

Get statistics for an anime or manga (the Stats tab): rankings, score distribution, distribution of user list statuses (completed, planning, etc.), popularity and favourites. Params: id* Read-only

curl 'https://clify-dev.netlify.app/anilist/get-media-stats'

get-character

Get a character by id, or the best match for a name: name, description, age, birthday, favourites, and the anime/manga they appear in with Japanese voice actors. Params: id, search, page, perPage Read-only

curl 'https://clify-dev.netlify.app/anilist/get-character'

search-characters

Search characters by name and return ids, names, favourites and their most popular media. Params: search*, sort, page, perPage Read-only

curl 'https://clify-dev.netlify.app/anilist/search-characters'

search-staff

Search staff and voice actors by name and return ids, occupations and language. Params: search*, page, perPage Read-only

curl 'https://clify-dev.netlify.app/anilist/search-staff'

get-staff

Get a staff member or voice actor by id, or the best match for a name: bio, occupations, birthday, the media they worked on with roles, and characters voiced. Params: id, search, page, perPage Read-only

curl 'https://clify-dev.netlify.app/anilist/get-staff'

get-studio

Get an animation studio or producer by id or name, with the media it produced, newest first. Params: id, search, page, perPage Read-only

curl 'https://clify-dev.netlify.app/anilist/get-studio'

list-genres

List all genre names accepted by the search-media --genre filter. Params: none Read-only

curl 'https://clify-dev.netlify.app/anilist/list-genres'

list-tags

List all media tags (name, category, description, adult flag) accepted by the search-media --tag filter. Params: none Read-only

curl 'https://clify-dev.netlify.app/anilist/list-tags'
