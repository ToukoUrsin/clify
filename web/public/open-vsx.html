open-vsx API for agents (unofficial) — JSON over curl

Open VSX Registry (open-vsx.org), the open-source VS Code extension marketplace. This CLI searches extensions and reads extension details, versions, README/CHANGELOG files, reviews, publisher namespaces and the registry change feed through its public JSON API.

Host: open-vsx.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-extensions

Search Open VSX extensions by keyword, with optional category filter, sorting and offset paging Params: query, category, sortBy, sortOrder, size, offset Read-only

curl 'https://clify-dev.netlify.app/open-vsx/search-extensions?query=python&category=Linters'

get-extension

Get full metadata of the latest version of an extension: description, files, links, all version URLs and download count Params: namespace*, extension* Read-only

curl 'https://clify-dev.netlify.app/open-vsx/get-extension'

get-extension-version

Get metadata of one specific version of an extension. The version can also be 'latest' or 'pre-release'. Params: namespace*, extension*, version* Read-only

curl 'https://clify-dev.netlify.app/open-vsx/get-extension-version'

get-extension-file

Fetch a text file from an extension version, such as README.md or CHANGELOG.md. The request redirects to the content CDN. Params: namespace*, extension*, version*, fileName* Read-only

curl 'https://clify-dev.netlify.app/open-vsx/get-extension-file'

list-extension-reviews

List user ratings and review comments for an extension Params: namespace*, extension* Read-only

curl 'https://clify-dev.netlify.app/open-vsx/list-extension-reviews'

list-extension-versions

List published versions of an extension, newest first, as a version-to-URL map with offset paging Params: namespace*, extension*, size, offset Read-only

curl 'https://clify-dev.netlify.app/open-vsx/list-extension-versions'

query-extensions

Query extension metadata by id (namespace.name), with optional version and all-versions flag; returns one entry per target platform (e.g. linux-x64, alpine-arm64, universal) Params: extensionId, namespaceName, extensionName, extensionVersion, includeAllVersions Read-only

curl 'https://clify-dev.netlify.app/open-vsx/query-extensions?extensionId=redhat.java'

get-namespace-details

Get a publisher namespace's profile (display name, description, website, social links) and its extensions with stats Params: namespace* Read-only

curl 'https://clify-dev.netlify.app/open-vsx/get-namespace-details'

list-namespace-extensions

List the names of all extensions in a namespace (a map of name to API URL) and whether the namespace is verified Params: namespace* Read-only

curl 'https://clify-dev.netlify.app/open-vsx/list-namespace-extensions'

list-version-changes

Page through the registry-wide feed of extension version changes (publish/state updates), oldest first, using a cursor Params: cursor Read-only

curl 'https://clify-dev.netlify.app/open-vsx/list-version-changes'

get-registry-version

Get the Open VSX server version and limits, such as the maximum extension size Params: none Read-only

curl 'https://clify-dev.netlify.app/open-vsx/get-registry-version'
