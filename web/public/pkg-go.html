pkg-go API for agents (unofficial) — JSON over curl | clify

pkg.go.dev is the Go package and module index. This CLI uses its public JSON API (/v1) to search packages and to look up package and module metadata, versions, symbols, importers and vulnerabilities. It also reads a few server-rendered pages: package docs, the standard library listing and the golang.org/x sub-repositories.

Host: pkg.go.dev. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-packages

Search Go packages by keyword, with an optional filter expression (e.g. on import counts) and cursor paging Params: q*, limit_value, filter, token

curl 'https://clify-dev.netlify.app/pkg-go/search-packages?q=http+router&limit_value=10&filter=importedByCounts.packages+%3E+1000'

get-package

Get metadata for a Go package (module, version, name, synopsis, latest flag, std flag), optionally at a specific version Params: path*, version, module

curl 'https://clify-dev.netlify.app/pkg-go/get-package?version=v1.7.0'

get-module

Get metadata for a Go module (latest or given version, commit time, repo URL, go.mod presence) Params: path*, version

curl 'https://clify-dev.netlify.app/pkg-go/get-module'

list-module-packages

List the packages contained in a Go module, with an optional filter (e.g. name == "main") Params: path*, version, filter, token

curl 'https://clify-dev.netlify.app/pkg-go/list-module-packages'

list-versions

List all versions of a Go module, with commit time, deprecation and retraction status Params: path*, filter, token

curl 'https://clify-dev.netlify.app/pkg-go/list-versions'

list-symbols

List exported symbols (types, funcs, methods, fields, consts, vars) of a Go package, optionally for a GOOS/GOARCH build context and filter Params: path*, version, GOOS, GOARCH, filter, token

curl 'https://clify-dev.netlify.app/pkg-go/list-symbols?GOOS=windows&GOARCH=amd64&filter=hasPrefix%28name%2C+%22Server%22%29'

list-importers

List import paths of packages that import a given Go package (excluding packages in the same module), paged by cursor Params: path*, filter, token

curl 'https://clify-dev.netlify.app/pkg-go/list-importers'

list-vulns

List known Go vulnerabilities (from the Go vuln DB) affecting a module at a given version (latest by default) Params: path*, version, token

curl 'https://clify-dev.netlify.app/pkg-go/list-vulns?version=v0.1.0'

get-package-doc

Fetch the rendered documentation page of a package (README, doc text, repo link), optionally at a version (path@version) and GOOS Params: path*, GOOS

curl 'https://clify-dev.netlify.app/pkg-go/get-package-doc'

list-std-packages

List the Go standard library packages with links and synopses Params: none

curl 'https://clify-dev.netlify.app/pkg-go/list-std-packages'

list-subrepos

List the official Go sub-repositories (golang.org/x/...) with short descriptions Params: none

curl 'https://clify-dev.netlify.app/pkg-go/list-subrepos'
