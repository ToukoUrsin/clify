rijksmuseum API for agents (unofficial) — JSON over curl | clify

Rijksmuseum online collection (rijksmuseum.nl): search artworks and library publications, browse facets, and look up artwork, person/topic node and publication details through the site's public JSON API.

Host: rijksmuseum.nl. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-collection

Search Rijksmuseum artworks by keyword with optional sort and up to two facet filters (object type, century, maker/person, ...); 20 results per page Params: query, sort, facet1_id, facet1_relation, facet2_id, facet2_relation, page

curl 'https://clify-dev.netlify.app/rijksmuseum/search-collection?query=rembrandt&sort=Popularity&facet1_id=3159edbfc6b22de59dfb2522fecc2706&facet1_relation=HasObjectType&facet2_id=7600f7d20164d7c752cf402c0b0762ad&facet2_relation=MadeInCentury&page=2'

search-library

Search Rijksmuseum library publications (books, articles) by keyword; 20 results per page Params: query*, sort, facet1_id, facet1_relation, page

curl 'https://clify-dev.netlify.app/rijksmuseum/search-library?query=Rachel+Ruysch'

autocomplete

Type-ahead suggestions for a search term: matching facet nodes (object types, places, people) and objects Params: query*, context, page_size

curl 'https://clify-dev.netlify.app/rijksmuseum/autocomplete'

list-search-facets

List the filter groups (Maker, Object type, Century, Place, ...) with facet ids, relation types and counts for a search query Params: query*, context, in_museum, has_image

curl 'https://clify-dev.netlify.app/rijksmuseum/list-search-facets'

search-facet-values

Search within one facet group (e.g. Object type, Maker, Place) for facet values matching text, scoped to a search query; returns facet ids and relation types for search-collection Params: query*, node_type*, facet_query*, relation_bin_id, context

curl 'https://clify-dev.netlify.app/rijksmuseum/search-facet-values'

get-artwork

Get full details of an artwork: title, maker, dating, dimensions, materials, description, location, image id and the full data tab Params: object_node_id*, language

curl 'https://clify-dev.netlify.app/rijksmuseum/get-artwork?object_node_id=7b8c9a4a2618f75528c6bcf8b813e9a6'

get-object-titles

Get an artwork's or publication's title in each available language (en, nl) Params: object_node_id*, domain

curl 'https://clify-dev.netlify.app/rijksmuseum/get-object-titles?object_node_id=7b8c9a4a2618f75528c6bcf8b813e9a6&domain=Art'

get-node

Get a collection node page (person/maker, object type, topic, place): its title, type and featured artworks such as most viewed and works through the years Params: node_id*, language

curl 'https://clify-dev.netlify.app/rijksmuseum/get-node?node_id=3159edbfc6b22de59dfb2522fecc2706'

get-facet-info

Resolve a facet/node id to its name and node type (e.g. Person 'Rachel Ruysch') Params: facet_id*, language

curl 'https://clify-dev.netlify.app/rijksmuseum/get-facet-info'

get-library-item

Get details of a Rijksmuseum library publication: title, type, authors and properties, ISBN, and a link to the library catalogue Params: object_node_id*, language

curl 'https://clify-dev.netlify.app/rijksmuseum/get-library-item?object_node_id=a2da6b4c23d5d0180354b7fd869e40f7'
