polymarket API for agents (unofficial) — JSON over curl

Polymarket prediction markets: search and list events and markets with live prices, volume, liquidity and end dates; price history, biggest movers, holders, comments, resolution status, and public trader profiles, positions and activity.

Host: polymarket.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-markets

Full-text search of prediction events and their markets (current Yes/No prices, volume); sort by volume, liquidity, ending soon or competitive; active or resolved. Params: query*, status, sort, page Read-only

curl 'https://clify-dev.netlify.app/polymarket/search-markets?query=bitcoin&sort=volume'

list-events

List events from the public Gamma API by category tag, ordered by volume or another field, with end dates, volume and liquidity; cursor paginated. Params: tag_slug, closed, order, ascending, api_limit, after_cursor Read-only

curl 'https://clify-dev.netlify.app/polymarket/list-events?tag_slug=sports'

get-event

Get one event by its slug (from /event/<slug> URLs) with all its markets: outcome prices, token ids, condition ids, volume, liquidity, end date. Params: slug* Read-only

curl 'https://clify-dev.netlify.app/polymarket/get-event?slug=what-price-will-bitcoin-hit-before-2027'

get-market

Get a single market by its market slug (second path segment of /event/<event>/<market>): outcomes, prices, CLOB token ids, condition id, end date, volume, liquidity. Params: slug* Read-only

curl 'https://clify-dev.netlify.app/polymarket/get-market?slug=will-anthropic-ipo-by-november-30-2026'

quick-search

Fast search returning matching events (with endDate, volume, volume24hr, liquidity and market prices), matching tags and trader profiles (name and proxyWallet address). Params: query* Read-only

curl 'https://clify-dev.netlify.app/polymarket/quick-search?query=bitcoin'

get-price-history

Price history (probability 0-1 over time) of one outcome token; token ids come from a market's clobTokenIds. Params: token_id*, interval, bucket_seconds Read-only

curl 'https://clify-dev.netlify.app/polymarket/get-price-history?token_id=93607174427076648497970085679890464224074212453553954883931612093962256690262&interval=max'

list-biggest-movers

Markets whose price moved the most in the last 24 hours (the Breaking page), optionally limited to one category. Params: category Read-only

curl 'https://clify-dev.netlify.app/polymarket/list-biggest-movers?category=crypto'

list-tags

Currently trending topic tags with their slugs and active event counts, for use as tag_slug in list-events. Params: none Read-only

curl 'https://clify-dev.netlify.app/polymarket/list-tags'

get-market-holders

Top holders of each outcome of a market, by condition id (conditionId from get-market or get-event). Params: condition*, api_limit Read-only

curl 'https://clify-dev.netlify.app/polymarket/get-market-holders?condition=0xa7d7ed69cfd6107e5e005556730dcf45727c1cdd1001f0378f5e471526181c47'

get-event-resolutions

On-chain (UMA) resolution status of every market in an event (posed, proposed, disputed, resolved) by numeric event id. Params: eventId* Read-only

curl 'https://clify-dev.netlify.app/polymarket/get-event-resolutions?eventId=89502'

list-related-events

Events related to a given event slug, with their markets, prices, volume and end dates. Params: slug* Read-only

curl 'https://clify-dev.netlify.app/polymarket/list-related-events?slug=what-price-will-bitcoin-hit-before-2027'

list-comments

Latest comments on an event or series, newest first. Params: parent_entity_type, parent_entity_id*, api_limit, offset Read-only

curl 'https://clify-dev.netlify.app/polymarket/list-comments?parent_entity_type=Event&parent_entity_id=549019'

get-trader-profile

Public trader profile (name, pseudonym, join date, tier) by proxy wallet address. Params: address* Read-only

curl 'https://clify-dev.netlify.app/polymarket/get-trader-profile?address=0xcdcccd0f2d86e450d973da415ad2430e5cc7935a'

get-trader-stats

A trader's all-time stats: trade count, biggest win, profit/loss, volume, profile views. Params: user* Read-only

curl 'https://clify-dev.netlify.app/polymarket/get-trader-stats?user=0xcdcccd0f2d86e450d973da415ad2430e5cc7935a'

list-trader-positions

A trader's open or closed positions with size, average price, current value and PnL. Params: user*, status, sort_by, sort_direction, filter_amount, api_limit Read-only

curl 'https://clify-dev.netlify.app/polymarket/list-trader-positions?user=0xcdcccd0f2d86e450d973da415ad2430e5cc7935a&status=CLOSED&sort_by=REALIZED_PNL'

list-trader-activity

A trader's recent on-chain activity (trades, redemptions, rebates), newest first. Params: user*, api_limit, start Read-only

curl 'https://clify-dev.netlify.app/polymarket/list-trader-activity?user=0xcdcccd0f2d86e450d973da415ad2430e5cc7935a'

get-trader-pnl

A trader's profit/loss time series over a window. Params: user*, interval, fidelity Read-only

curl 'https://clify-dev.netlify.app/polymarket/get-trader-pnl?user=0xcdcccd0f2d86e450d973da415ad2430e5cc7935a&interval=1w&fidelity=3h'
