cocoapods API for agents (unofficial) — JSON over curl | clify

CocoaPods.org is the public registry of Swift/Objective-C libraries (pods). This CLI searches pods by keyword through the site's Algolia index and reads pod detail pages, pod changelogs and owner profiles.

Host: cocoapods.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-pods

Search CocoaPods libraries by keyword. Returns name, version, summary, license, platforms, download counts and repo owner. Paginated, 20 per page. Params: query*, page, hits_per_page

curl 'https://clify-dev.netlify.app/cocoapods/search-pods'

get-pod

Get one pod's detail page: version, metadata table (tests, language, license, release, SPM), first maintainer, Podfile line, podspec/GitHub links and README text. Params: name*

curl 'https://clify-dev.netlify.app/cocoapods/get-pod'

get-pod-changelog

Get a pod's CHANGELOG as rendered text. Some pods only contain a link to their GitHub releases (see first_link). Params: name*

curl 'https://clify-dev.netlify.app/cocoapods/get-pod-changelog'

list-owner-pods

List all pods maintained by an owner (numeric owner id from get-pod's maintainer_url), with summary, license and language. Params: id*

curl 'https://clify-dev.netlify.app/cocoapods/list-owner-pods'
