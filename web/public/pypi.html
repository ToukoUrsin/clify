pypi API for agents (unofficial) — JSON over curl

PyPI (Python Package Index): look up Python packages and specific versions, read release, update and new-package RSS feeds, see top projects by size and index-wide totals, and fetch the GitHub repo stats and issues that PyPI project pages show.

Host: pypi.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

get-package

Get a package's PyPI page for its latest version: name and version, summary, pip install command, project links and metadata sidebar, and README text. Params: name* Read-only

curl 'https://clify-dev.netlify.app/pypi/get-package?name=requests'

get-package-version

Get the PyPI page for one specific version of a package: header, summary, pinned pip command, metadata sidebar and the README as it was at that release. Params: name*, version* Read-only

curl 'https://clify-dev.netlify.app/pypi/get-package-version?name=requests&version=2.31.0'

list-package-releases

List a package's recent releases (version, link, publish date) from its releases RSS feed. Params: name* Read-only

curl 'https://clify-dev.netlify.app/pypi/list-package-releases?name=requests'

list-latest-updates

List the newest releases uploaded across all of PyPI (package + version, link, date) from the site-wide updates RSS feed. Params: none Read-only

curl 'https://clify-dev.netlify.app/pypi/list-latest-updates'

list-newest-packages

List projects newly created on PyPI (name, link, summary, date) from the newest-packages RSS feed. Params: none Read-only

curl 'https://clify-dev.netlify.app/pypi/list-newest-packages'

list-top-projects-by-size

List the top 100 PyPI projects ranked by the total size of their release files. The first row is the total for all of PyPI. Params: none Read-only

curl 'https://clify-dev.netlify.app/pypi/list-top-projects-by-size'

get-index-totals

Get PyPI-wide totals shown on the homepage (number of projects, releases, files, users). Params: none Read-only

curl 'https://clify-dev.netlify.app/pypi/get-index-totals'

get-github-repo

Get the GitHub statistics PyPI shows for a project's source repo (stars, forks, open issues, description, last push), from the GitHub API. Params: owner*, repo* Read-only

curl 'https://clify-dev.netlify.app/pypi/get-github-repo?owner=psf&repo=requests'

search-github-issues

Search GitHub issues and PRs with a GitHub query, e.g. the open issues of a package's repo, via the GitHub search API (the same call PyPI uses to show open-issue counts). Params: q*, per_page, page Read-only

curl 'https://clify-dev.netlify.app/pypi/search-github-issues?q=repo%3Apsf%2Frequests+type%3Aissue+state%3Aopen&per_page=5'
