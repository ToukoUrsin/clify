packagist API for agents (unofficial) — JSON over curl

Packagist.org is the main PHP/Composer package repository. This CLI searches packages, faceted by tags and type, and reads package metadata, install and PHP-version statistics, dependents, suggesters, security advisories, vendor package lists, popular and new packages, PHP extensions and global stats.

Host: packagist.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-packages

Search Packagist packages by keyword, optionally filtered by package type and tags. Uses the official search.json API. Params: q*, type, tags, per_page, page Read-only

curl 'https://clify-dev.netlify.app/packagist/search-packages?q=logger&type=library&per_page=5'

search-packages-faceted

Search packages through the site's Algolia index. Returns hits plus facet counts per tag and type. Supports Algolia filter expressions; page is 0-based. Params: query*, filters, page, hits_per_page Read-only

curl 'https://clify-dev.netlify.app/packagist/search-packages-faceted'

search-facet-values

Search the values of a search facet (tags or type) by prefix, with counts within a keyword query. Useful for finding valid tag names to filter on. Params: facet*, facet_query*, query Read-only

curl 'https://clify-dev.netlify.app/packagist/search-facet-values'

get-package

Get full package metadata as JSON: description, maintainers, repository, download totals, favers, and all versions with their requirements. Params: vendor*, package* Read-only

curl 'https://clify-dev.netlify.app/packagist/get-package'

get-package-install-stats

Get a time series of daily installs for a package, averaged daily, weekly or monthly, starting from a date. Params: vendor*, package*, average, from Read-only

curl 'https://clify-dev.netlify.app/packagist/get-package-install-stats?average=weekly&from=2025-10-18'

get-package-major-version-stats

Get a time series of daily installs for a package, split by major version (1, 2, 3, ...). Params: vendor*, package*, average, from Read-only

curl 'https://clify-dev.netlify.app/packagist/get-package-major-version-stats?average=monthly&from=2012-04-13'

get-package-php-stats

Get a time series of installs for a package, split by the PHP version (and HHVM) used by installers. Params: vendor*, package*, average, from Read-only

curl 'https://clify-dev.netlify.app/packagist/get-package-php-stats?average=monthly&from=2021-05-18'

get-version-details

Get the rendered detail block for one package version by its numeric version id: version number, release date, and requires/suggests/provides/conflicts. Returned as an HTML fragment inside JSON. Params: id* Read-only

curl 'https://clify-dev.netlify.app/packagist/get-version-details'

list-dependents

List packages that depend on a given package. Can sort by downloads and filter by require or require-dev. Params: vendor*, package*, order_by, requires, page Read-only

curl 'https://clify-dev.netlify.app/packagist/list-dependents?order_by=downloads'

list-suggesters

List packages that suggest a given package in their composer.json 'suggest' section. Params: vendor*, package*, page Read-only

curl 'https://clify-dev.netlify.app/packagist/list-suggesters'

list-security-advisories

List known security advisories (PKSA id, CVE, affected versions, severity) for a package via the official API. Params: packages*, updatedSince Read-only

curl 'https://clify-dev.netlify.app/packagist/list-security-advisories?packages=monolog%2Fmonolog'

get-security-advisory

Get one security advisory by its PKSA id: severity, title, CVE/GHSA ids, affected package and versions, and reporting sources. Params: advisory_id* Read-only

curl 'https://clify-dev.netlify.app/packagist/get-security-advisory'

list-vendor-packages

List all package names published under a vendor, optionally filtered by package type. Params: vendor*, type Read-only

curl 'https://clify-dev.netlify.app/packagist/list-vendor-packages?vendor=monolog'

list-popular-packages

List the most popular packages on Packagist, paginated. Params: per_page, page Read-only

curl 'https://clify-dev.netlify.app/packagist/list-popular-packages?per_page=5'

browse-explore

Get the Browse page lists, in this order: New Releases (with version), New Packages, Popular Packages and Random Packages. Params: none Read-only

curl 'https://clify-dev.netlify.app/packagist/browse-explore'

list-php-extensions

List PHP extension packages that can be installed with PIE, paginated. Params: page Read-only

curl 'https://clify-dev.netlify.app/packagist/list-php-extensions'

get-global-statistics

Get Packagist-wide totals: packages registered, versions available, and total package installs since 2012. Params: none Read-only

curl 'https://clify-dev.netlify.app/packagist/get-global-statistics'
