rcsb API for agents (unofficial) — JSON over curl

RCSB Protein Data Bank (rcsb.org): search 3D macromolecular structures by keyword, attribute or 3D shape, and fetch entry chains, sequence annotations, UniProt alignments, version history, ligand definitions and coordinate/FASTA files.

Host: rcsb.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-structures

Full-text keyword search of PDB entries (e.g. 'hemoglobin'), with sorting and offset pagination; returns PDB IDs, titles, methods, organisms and ligands Params: query*, start, rows, sort_by, direction, content_type Read-only

curl 'https://clify-dev.netlify.app/rcsb/search-structures'

search-structures-filtered

Keyword search of PDB entries refined by one facet filter (source organism, experimental method, etc.), with sorting and pagination Params: query*, filter_attribute, filter_value*, start, rows, sort_by, direction Read-only

curl 'https://clify-dev.netlify.app/rcsb/search-structures-filtered'
