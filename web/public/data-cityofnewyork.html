data-cityofnewyork API for agents (unofficial) — JSON over curl | clify

NYC Open Data (Socrata catalog at data.cityofnewyork.us). The CLI searches the dataset catalog by keyword, tag, category and sort order; reads dataset metadata and columns; runs SoQL queries against rows; exports CSV; and lists change history and attachments. It needs no login.

Host: data.cityofnewyork.us. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-datasets

Search the NYC Open Data catalog by keyword, tag, category or asset type, with sorting and offset paging Params: q, tags, categories, only, order, api_limit, offset

curl 'https://clify-dev.netlify.app/data-cityofnewyork/search-datasets?q=restaurant&tags=food'

suggest-dataset-titles

Autocomplete dataset titles that match a partial keyword Params: q*, api_limit

curl 'https://clify-dev.netlify.app/data-cityofnewyork/suggest-dataset-titles?q=taxi'

list-catalog-facets

List the catalog's browse facets: domain categories and custom facets such as Data Collection, with their options Params: none

curl 'https://clify-dev.netlify.app/data-cityofnewyork/list-catalog-facets'

get-dataset

Get full metadata for a dataset by its 4x4 id: name, description, agency, category, view and download counts, update times and column definitions Params: id*

curl 'https://clify-dev.netlify.app/data-cityofnewyork/get-dataset'

query-dataset

Run a SoQL query against a dataset's rows: select, filter, aggregate, count, or page with LIMIT/OFFSET Params: id*, query*

curl 'https://clify-dev.netlify.app/data-cityofnewyork/query-dataset'

export-dataset-csv

Download the entire dataset as CSV text (this can be very large for big datasets) Params: id*

curl 'https://clify-dev.netlify.app/data-cityofnewyork/export-dataset-csv'

list-dataset-changes

List a dataset's update/version history (archive entries with version number and timestamp), using cursor paging Params: id*, api_limit, cursor

curl 'https://clify-dev.netlify.app/data-cityofnewyork/list-dataset-changes'

list-dataset-attachments

List the file ids of a dataset's attachments (data dictionaries, user guides) with their scan state Params: id*

curl 'https://clify-dev.netlify.app/data-cityofnewyork/list-dataset-attachments'
