worldcubeassociation API for agents (unofficial) — JSON over curl

World Cube Association (speedcubing) public data: search competitions and fetch their results, scrambles, schedules (WCIF) and competitors; look up competitors' profiles, personal records and results; get current world, continental and national records and news posts. All of it comes from the WCA's public /api/v0 JSON API.

Host: worldcubeassociation.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-competitions

Search WCA competitions like the /competitions page: keyword, event, country and date filters, sorted and paginated with 25 per page Params: q, event, country_iso2, ongoing_and_future, include_cancelled, sort, page Read-only

curl 'https://clify-dev.netlify.app/worldcubeassociation/search-competitions?q=Open&event=333bf&country_iso2=ES&ongoing_and_future=2026-10-18&sort=start_date%2Cend_date%2Cname'

list-competitions

List competitions through the public API, filtered by country and a start/end date range, with sort and pagination Params: country_iso2, start, end, sort, page Read-only

curl 'https://clify-dev.netlify.app/worldcubeassociation/list-competitions?country_iso2=ES&start=2025-01-01&end=2025-12-31&sort=-start_date'

get-competition

Get one competition's details: dates, venue, registration settings, fees and information Params: competition_id* Read-only

curl 'https://clify-dev.netlify.app/worldcubeassociation/get-competition'

get-competition-results

Get a competition's results for one event, round by round, with each competitor's position, best, average and attempts Params: competition_id*, event_id* Read-only

curl 'https://clify-dev.netlify.app/worldcubeassociation/get-competition-results'

get-competition-scrambles

Get the official scrambles a competition used for one event, grouped by round Params: competition_id*, event_id* Read-only

curl 'https://clify-dev.netlify.app/worldcubeassociation/get-competition-scrambles'

get-competition-wcif

Get a competition's public WCIF: events, rounds, formats, time limits, cutoffs, schedule/venues and registered persons with their assignments Params: competition_id* Read-only

curl 'https://clify-dev.netlify.app/worldcubeassociation/get-competition-wcif'

list-competition-competitors

List the people who competed in or are registered for a competition Params: competition_id* Read-only

curl 'https://clify-dev.netlify.app/worldcubeassociation/list-competition-competitors'

search-persons

Search WCA competitors by name or WCA id; each result includes competition count and personal records with ranks Params: q*, page Read-only

curl 'https://clify-dev.netlify.app/worldcubeassociation/search-persons?q=Feliks'

get-person

Get a competitor's profile by WCA id: country, delegate status, teams, competition count and personal records (single/average with world, continent and country ranks) Params: wca_id* Read-only

curl 'https://clify-dev.netlify.app/worldcubeassociation/get-person'

get-person-results

List every result a competitor has, one row per round: competition, event, round, position, best, average, attempts Params: wca_id* Read-only

curl 'https://clify-dev.netlify.app/worldcubeassociation/get-person-results'

get-person-competitions

List the competitions a competitor has attended Params: wca_id* Read-only

curl 'https://clify-dev.netlify.app/worldcubeassociation/get-person-competitions'

get-records

Get current world, continental and national records (single and average) for every event Params: none Read-only

curl 'https://clify-dev.netlify.app/worldcubeassociation/get-records'

search-site

Site-wide search (the navbar omnisearch) that returns matching people and competitions Params: q* Read-only

curl 'https://clify-dev.netlify.app/worldcubeassociation/search-site?q=Feliks'

list-posts

List WCA news and announcement posts, newest first, 10 per page Params: page Read-only

curl 'https://clify-dev.netlify.app/worldcubeassociation/list-posts?page=1'
