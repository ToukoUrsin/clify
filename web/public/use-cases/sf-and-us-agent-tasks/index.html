San Francisco and U.S. web data for AI agents

Find SF events, startup jobs, transit departures, local news, listings, public datasets and prediction markets as verified JSON commands.

Start with practical U.S. tasks that normally force an agent into browser scraping: browse Luma and Eventbrite events, search YC startup jobs, check BART and Muni departures, find Craigslist listings, or read local reporting. Every linked source has commands verified against its public site.
