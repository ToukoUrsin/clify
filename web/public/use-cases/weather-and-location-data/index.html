Weather and location data APIs for AI agents

Query forecasts, alerts, observations, geocoding, maps and open location data through JSON endpoints for AI agents.

Start with a location or forecast task, then follow the linked command docs. These are public read endpoints and examples are generated from verified site specs.

Verified sources

weather

weather.gov

National Weather Service (weather.gov / api.weather.gov): look up US forecasts by lat/lon or NWS grid point, active alerts, weather stations and their latest observations, forecast-office text products (e.g. Area Forecast Discussions), zone boundary KML, DWML forecast export, and weather glossary terms.

Machine-readable commands · 11 verified commands

open-meteo

open-meteo.com

Open-Meteo: free, keyless weather APIs. The CLI provides forecasts, historical reanalysis, archived and previous model runs, ensembles, seasonal and climate projections, marine, air quality, satellite radiation, flood, elevation, geocoding and CSV export.

Machine-readable commands · 16 verified commands

yr

yr.no

yr.no (Norwegian Meteorological Institute / NRK weather service): search places and get forecasts, current weather, nowcasts, long-range, coastal/tide/water-level, air quality, aurora, sun/moon, observation history, warnings, mountain pass conditions and meteorologist posts via yr.no's public /api/v0 JSON API.

Machine-readable commands · 24 verified commands

smhi

smhi.se

SMHI (Swedish Meteorological and Hydrological Institute): look up places, get current weather, 10-day forecasts and recent observed weather, see active weather warnings, search SMHI's open-data catalog, download station observations from the open metobs API, and search or read knowledge-bank and news articles.

Machine-readable commands · 16 verified commands

nominatim-openstreetmap

nominatim.openstreetmap.org

Nominatim (OpenStreetMap geocoder): search places by free text or structured address, reverse-geocode coordinates, fetch full place details by OSM id, and check server/data status.

Machine-readable commands · 5 verified commands

geonames

geonames.org

GeoNames (geonames.org) is an open world gazetteer with about 13M places. This CLI searches places and postal codes and reads place details, edit history, metro areas, the admin hierarchy (geotree), country data, largest cities, highest mountains, admin divisions, feature statistics, recent edits and site totals.

Machine-readable commands · 19 verified commands

earthquake-usgs

earthquake.usgs.gov

USGS Earthquake Hazards Program (Latest Earthquakes map). This CLI queries real-time earthquake feeds, the ComCat FDSN event search and count APIs, event details with products such as PAGER, ShakeMap and aftershock forecasts, geoserve nearby-place and region lookups, and catalog/contributor metadata.
