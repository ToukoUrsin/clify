Open government data APIs for AI agents

Search public datasets, regulations, procurement notices, grants, statistics and official records with JSON commands.

For public-sector research, start with a catalogue or search command and follow its result identifiers into detail commands. Each linked page documents the source and its public endpoint.

Verified sources

data-gov

data.gov.uk

data.gov.uk (National Data Library): the UK government's open data directory. The CLI searches and reads dataset metadata through the public CKAN JSON API, lists data files and previews from dataset pages, and browses the curated theme collections and their chart data.

data-cdc

data.cdc.gov

data.cdc.gov is the CDC's open-data portal (Socrata). This CLI searches the dataset catalog, lists categories and tags, reads dataset metadata, and queries or exports dataset rows through the public Socrata Discovery, SODA and views APIs.

Machine-readable commands · 10 verified commands

data-cityofnewyork

data.cityofnewyork.us

NYC Open Data (Socrata catalog at data.cityofnewyork.us). The CLI searches the dataset catalog by keyword, tag, category and sort order; reads dataset metadata and columns; runs SoQL queries against rows; exports CSV; and lists change history and attachments. It needs no login.

data-europa

data.europa.eu

data.europa.eu (the official EU open data portal): search EU and national open datasets, catalogues and data services, read dataset and catalogue metadata, find similar datasets, and export DCAT metadata.

Machine-readable commands · 10 verified commands

data-norge

data.norge.no

data.norge.no (Felles datakatalog) is Norway's national data portal. This CLI searches and looks up datasets, APIs (data services), concepts, information models, public services/events and publishing organizations through the portal's public JSON APIs.

data-police

data.police.uk

data.police.uk is the UK's open police data API. This CLI covers forces and senior officers, street-level crimes and outcomes, neighbourhood teams, events and priorities, stop and search records, data availability dates, and the custom CSV download form.

finlex

finlex.fi

Finlex, the Finnish government's free legal database (statutes, Statute Book, translations and Supreme Court case law). This CLI searches all datasets, lists Statute Book entries and Supreme Court precedents, and fetches statute, translation and precedent detail pages and translation PDFs.

Machine-readable commands · 7 verified commands

federalregister

federalregister.gov

Federal Register (federalregister.gov): search and read U.S. federal rules, proposed rules, notices and presidential documents, agencies, public inspection filings and topic searches through the official public JSON API.

grants

grants.gov

Grants.gov / Simpler.Grants.gov: US federal grant opportunities. The CLI searches and exports funding opportunities, gets opportunity details from the classic Grants.gov web service, looks up agencies, searches site content, reads CMS pages, and lists the daily XML database extracts and RSS feeds.

hankintailmoitukset

hankintailmoitukset.fi

Hilma (hankintailmoitukset.fi) is Finland's public procurement notice service. This CLI searches tender notices and procurement plans, fetches notice, procedure and plan details, browses CPV and NUTS codes, and reads statistics and Hilma announcements.

ons

ons.gov.uk

Office for National Statistics (ons.gov.uk), the UK's official statistics site. This CLI searches publications and data, reads time series values and metadata, bulletins, datasets and the release calendar, and downloads CSV data. It is read-only and needs no login.

Machine-readable commands · 15 verified commands

usaspending

usaspending.gov

USAspending.gov is the official U.S. federal spending database. This CLI calls its public API (api.usaspending.gov, no auth needed) to search awards and transactions, open award, recipient, agency, state and federal-account profiles, break spending down by category, and request bulk downloads.
