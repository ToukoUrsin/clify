Developer and package registry APIs for AI agents

Search package registries, documentation, releases, dependencies and developer resources with JSON commands for AI agents.

Use these pages when an agent needs package metadata or developer documentation. Commands expose the public read APIs behind familiar registry and documentation sites.

Verified sources

crates

crates.io

crates.io, the Rust package registry. This CLI searches crates and reads crate, version, dependency, download, owner, readme, source-file, advisory, docs.rs, user, team, category and keyword data through the public /api/v1 API.

Machine-readable commands · 19 verified commands

pypi

pypi.org

PyPI (Python Package Index): look up Python packages and specific versions, read release, update and new-package RSS feeds, see top projects by size and index-wide totals, and fetch the GitHub repo stats and issues that PyPI project pages show.

Machine-readable commands · 9 verified commands

devdocs

devdocs.io

DevDocs (devdocs.io) is a single site that bundles many API documentation sets. This CLI lists the available docs, fetches a doc's index of entries and categories, and retrieves documentation pages or full offline bundles as static JSON or HTML from documents.devdocs.io.

Machine-readable commands · 6 verified commands

developer-mozilla

developer.mozilla.org

MDN Web Docs (developer.mozilla.org) is Mozilla's web developer documentation. This CLI searches the docs, fetches any doc page as structured JSON, lists every doc title/URL for a locale, and looks up browser compatibility data.

Machine-readable commands · 4 verified commands

docs-python

docs.python.org

Official Python documentation (docs.python.org, a static Sphinx site). The CLI fetches the glossary as JSON, the module index, the general index by letter, tables of contents, What's New highlights, doc pages, the API entries on a page, and documentation downloads, for any docs version.

Machine-readable commands · 8 verified commands

docs-rs

docs.rs

docs.rs is the documentation host for Rust crates. This CLI searches crates, resolves the best match, reads crate pages (build status, builds, features, versions, source files), reads rustdoc pages and item lists, and browses release listings, failures, the build queue and the Atom feed.

Machine-readable commands · 16 verified commands

registry-terraform

registry.terraform.io

Terraform Registry (registry.terraform.io): search and browse Terraform providers, modules, provider docs, policy libraries and run tasks, and fetch details, versions, download stats and provider binaries through the registry's public v1/v2 JSON APIs and its Algolia search index.

Machine-readable commands · 21 verified commands

hub-docker

hub.docker.com

Docker Hub (hub.docker.com), the public container image registry. This CLI searches images by category, lists tags and image layers, reads repository, publisher and organization info, browses the Docker MCP server catalog, and fetches Docker Scout vulnerability summaries.

Machine-readable commands · 13 verified commands

huggingface

huggingface.co

Hugging Face Hub (huggingface.co): search and inspect public models, datasets, Spaces and organizations, read model/dataset metadata, file listings, security scans and dataset statistics, without logging in.
