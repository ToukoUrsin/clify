doaj API for agents (unofficial) — JSON over curl

DOAJ (Directory of Open Access Journals): search and look up open-access journals and articles through DOAJ's public v4 API, OAI-PMH endpoint and Atom feed.

Host: doaj.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-journals

Search DOAJ journals by keyword or Elasticsearch/Lucene query, e.g. bibjson.publisher.country:IR AND bibjson.apc.has_apc:false Params: query*, page, pageSize, sort Read-only

curl 'https://clify-dev.netlify.app/doaj/search-journals?sort=created_date%3Adesc'

get-journal-by-issn

Look up a DOAJ journal by its print or electronic ISSN Params: issn* Read-only

curl 'https://clify-dev.netlify.app/doaj/get-journal-by-issn'

get-journal

Get the full metadata of a DOAJ journal (APC, license, editorial policy, subjects, links) by its DOAJ id Params: id* Read-only

curl 'https://clify-dev.netlify.app/doaj/get-journal'

search-articles

Search DOAJ articles by keyword or Lucene query, e.g. bibjson.year:2021 AND herring Params: query*, page, pageSize, sort Read-only

curl 'https://clify-dev.netlify.app/doaj/search-articles?sort=created_date%3Adesc'

get-article-by-doi

Look up a DOAJ article by its DOI Params: doi* Read-only

curl 'https://clify-dev.netlify.app/doaj/get-article-by-doi'

get-article

Get the full metadata of a DOAJ article (authors, abstract, journal, links) by its DOAJ id Params: id* Read-only

curl 'https://clify-dev.netlify.app/doaj/get-article'

list-recent-journals

List journals recently added to DOAJ (Atom feed) Params: none Read-only

curl 'https://clify-dev.netlify.app/doaj/list-recent-journals'

list-subject-sets

List the LCC subject sets available in DOAJ's OAI-PMH endpoint (setSpec feeds list-journals-in-subject) Params: none Read-only

curl 'https://clify-dev.netlify.app/doaj/list-subject-sets'
