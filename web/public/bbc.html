bbc API for agents (unofficial) — JSON over curl | clify

BBC (www.bbc.com): read BBC News and Sport from the command line. Covers article, video and live-blog details, section, region and topic listings, live pages, football scores, fixtures, tables and team lookup, the BBC News TV schedule, JSON page content and video media streams.

Host: bbc.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

list-section-news

List the latest stories (articles, videos, live pages) on a top-level BBC section page such as news, sport, business or technology. Params: section*

curl 'https://clify-dev.netlify.app/bbc/list-section-news'

list-subsection-news

List the latest stories on a BBC sub-section page, e.g. technology/artificial-intelligence. Params: section*, subsection*

curl 'https://clify-dev.netlify.app/bbc/list-subsection-news'

list-region-news

List the latest BBC News stories for a world region (Europe, Asia, Africa, ...). Params: region*

curl 'https://clify-dev.netlify.app/bbc/list-region-news'

list-topic-articles

List stories tagged with a BBC News topic (e.g. France), paginated. Params: topicId*, page

curl 'https://clify-dev.netlify.app/bbc/list-topic-articles?page=2'

get-article

Get a BBC News article's metadata: headline, description, author, publish/modify dates, image. Params: id*

curl 'https://clify-dev.netlify.app/bbc/get-article'

get-video

Get a BBC News video page: title, description, publish time and related video links. Params: id*

curl 'https://clify-dev.netlify.app/bbc/get-video'

get-live-blog

Get a BBC live blog page: title, description and latest update time. Params: id*

curl 'https://clify-dev.netlify.app/bbc/get-live-blog'

list-live-pages

List the BBC live blogs currently running (news and sport), from the /live index. Params: none

curl 'https://clify-dev.netlify.app/bbc/list-live-pages'

list-football-scores

List football matches (scores and fixtures, all competitions) on a given date. Params: date*

curl 'https://clify-dev.netlify.app/bbc/list-football-scores'

list-team-fixtures

List a football team's recent results and upcoming fixtures. Params: team*

curl 'https://clify-dev.netlify.app/bbc/list-team-fixtures'

get-league-table

Get the current standings table for a football competition. Params: competition*

curl 'https://clify-dev.netlify.app/bbc/get-league-table'

search-football-teams

Find football teams and competitions by name. Returns BBC URNs and scores-fixtures URLs (the team slug is in the URL). Params: q*

curl 'https://clify-dev.netlify.app/bbc/search-football-teams?q=Arsenal'

list-tv-schedule

List the BBC News TV channel programme schedule (titles, synopses, start times) for a country feed. Params: country

curl 'https://clify-dev.netlify.app/bbc/list-tv-schedule?country=us'

get-page-content

Get structured JSON content for a BBC page path (e.g. a /reel/video/{id}/watch video): title, summary, publish times, metadata. Params: path*

curl 'https://clify-dev.netlify.app/bbc/get-page-content?path=%2Freel%2Fvideo%2Fp0p7tc6s%2Fwatch'

get-media-streams

Resolve a BBC media PID into playable stream URLs (HLS video renditions and thumbnails). Params: pid*

curl 'https://clify-dev.netlify.app/bbc/get-media-streams'
