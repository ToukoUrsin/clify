sfstandard API for agents (unofficial) — JSON over curl

The San Francisco Standard (sfstandard.com), a San Francisco local news site. This CLI searches articles and lists the latest, tag, section, topic-series and author stories with dates and URLs, and reads full articles.

Host: sfstandard.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-articles

Keyword search across all SF Standard articles (tech, housing, transit, city news). Returns headline, date and URL; sort by relevance or newest, filter by date range, section or author. Params: query*, sortBy, dateRange, sectionId, authorId, pageSize, page Read-only

curl 'https://clify-dev.netlify.app/sfstandard/search-articles?query=housing&dateRange=%221m%22'

list-latest-articles

Newest articles across the whole site (the Latest feed), newest first, with dates and URLs. Params: api_limit Read-only

curl 'https://clify-dev.netlify.app/sfstandard/list-latest-articles?api_limit=10'

list-tag-articles

Latest articles for a topic tag such as tech, transportation, criminal-justice or housing, with dates and URLs. Params: slug* Read-only

curl 'https://clify-dev.netlify.app/sfstandard/list-tag-articles?slug=tech'

get-article

Full article by its URL parts (/YYYY/MM/DD/slug/): headline, description, publish date, authors, section, keywords and full body text. Params: year*, month*, day*, slug* Read-only

curl 'https://clify-dev.netlify.app/sfstandard/get-article?year=2026&month=10&day=20&slug=mall-data-center-sf-downtown'

list-section-articles

Top and recent stories on a section front page such as news or business, with dates and URLs. Params: section* Read-only

curl 'https://clify-dev.netlify.app/sfstandard/list-section-articles?section=news'

list-obsession-articles

Articles in a topic series ("obsession") such as real-estate, boom-loop, crisis-in-streets, artificial-intelligence or school-wars. Params: slug* Read-only

curl 'https://clify-dev.netlify.app/sfstandard/list-obsession-articles?slug=real-estate'

list-author-articles

Recent articles by one reporter, looked up by author slug. Params: slug* Read-only

curl 'https://clify-dev.netlify.app/sfstandard/list-author-articles?slug=garrett-leahy'

get-article-comments-info

Comment status and counts for an article, looked up by its article id (the id field in search and list results). Params: storyId* Read-only

curl 'https://clify-dev.netlify.app/sfstandard/get-article-comments-info?storyId=b50c25ea-6978-4436-8dbb-63c828decda0'
