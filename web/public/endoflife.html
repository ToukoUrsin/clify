endoflife API for agents (unofficial) — JSON over curl

endoflife.date is a public catalog of end-of-life dates and support lifecycles for software products. This CLI wraps its public JSON API v1 and Atom feeds to list products, categories, tags and identifiers, and to look up release cycles and EOL dates.

Host: endoflife.date. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

list-products

List all tracked products (slug, label, category, tags, aliases) Params: none Read-only

curl 'https://clify-dev.netlify.app/endoflife/list-products'

export-products-full

Dump all products with full details including every release cycle (large response) Params: none Read-only

curl 'https://clify-dev.netlify.app/endoflife/export-products-full'

get-product

Get a product's metadata: label, category, tags, aliases, identifiers, version command, links Params: product* Read-only

curl 'https://clify-dev.netlify.app/endoflife/get-product?product=python'

list-releases

List all release cycles of a product with release, LTS, end-of-active-support and EOL dates Params: product* Read-only

curl 'https://clify-dev.netlify.app/endoflife/list-releases?product=python'

get-latest-release

Get the latest release cycle of a product with its support and EOL dates Params: product* Read-only

curl 'https://clify-dev.netlify.app/endoflife/get-latest-release?product=nodejs'

get-release

Get one release cycle of a product (e.g. python 3.12) with its support and EOL status and dates Params: product*, release* Read-only

curl 'https://clify-dev.netlify.app/endoflife/get-release?product=python&release=3.12'

list-categories

List product categories (e.g. framework, server-app, database, lang, os, service) Params: none Read-only

curl 'https://clify-dev.netlify.app/endoflife/list-categories'

list-products-by-category

List products in a category Params: category* Read-only

curl 'https://clify-dev.netlify.app/endoflife/list-products-by-category?category=database'

list-tags

List all product tags (e.g. amazon, linux-distribution, java-distribution) Params: none Read-only

curl 'https://clify-dev.netlify.app/endoflife/list-tags'

list-products-by-tag

List products that have a given tag Params: tag* Read-only

curl 'https://clify-dev.netlify.app/endoflife/list-products-by-tag?tag=amazon'

list-identifier-types

List supported product identifier types (purl, cpe, ...) Params: none Read-only

curl 'https://clify-dev.netlify.app/endoflife/list-identifier-types'

list-identifiers

List all identifiers of a given type (e.g. CPE or purl strings) mapped to product slugs; use it to resolve a CPE/purl to a product Params: type* Read-only

curl 'https://clify-dev.netlify.app/endoflife/list-identifiers?type=cpe'

list-new-products

Recently added products, newest first (Atom feed) Params: none Read-only

curl 'https://clify-dev.netlify.app/endoflife/list-new-products'

Timeline of a product's release and end-of-life events (Atom feed) Params: product* Read-only
