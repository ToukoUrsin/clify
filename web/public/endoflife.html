endoflife API for agents (unofficial) — JSON over curl | clify

endoflife.date is a public catalog of end-of-life dates and support lifecycles for software products. This CLI wraps its public JSON API v1 and Atom feeds to list products, categories, tags and identifiers, and to look up release cycles and EOL dates.

Host: endoflife.date. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

list-products

List all tracked products (slug, label, category, tags, aliases) Params: none

curl 'https://clify-dev.netlify.app/endoflife/list-products'

export-products-full

Dump all products with full details including every release cycle (large response) Params: none

curl 'https://clify-dev.netlify.app/endoflife/export-products-full'

get-product

Get a product's metadata: label, category, tags, aliases, identifiers, version command, links Params: product*

curl 'https://clify-dev.netlify.app/endoflife/get-product'

list-releases

List all release cycles of a product with release, LTS, end-of-active-support and EOL dates Params: product*

curl 'https://clify-dev.netlify.app/endoflife/list-releases'

get-latest-release

Get the latest release cycle of a product with its support and EOL dates Params: product*

curl 'https://clify-dev.netlify.app/endoflife/get-latest-release'

get-release

Get one release cycle of a product (e.g. python 3.12) with its support and EOL status and dates Params: product*, release*

curl 'https://clify-dev.netlify.app/endoflife/get-release'

list-categories

List product categories (e.g. framework, server-app, database, lang, os, service) Params: none

curl 'https://clify-dev.netlify.app/endoflife/list-categories'

list-products-by-category

List products in a category Params: category*

curl 'https://clify-dev.netlify.app/endoflife/list-products-by-category'

list-tags

List all product tags (e.g. amazon, linux-distribution, java-distribution) Params: none

curl 'https://clify-dev.netlify.app/endoflife/list-tags'

list-products-by-tag

List products that have a given tag Params: tag*

curl 'https://clify-dev.netlify.app/endoflife/list-products-by-tag'

list-identifier-types

List supported product identifier types (purl, cpe, ...) Params: none

curl 'https://clify-dev.netlify.app/endoflife/list-identifier-types'

list-identifiers

List all identifiers of a given type (e.g. CPE or purl strings) mapped to product slugs; use it to resolve a CPE/purl to a product Params: type*

curl 'https://clify-dev.netlify.app/endoflife/list-identifiers'

list-new-products

Recently added products, newest first (Atom feed) Params: none

curl 'https://clify-dev.netlify.app/endoflife/list-new-products'

list-product-events

Timeline of a product's release and end-of-life events (Atom feed) Params: product*

curl 'https://clify-dev.netlify.app/endoflife/list-product-events'
