usajobs API for agents (unofficial) — JSON over curl | clify

USAJOBS (usajobs.gov), the U.S. federal government's job board. The CLI searches federal job announcements with filters, sorting and pagination, fetches job details, suggests keywords and locations, lists recruiting events, and saves jobs for signed-in users.

Host: usajobs.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

get-job

Get one job announcement's details (title, agency, salary, location, dates, description, duties, qualifications) by its numeric announcement id Params: id*

curl 'https://clify-dev.netlify.app/usajobs/get-job'

suggest-keywords

Get keyword or job-title suggestions for a partial search term Params: term*, size

curl 'https://clify-dev.netlify.app/usajobs/suggest-keywords?term=nurse'

suggest-locations

Get location name suggestions for a partial place name, to use as search-jobs --location Params: term*, size

curl 'https://clify-dev.netlify.app/usajobs/suggest-locations?term=Denver'

list-events

List federal recruiting events (career fairs, webinars, info sessions), optionally only online events Params: online

curl 'https://clify-dev.netlify.app/usajobs/list-events?online=true'

get-event

Get a recruiting event's details (date, time, venue, address, website, description, host) by event id Params: id*

curl 'https://clify-dev.netlify.app/usajobs/get-event'

list-event-jobs

List the job announcements linked to a recruiting event Params: id*

curl 'https://clify-dev.netlify.app/usajobs/list-event-jobs'
