ecb-europa API for agents (unofficial) — JSON over curl | clify

ECB Data Portal (data.ecb.europa.eu): search European Central Bank statistical series (HICP inflation, exchange rates, SPF forecasts and more), fetch a series' observations as JSON, and pull raw data from the public ECB SDMX REST API.

Host: data.ecb.europa.eu. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

get-series-observations

Get the observations (period, value, unit, trend, status) of one ECB series by its full series key, e.g. HICP.M.U2.N.SERV00.4D0.ANR Params: series_key*

curl 'https://clify-dev.netlify.app/ecb-europa/get-series-observations'

search-series

Keyword search for ECB data series, optionally filtered by concept tag; returns links to series detail pages that contain the series keys Params: searchTerm*, layerType, tag, page

curl 'https://clify-dev.netlify.app/ecb-europa/search-series?searchTerm=inflation&layerType=KL&tag=Services'

get-sdmx-data

Download series data as CSV from the public ECB SDMX REST API (data-api.ecb.europa.eu); supports wildcard keys and period filters Params: dataset*, key*, startPeriod, endPeriod, lastNObservations, detail

curl 'https://clify-dev.netlify.app/ecb-europa/get-sdmx-data?startPeriod=2025-01'

list-dataflows

List all ECB dataflows (dataset ids, names and their data structure ids) from the SDMX REST API Params: none

curl 'https://clify-dev.netlify.app/ecb-europa/list-dataflows'

get-data-structure

Get the SDMX data structure definition (dimensions, concepts and code lists) for a dataset, e.g. ECB_EXR1 for EXR Params: dsd_id*

curl 'https://clify-dev.netlify.app/ecb-europa/get-data-structure'
