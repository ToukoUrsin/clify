usaspending API for agents (unofficial) — JSON over curl | clify

USAspending.gov is the official U.S. federal spending database. This CLI calls its public API (api.usaspending.gov, no auth needed) to search awards and transactions, open award, recipient, agency, state and federal-account profiles, break spending down by category, and request bulk downloads.

Host: usaspending.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.
