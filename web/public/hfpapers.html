hfpapers API for agents (unofficial) — JSON over curl

Hugging Face Papers (huggingface.co/papers): search AI research papers by topic, browse daily, weekly, monthly and trending paper lists, and get paper details (authors, abstract, AI summary, GitHub and project links, linked models and spaces) or the full text as markdown.

Host: huggingface.co. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-papers

Search Hugging Face papers by topic or keywords; returns title, authors, abstract, AI summary, keywords, GitHub repo, upvotes and publish date. Params: q*, api_limit Read-only

curl 'https://clify-dev.netlify.app/hfpapers/search-papers?q=reinforcement+learning+agents&api_limit=10'

list-daily-papers

List curated Daily Papers. Use date for one day, week for a week or month for a month; sort=trending ranks by trend. Pages with p. Params: date, week, month, sort, api_limit, p Read-only

curl 'https://clify-dev.netlify.app/hfpapers/list-daily-papers?date=2026-10-20&week=2026-W43&month=2026-10&sort=trending&api_limit=20&p=1'

list-papers

List recent papers from the papers index, optionally filtered by a keyword query; returns id, title, authors, abstract, upvotes and publish date. Params: q, api_limit Read-only

curl 'https://clify-dev.netlify.app/hfpapers/list-papers?q=multimodal+agents&api_limit=10'

get-paper

Get one paper by arXiv id: title, authors, abstract, AI summary and keywords, project page, GitHub repo and stars, organization, and linked models, datasets and spaces. Params: paperId* Read-only

curl 'https://clify-dev.netlify.app/hfpapers/get-paper?paperId=2511.03276'

get-paper-markdown

Get the full text of a paper as markdown (title, authors, abstract, body), by arXiv id. Params: paperId* Read-only

curl 'https://clify-dev.netlify.app/hfpapers/get-paper-markdown?paperId=2512.22234'

list-trending-papers

List currently trending papers with title, short summary, organization, publish date, upvotes, and GitHub and arXiv links. Params: none Read-only

curl 'https://clify-dev.netlify.app/hfpapers/list-trending-papers'
