sfmta API for agents (unofficial) — JSON over curl

SFMTA (San Francisco Muni): look up routes, stops, real-time arrival predictions, vehicle locations, trip updates, service alerts and stop relocations through the JSON APIs behind sfmta.com.

Host: sfmta.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

list-routes

List all Muni routes from the GTFS feed: route id, number, name, hours description and color. Params: none Read-only

curl 'https://clify-dev.netlify.app/sfmta/list-routes'

list-muni-alerts

List recent Muni service alerts (delays, reroutes, all-clears) with publish time and affected route tags. Params: none Read-only

curl 'https://clify-dev.netlify.app/sfmta/list-muni-alerts'

get-stop-predictions

Real-time arrival predictions (minutes, vehicle, direction, occupancy) for every route serving a stop, by public 5-digit stop code. Params: stopCode* Read-only

curl 'https://clify-dev.netlify.app/sfmta/get-stop-predictions?stopCode=17954'

get-route-vehicles

Live vehicle positions on a route: vehicle id, direction, lat/lon, speed, occupancy and time since last report. Params: routeId* Read-only

curl 'https://clify-dev.netlify.app/sfmta/get-route-vehicles?routeId=38'

get-route

Get GTFS details of one route: number, name, service hours description, type, color and links. Params: routeId* Read-only

curl 'https://clify-dev.netlify.app/sfmta/get-route?routeId=22'

get-route-stops

List all stops served by a route with stop id, public stop code, name and coordinates. Params: routeId* Read-only

curl 'https://clify-dev.netlify.app/sfmta/get-route-stops?routeId=22'

get-route-directions

Route configuration with its directions (inbound/outbound names and ordered stop ids) and all stops with codes and coordinates. Params: routeId* Read-only

curl 'https://clify-dev.netlify.app/sfmta/get-route-directions?routeId=38R'

find-stop

Look up a stop by public stop code: title, sfmta.com page URL, location, internal stop id and the routes serving it with their direction names. Params: stopCode* Read-only

curl 'https://clify-dev.netlify.app/sfmta/find-stop?stopCode=17954'

get-stop

Get GTFS details of a stop by internal stop id (stop code without the leading 1): name, code, coordinates, wheelchair boarding. Params: stopId* Read-only

curl 'https://clify-dev.netlify.app/sfmta/get-stop?stopId=7954'

get-stop-routes

List the routes that serve a stop (by internal stop id), with route names and service hours. Params: stopId* Read-only

curl 'https://clify-dev.netlify.app/sfmta/get-stop-routes?stopId=7954'

get-trip-updates

GTFS-realtime trip updates (vehicle, headsign, per-stop predicted arrival times and delays in seconds) for a public stop code or a route id. Params: id* Read-only

curl 'https://clify-dev.netlify.app/sfmta/get-trip-updates?id=17954'

get-route-alerts

Active GTFS-realtime service alerts affecting a route (empty list when none). Params: routeId* Read-only

curl 'https://clify-dev.netlify.app/sfmta/get-route-alerts?routeId=14'

get-stop-alerts

Active GTFS-realtime service alerts affecting a stop, by public stop code (empty list when none). Params: stopCode* Read-only

curl 'https://clify-dev.netlify.app/sfmta/get-stop-alerts?stopCode=15623'

get-route-annotations

Route notes posted by SFMTA (service hours, frequency, special notices) as HTML snippets. Params: routeId* Read-only

curl 'https://clify-dev.netlify.app/sfmta/get-route-annotations?routeId=38R'

get-stop-annotations

Stop notes posted by SFMTA (relocations, closures, notices) for an internal stop id. Params: stopId* Read-only

curl 'https://clify-dev.netlify.app/sfmta/get-stop-annotations?stopId=7915'

get-latest-alert

The single most recent Muni service alert plus the count of alerts in the last two days. Params: none Read-only

curl 'https://clify-dev.netlify.app/sfmta/get-latest-alert'

get-route-geojson

Route shape as a GeoJSON MultiLineString feature (coordinates as [lon, lat]) with route properties. Params: routeId* Read-only

curl 'https://clify-dev.netlify.app/sfmta/get-route-geojson?routeId=38'

list-stop-relocations

Feed of temporary Muni bus stop relocations/closures (stop, routes affected, dates, alternate stop). Params: none Read-only

curl 'https://clify-dev.netlify.app/sfmta/list-stop-relocations'
