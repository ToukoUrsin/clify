company-information-service API for agents (unofficial) — JSON over curl

Companies House public register (UK): search companies, officers and disqualified directors, and read company profiles, filing history, officers, PSCs, charges, officer appointments, dissolved and alphabetical company searches, name availability, advanced search with CSV export, and filing document PDFs.

Host: find-and-update.company-information.service.gov.uk. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-all

Search companies and officers together by keyword. Results are mixed; the item class is type-company or type-officer. Params: q*, page Read-only

curl 'https://clify-dev.netlify.app/company-information-service/search-all?q=tesco&page=2'

search-companies

Search companies by name or number. Returns name, profile URL, company number, incorporation or dissolution date and address. Params: q*, page, searchType Read-only

curl 'https://clify-dev.netlify.app/company-information-service/search-companies?q=tesco&page=2&searchType=dissolved'

search-officers

Search company officers (directors, secretaries, corporate officers) by name. Returns links to each officer's appointments. Params: q*, page Read-only

curl 'https://clify-dev.netlify.app/company-information-service/search-officers?q=tesco&page=2'

search-disqualified-officers

Search disqualified directors by name. Returns links to each disqualification detail page. Params: q*, page Read-only

curl 'https://clify-dev.netlify.app/company-information-service/search-disqualified-officers?q=smith&page=2'

get-disqualified-officer

Get disqualification details for a person or company: date of birth, nationality, disqualification type, start and end dates, case reference, companies involved and reason. Params: kind, officerId* Read-only

curl 'https://clify-dev.netlify.app/company-information-service/get-disqualified-officer'

get-company

Get a company overview by company number: name, registered office address, status, SIC code and previous names. Params: companyNumber* Read-only

curl 'https://clify-dev.netlify.app/company-information-service/get-company'

list-filing-history

List a company's filing history (date, type, description, PDF link), optionally filtered by category. Paginated. Params: companyNumber*, category, page Read-only

curl 'https://clify-dev.netlify.app/company-information-service/list-filing-history?category=accounts&page=2'

get-filing-document

Download a filing document PDF. The server redirects to a signed S3 URL. Params: companyNumber*, transactionId*, format, download Read-only

curl 'https://clify-dev.netlify.app/company-information-service/get-filing-document'

list-company-officers

List a company's officers (directors and secretaries) with role, appointment date, date of birth and links to their appointments. Params: companyNumber*, filter, page Read-only

curl 'https://clify-dev.netlify.app/company-information-service/list-company-officers?page=2'

list-company-pscs

List a company's persons with significant control (owners and controllers), or the reason the company is exempt. Params: companyNumber*, page Read-only

curl 'https://clify-dev.netlify.app/company-information-service/list-company-pscs?page=2'

list-company-charges

List a company's registered charges (mortgages and security agreements), with links to each charge's details. Params: companyNumber*, page Read-only

curl 'https://clify-dev.netlify.app/company-information-service/list-company-charges?page=2'

get-charge

Get one charge's details: type, created and delivered dates, status, filing transaction with PDF link, and persons entitled. Params: companyNumber*, chargeId* Read-only

curl 'https://clify-dev.netlify.app/company-information-service/get-charge'

get-officer-appointments

List all company appointments held by one officer: company, company status, role, appointed and resigned dates, correspondence address. Params: officerId*, filter, page Read-only

curl 'https://clify-dev.netlify.app/company-information-service/get-officer-appointments?page=2'

advanced-search-companies

Advanced company search. Filter by name include/exclude, registered office address, incorporation and dissolution date ranges, status, SIC code and company type. Returns company names and profile URLs Params: companyNameIncludes, companyNameExcludes, registeredOfficeAddress, incorporationFromDay, incorporationFromMonth, incorporationFromYear, incorporationToDay, incorporationToMonth, incorporationToYear, dissolvedFromDay, dissolvedFromMonth, dissolvedFromYear, dissolvedToDay, dissolvedToMonth, dissolvedToYear, status, sicCodes, type, page Read-only

curl 'https://clify-dev.netlify.app/company-information-service/advanced-search-companies?companyNameIncludes=bakery&registeredOfficeAddress=london&incorporationFromYear=2015&status=active&sicCodes=10710&type=ltd&page=2'

export-advanced-search-csv

Download advanced company search results as CSV, using the same filters as advanced-search-companies. Params: companyNameIncludes, companyNameExcludes, registeredOfficeAddress, incorporationFromDay, incorporationFromMonth, incorporationFromYear, incorporationToDay, incorporationToMonth, incorporationToYear, dissolvedFromDay, dissolvedFromMonth, dissolvedFromYear, dissolvedToDay, dissolvedToMonth, dissolvedToYear, status, sicCodes, type Read-only

curl 'https://clify-dev.netlify.app/company-information-service/export-advanced-search-csv?companyNameIncludes=bakery&registeredOfficeAddress=london&status=active'

search-dissolved-companies

Search companies dissolved since 1989 by their name at dissolution or by a previous name. Params: companyName*, changedName, searchType, page Read-only

curl 'https://clify-dev.netlify.app/company-information-service/search-dissolved-companies?companyName=tesco&changedName=name-at-dissolution&page=2'

alphabetical-search-companies

Browse the register alphabetically around a company name (40 rows per page). Returns name, number and status. Uses cursor paging via searchAfter/searchBefore. Params: companyName*, searchAfter, searchBefore Read-only

curl 'https://clify-dev.netlify.app/company-information-service/alphabetical-search-companies?companyName=tesco&searchAfter=TESCOBARBERSWOOD%3A07137692'

check-company-name-availability

Check whether a proposed company name is available by listing existing companies with the same or similar names. Params: q* Read-only

curl 'https://clify-dev.netlify.app/company-information-service/check-company-name-availability?q=tesco'
