theguardian API for agents (unofficial) — JSON over curl | clify

The Guardian (theguardian.com) news site. The CLI reads articles, edition and section fronts, tag and topic listings, writer pages, most-read lists, daily section archives, topic and contributor indexes, and reader comments as JSON. It uses the site's own `.json?dcr` page data, RSS feeds and the public discussion API.

Host: theguardian.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

get-article

Get one full article (headline, standfirst, byline, date, body blocks, tags) as JSON from its URL parts Params: section*, year*, month*, day*, slug*

curl 'https://clify-dev.netlify.app/theguardian/get-article'

get-front

Get an edition or section front page (e.g. international, uk, us, sport) as its list of curated story collections Params: front*

curl 'https://clify-dev.netlify.app/theguardian/get-front'

get-tag-feed

Get the RSS feed of the latest articles for a tag or topic, with title, link, date, byline and categories Params: section*, tag*

curl 'https://clify-dev.netlify.app/theguardian/get-tag-feed'

list-contributor-articles

Get the RSS feed of a Guardian writer's latest articles (e.g. angela-giuffrida), with title, link, date, byline and categories Params: slug*

curl 'https://clify-dev.netlify.app/theguardian/list-contributor-articles'

get-most-read

Get the site-wide most-viewed and deeply-read article lists with headline, url, byline and shortUrl Params: none

curl 'https://clify-dev.netlify.app/theguardian/get-most-read'

list-section-day

List all articles published in a section on one date (daily archive, e.g. world on 2026/oct/17) Params: section*, year*, month*, day*

curl 'https://clify-dev.netlify.app/theguardian/list-section-day'

list-subjects

Browse the A-Z index of Guardian topics/subjects for one letter; links give tag ids Params: letter*

curl 'https://clify-dev.netlify.app/theguardian/list-subjects'

list-contributors

Browse the A-Z index of Guardian writers/contributors for one letter; links give profile slugs Params: letter*

curl 'https://clify-dev.netlify.app/theguardian/list-contributors'

list-comments

List reader comments on an article by its short id (e.g. x67fk6), sorted and paged Params: shortId*, orderBy, page, pageSize

curl 'https://clify-dev.netlify.app/theguardian/list-comments'

get-comment-counts

Get comment counts for one or more articles by short URL (/p/xxxxx), comma-separated Params: shortUrls*

curl 'https://clify-dev.netlify.app/theguardian/get-comment-counts?shortUrls=%2Fp%2Fx46an8%2C%2Fp%2Fx65353%2C%2Fp%2Fx67fk6'
