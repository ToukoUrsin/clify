weather API for agents (unofficial) — JSON over curl | clify

National Weather Service (weather.gov / api.weather.gov): look up US forecasts by lat/lon or NWS grid point, active alerts, weather stations and their latest observations, forecast-office text products (e.g. Area Forecast Discussions), zone boundary KML, DWML forecast export, and weather glossary terms.

Host: weather.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

get-point

Resolve a lat/lon to its NWS forecast office, grid x/y, forecast URLs, forecast zone, county and nearby city. Run this first to get the wfo/x/y that the forecast commands take. Params: lat*, lon*

curl 'https://clify-dev.netlify.app/weather/get-point'

get-forecast

Get the 7-day forecast (day/night periods) for an NWS grid point (office + x,y from get-point). Params: wfo*, x*, y*, units

curl 'https://clify-dev.netlify.app/weather/get-forecast'

get-hourly-forecast

Get the hour-by-hour forecast (about 7 days) for an NWS grid point. Params: wfo*, x*, y*, units

curl 'https://clify-dev.netlify.app/weather/get-hourly-forecast'

list-active-alerts

List currently active NWS watches, warnings and advisories. Filter by state/marine area, zone, event type, severity or urgency. Params: area, zone, event, severity, urgency

curl 'https://clify-dev.netlify.app/weather/list-active-alerts?area=CO'

list-stations

List NWS observation stations, optionally filtered by state. Returns station IDs for get-latest-observation. Params: state, api_limit

curl 'https://clify-dev.netlify.app/weather/list-stations?state=CO'

get-latest-observation

Get the latest current-conditions observation from a station: temperature, dewpoint, wind, pressure, humidity and sky text. Params: station*

curl 'https://clify-dev.netlify.app/weather/get-latest-observation'

list-office-products

List issued text products of one type from a forecast office, newest first (e.g. Area Forecast Discussions from BOU). Params: type*, office*

curl 'https://clify-dev.netlify.app/weather/list-office-products'

get-latest-product

Get the full text of the most recent product of a type from an office, e.g. the latest Area Forecast Discussion. Params: type*, office*

curl 'https://clify-dev.netlify.app/weather/get-latest-product'

export-forecast-dwml

Export the point forecast as DWML (NWS Digital Weather Markup Language, converted to JSON): time layouts, temperatures, precipitation probabilities, weather and current observations for a lat/lon. Params: lat*, lon*

curl 'https://clify-dev.netlify.app/weather/export-forecast-dwml?lat=39.7456&lon=-97.0892'

get-zone-boundary

Get the KML boundary polygon and description (area name) of an NWS public forecast zone. Params: zone*

curl 'https://clify-dev.netlify.app/weather/get-zone-boundary'

lookup-glossary-term

Look up the definition of a weather term in the NWS glossary. Params: word*

curl 'https://clify-dev.netlify.app/weather/lookup-glossary-term?word=trough'
