hnsearch API for agents (unofficial) — JSON over curl | clify

Hacker News search. The web app calls Algolia directly (recorded: POST .../indexes/Item_dev/query and Item_dev_sort_date); this spec uses the site's documented public API with the same parameters.

Host: hn.algolia.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search

Search stories/comments by relevance Params: query*, tags, page, hitsPerPage

curl 'https://clify-dev.netlify.app/hnsearch/search?query=playwright'

search-by-date

Newest first Params: query*, tags, numericFilters

curl 'https://clify-dev.netlify.app/hnsearch/search-by-date'

get-item

A story or comment with its comment tree Params: id*

curl 'https://clify-dev.netlify.app/hnsearch/get-item'

get-user

A user's profile Params: username*

curl 'https://clify-dev.netlify.app/hnsearch/get-user'
