hnsearch API for agents (unofficial) — JSON over curl

Hacker News search. The web app calls Algolia directly (recorded: POST .../indexes/Item_dev/query and Item_dev_sort_date); this spec uses the site's documented public API with the same parameters.

Host: hn.algolia.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.
