ror API for agents (unofficial) — JSON over curl | clify

ROR (Research Organization Registry): look up research organizations (universities, funders, hospitals, companies and others) and their persistent ROR IDs through the public ROR REST API v2 at api.ror.org. Search, filter, fetch details and match affiliation strings.

Host: ror.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-organizations

Search ROR organizations by keyword or advanced field query, with optional filters (type, status, country, continent) and pagination (20 per page) Params: query, advanced, filter, page

curl 'https://clify-dev.netlify.app/ror/search-organizations?query=oxford&advanced=names.value%3ACornell*&filter=types%3Aeducation%2Clocations.geonames_details.country_code%3AGB'

get-search-facets

Get the total match count and facet counts (types, countries, continents, statuses) for a ROR search, without the result items Params: query, advanced, filter

curl 'https://clify-dev.netlify.app/ror/get-search-facets?query=oxford&advanced=names.value%3ACornell*&filter=status%3Aactive%2Ctypes%3Afunder'

get-organization

Get the full ROR record for one organization by ROR ID: names, locations, external IDs (GRID, ISNI, Wikidata, FundRef), links and parent/child/related relationships Params: id*

curl 'https://clify-dev.netlify.app/ror/get-organization'

match-affiliation

Match a free-text affiliation string (e.g. from a paper's author list) to ROR organizations; returns scored candidates with matching type and a 'chosen' flag for a confident match Params: affiliation*

curl 'https://clify-dev.netlify.app/ror/match-affiliation?affiliation=University+of+Oxford%2C+UK'
