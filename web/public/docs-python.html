docs-python API for agents (unofficial) — JSON over curl | clify

Official Python documentation (docs.python.org, a static Sphinx site). The CLI fetches the glossary as JSON, the module index, the general index by letter, tables of contents, What's New highlights, doc pages, the API entries on a page, and documentation downloads, for any docs version.

Host: docs.python.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

get-glossary

Get every Python glossary term with its HTML definition, as a JSON object keyed by term Params: version

curl 'https://clify-dev.netlify.app/docs-python/get-glossary'

list-modules

List all standard-library modules from the Python Module Index, with descriptions and doc links Params: version

curl 'https://clify-dev.netlify.app/docs-python/list-modules'

get-index-letter

List general index entries (functions, classes, keywords, topics) that start with a given letter, with links to where each is documented Params: letter*, version

curl 'https://clify-dev.netlify.app/docs-python/get-index-letter'

list-toc

List the table of contents (chapters and pages) of a docs section such as the library reference, tutorial, HOWTOs, language reference or What's New Params: section*, version

curl 'https://clify-dev.netlify.app/docs-python/list-toc'

get-page

Get a documentation page (module reference, tutorial chapter, HOWTO, What's New) with its title, breadcrumb, source link and full text Params: section*, page*, version

curl 'https://clify-dev.netlify.app/docs-python/get-page'

get-api-entries

List the API objects (functions, classes, methods, attributes, exceptions, data) documented on a page, each with signature, anchor and first description paragraph Params: section*, page*, version

curl 'https://clify-dev.netlify.app/docs-python/get-api-entries'

get-release-highlights

Get the 'Summary – Release highlights' bullet points from a Python release's What's New page Params: release*, version

curl 'https://clify-dev.netlify.app/docs-python/get-release-highlights'

list-downloads

List downloadable documentation archives (PDF, HTML, plain text, EPUB) for a docs version Params: version

curl 'https://clify-dev.netlify.app/docs-python/list-downloads'
