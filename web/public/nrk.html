nrk API for agents (unofficial) — JSON over curl | clify

NRK (Norwegian Broadcasting) news, sport, culture, TV and radio: the CLI reads news collections and articles, tag, author and review listings, TV/radio broadcast schedules, playback metadata and manifests, radio/podcast catalogs and NRK TV page plugs.

Host: nrk.no. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

get-content

Get an nrk.no content item (article teaser, news collection or stream such as 'Krigen i Ukraina' or the sports news stream) by its 1.<id>, including its latest related items Params: id*, api_limit

curl 'https://clify-dev.netlify.app/nrk/get-content'

list-topic-articles

List articles on an nrk.no topic/tag page (e.g. /atomkraft/, /sverige/) by topic id, newest first, with cursor paging Params: topicId*, count, cursor

curl 'https://clify-dev.netlify.app/nrk/list-topic-articles?topicId=148'

list-author-articles

List articles written by an NRK journalist (author profile /forfatter/<slug>-<id>) by author id, with cursor paging Params: authorId*, count, cursor

curl 'https://clify-dev.netlify.app/nrk/list-author-articles?authorId=385'

list-reviews

List NRK reviews (anmeldelser) of a given category, e.g. books, with score and cursor paging Params: reviewType*, count, cursor

curl 'https://clify-dev.netlify.app/nrk/list-reviews'

list-related-articles

List articles topically related to a given (newer-format /artikkel/<slug>-<id>) article id Params: articleId*, count

curl 'https://clify-dev.netlify.app/nrk/list-related-articles?articleId=1530245'

get-epg

Get the broadcast schedule (EPG) for one or more NRK TV/radio channels on a given date Params: channels, date*

curl 'https://clify-dev.netlify.app/nrk/get-epg?date=2026-10-18'

get-playback-metadata

Get playback metadata (title, duration, availability, geoblocking, manifest link) for a video clip, TV/radio program, podcast episode or live channel Params: kind*, id*

curl 'https://clify-dev.netlify.app/nrk/get-playback-metadata'

get-playback-manifest

Get the playback manifest (stream URLs such as HLS, plus subtitles) for a playable clip, program, podcast episode or channel Params: kind*, id*

curl 'https://clify-dev.netlify.app/nrk/get-playback-manifest'

get-radio-catalog

Get an NRK radio series or podcast catalog entry, including its seasons (months) and links Params: kind*, slug*

curl 'https://clify-dev.netlify.app/nrk/get-radio-catalog'

get-podcast-episode

Get details of a single NRK podcast episode (title, date, duration, contributors, playback link) Params: slug*, episodeId*

curl 'https://clify-dev.netlify.app/nrk/get-podcast-episode'

get-latest-episode

Get the latest (or next upcoming) episode of an NRK TV series, e.g. dagsrevyen or nyheter Params: seriesId*

curl 'https://clify-dev.netlify.app/nrk/get-latest-episode'

get-tv-page

Get an NRK TV page (e.g. the front page) with its sections and plug references Params: pageId

curl 'https://clify-dev.netlify.app/nrk/get-tv-page'

get-tv-plug

Resolve an NRK TV plug reference (from get-tv-page plugRefs) to its series/program title, description, images and ids Params: id*

curl 'https://clify-dev.netlify.app/nrk/get-tv-plug'

list-clip-collections

List the related video collections shown alongside an nrk.no video clip Params: clipId*

curl 'https://clify-dev.netlify.app/nrk/list-clip-collections?clipId=4c5a7d19-d101-4877-a1a8-faefbd3f9ce5'
