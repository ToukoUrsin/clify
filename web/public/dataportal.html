dataportal API for agents (unofficial) — JSON over curl | clify

Sveriges dataportal (dataportal.se), Sweden's national open-data catalogue. This CLI searches and reads datasets, APIs (data services), organisations, specifications, concepts and terminologies through the public EntryScape/EntryStore backends (admin.dataportal.se and editera.dataportal.se). No login is needed.

Host: dataportal.se. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-datasets

Full-text search of public datasets (dcat:Dataset) in the national catalogue, with sorting and offset paging Params: q, api_limit, offset, sort

curl 'https://clify-dev.netlify.app/dataportal/search-datasets?q=trafik'

search-data-services

Full-text search of public APIs / data services (dcat:DataService) in the catalogue Params: q, api_limit, offset, sort

curl 'https://clify-dev.netlify.app/dataportal/search-data-services?q=trafik'

search-organisations

Search publishing organisations (foaf:Agent / foaf:Organization) by name or text Params: q, api_limit, offset, sort

curl 'https://clify-dev.netlify.app/dataportal/search-organisations?q=trafik'

search-catalog-solr

Advanced: run a raw Solr query against the admin.dataportal.se catalogue store (filter by theme, access rights, publisher, type, with optional facets) Params: query*, api_limit, offset, sort, facetFields

curl 'https://clify-dev.netlify.app/dataportal/search-catalog-solr?query=public%3Atrue+AND+rdfType%3Ahttp%5C%3A%2F%2Fwww.w3.org%2Fns%2Fdcat%23Dataset+AND+%28title%3Atrafik+OR+description%3Atrafik%29'

get-entry

Get full DCAT metadata for a dataset, data service (API) or organisation by catalog and entry id (site URL ids like 389_8203 = catalog 389, entry 8203) Params: catalog*, entry*

curl 'https://clify-dev.netlify.app/dataportal/get-entry'

get-catalog-quality

Get the metadata-quality score (MQA percentage, score, rating) for a catalog Params: catalog*

curl 'https://clify-dev.netlify.app/dataportal/get-catalog-quality'

export-metadata

Export an entry's RDF metadata (dataset/API/organisation) as JSON-LD, Turtle, N-Triples or RDF/XML Params: catalog*, entry*, format

curl 'https://clify-dev.netlify.app/dataportal/export-metadata'

search-concepts

Search concepts/terms (skos:Concept) in the national terminology store Params: q*, api_limit, offset, sort

curl 'https://clify-dev.netlify.app/dataportal/search-concepts?q=trafik'

list-terminologies

List public terminologies (skos:ConceptScheme) in the terminology store Params: api_limit, offset

curl 'https://clify-dev.netlify.app/dataportal/list-terminologies'

search-specifications

Search specifications (information/data models, dx-prof Profiles) in the editera store Params: q, api_limit, offset

curl 'https://clify-dev.netlify.app/dataportal/search-specifications?q=*'

get-concept

Get a concept, terminology or specification entry from the editera store by catalog and entry id (site ids like /concepts/202_4778 or /terminology/202_1) Params: catalog*, entry*

curl 'https://clify-dev.netlify.app/dataportal/get-concept'

list-detected-apis

List catalogue entries with an automatically detected OpenAPI definition (definition URL, version, format, CORS) Params: none

curl 'https://clify-dev.netlify.app/dataportal/list-detected-apis'

get-theme-stats

Count of datasets per EU data theme (Transport, Economy, ...) Params: none

curl 'https://clify-dev.netlify.app/dataportal/get-theme-stats'

get-organisation-stats

Organisations ranked by number of published datasets (labels and counts) Params: none

curl 'https://clify-dev.netlify.app/dataportal/get-organisation-stats'

get-dataset-history

Monthly history of the total number of datasets in the catalogue Params: none

curl 'https://clify-dev.netlify.app/dataportal/get-dataset-history'

get-entity-counts

Total counts of concepts, terminologies and specifications Params: none

curl 'https://clify-dev.netlify.app/dataportal/get-entity-counts'
