zenodo API for agents (unofficial) — JSON over curl | clify

Zenodo (CERN's open research repository). This CLI searches communities and the records inside them, and fetches record metadata, versions, formatted citations, citing works, community members, subcommunities and collection records.

Host: zenodo.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-community-records

Search or list records (datasets, software, publications…) inside a community by keyword, with resource-type and access filters, sorting and pagination Params: community_id*, q, sort, resource_type, access_status, allversions, page, size

curl 'https://clify-dev.netlify.app/zenodo/search-community-records?q=climate+change&sort=bestmatch&resource_type=dataset&access_status=open'

search-communities

Search or browse Zenodo communities by keyword, with a community-type filter, sorting and pagination Params: q, sort, type, page, size

curl 'https://clify-dev.netlify.app/zenodo/search-communities?q=biodiversity&sort=bestmatch&type=project'

list-featured-communities

List the communities currently featured on Zenodo's home and communities pages Params: none

curl 'https://clify-dev.netlify.app/zenodo/list-featured-communities'

get-record

Get a record's full metadata (title, creators, description, DOI, license, files, stats) as JSON, using the record's JSON export Params: record_id*

curl 'https://clify-dev.netlify.app/zenodo/get-record'

get-record-communities

List the communities a record belongs to Params: record_id*

curl 'https://clify-dev.netlify.app/zenodo/get-record-communities'

list-record-versions

List all versions of a record, ordered by version Params: record_id*, page, size

curl 'https://clify-dev.netlify.app/zenodo/list-record-versions'

get-record-citation

Get a formatted bibliography citation for a record in a chosen citation style (APA, Harvard, MLA, Vancouver, Chicago, IEEE) Params: record_id*, style, locale

curl 'https://clify-dev.netlify.app/zenodo/get-record-citation?style=apa'

list-citing-works

List works that cite a Zenodo record, looked up by the record's concept (parent) DOI through the Zenodo citation broker Params: doi*, q, sort, page, size

curl 'https://clify-dev.netlify.app/zenodo/list-citing-works?doi=10.5281%2Fzenodo.592536'

list-community-members

List the public members of a community Params: community_id*, q, page, size

curl 'https://clify-dev.netlify.app/zenodo/list-community-members'

list-subcommunities

List the subcommunities of a parent community, e.g. the EU Open Research Repository or the Biodiversity Literature Repository Params: community_id*, q, sort, page, size

curl 'https://clify-dev.netlify.app/zenodo/list-subcommunities'

list-collection-records

List or search the records in a community collection (e.g. Biodiversity Literature Repository taxon collections) by numeric collection id Params: collection_id*, q, page, size

curl 'https://clify-dev.netlify.app/zenodo/list-collection-records'

search-records

Search across all Zenodo records with an Elasticsearch/Lucene query, e.g. by title, creator, community id or related identifiers Params: q*, sort, page, size

curl 'https://clify-dev.netlify.app/zenodo/search-records?q=parent.communities.ids%3Ac529f97d-f8cb-4c13-a439-9e36891694c2+AND+metadata.title%3A%22Tyrannosaurus+rex%22'
