cordis-europa API for agents (unofficial) — JSON over curl

CORDIS (EU research results portal): look up EU-funded research projects and their reports, deliverables, OpenAIRE publications, Results-in-Brief and news articles, browse news and domain-of-application listings, and run keyword searches over the Projects Map data.

Host: cordis.europa.eu. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

get-project

Get the full fact sheet of an EU research project (Horizon Europe, H2020, FP7…) as JSON, looked up by grant agreement ID Params: id* Read-only

curl 'https://clify-dev.netlify.app/cordis-europa/get-project?id=101070320'

get-project-reporting

Get a project's periodic or final report summary: context and objectives, work performed, and results so far Params: id* Read-only

curl 'https://clify-dev.netlify.app/cordis-europa/get-project-reporting?id=101070320'

list-project-deliverables

List a project's public deliverables, data management plans and publications, with download links (from the project's Results tab) Params: id* Read-only

curl 'https://clify-dev.netlify.app/cordis-europa/list-project-deliverables?id=101070320'

get-project-openaire

Get the publications, datasets, software and other research outputs that OpenAIRE links to a project Params: project_id* Read-only

curl 'https://clify-dev.netlify.app/cordis-europa/get-project-openaire?project_id=101070320'

get-result-report

Get a result/report record as JSON (periodic report summary, work performed, final results, related project), looked up by its RCN Params: rcn* Read-only

curl 'https://clify-dev.netlify.app/cordis-europa/get-result-report?rcn=1169591'

get-article

Get a CORDIS article (news, Results in Brief, Ask an expert…) as JSON, including body, keywords and related projects/articles Params: id* Read-only

curl 'https://clify-dev.netlify.app/cordis-europa/get-article?id=467900-can-birds-understand-the-songs-of-other-species'

list-news

List the latest CORDIS news articles shown on the news hub, by section (Scientific advances, Ask an expert…) Params: none Read-only

curl 'https://clify-dev.netlify.app/cordis-europa/list-news'

list-domain-articles

List recent articles for a domain of application (Energy, Health, Digital Economy, Climate Change and Environment, …) Params: domain* Read-only

curl 'https://clify-dev.netlify.app/cordis-europa/list-domain-articles?domain=energy'

search-projects-map

Keyword search over EU-funded projects and participating organisations (Projects Map data): returns hit counts plus organisations with address, coordinates and their projects (budget, dates, scheme); Params: query* Read-only

curl 'https://clify-dev.netlify.app/cordis-europa/search-projects-map?query=hydrogen'
