arbeitnow API for agents (unofficial) — JSON over curl

Arbeitnow: a job board for jobs in Germany (remote, visa sponsorship, English speaking). This CLI searches and filters jobs, lists a company's jobs, reads the free public job-feed API, opens job details and lists hiring companies.

Host: arbeitnow.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-jobs

Search jobs by keyword, with optional tag, location/category, date-posted filter, sort order and page. Returns paging info plus the result list as rendered HTML; each <li data-slug> holds a job slug a Params: search, tags, category, sort_by, date_posted, page Read-only

curl 'https://clify-dev.netlify.app/arbeitnow/search-jobs?search=python+developer&tags=%5B%22remote%22%5D&category=remote&date_posted=7d'

list-company-jobs

List the open jobs of one company. Needs both the display name and the slug. Returns paging info plus the result list as rendered HTML; each <li data-slug> holds a job slug for get-job. Params: company_name*, company_slug*, sort_by, page Read-only

curl 'https://clify-dev.netlify.app/arbeitnow/list-company-jobs?company_name=Duck+Duck+Go&company_slug=duck-duck-go'

list-jobs-feed

Free public job-board API feed: newest jobs as clean JSON (slug, company, title, description, remote flag, tags, job types, location, created_at), paginated. Params: page, visa_sponsorship Read-only

curl 'https://clify-dev.netlify.app/arbeitnow/list-jobs-feed?page=2'

get-job

Get full details of one job posting: title, HTML description, salary, employment type, remote/location, dates and hiring company. Params: company_slug*, job_slug* Read-only

curl 'https://clify-dev.netlify.app/arbeitnow/get-job'

list-companies

List the companies hiring on Arbeitnow with their open-job count. The company slug is the last segment of url; use it with list-company-jobs. Params: none Read-only

curl 'https://clify-dev.netlify.app/arbeitnow/list-companies'
