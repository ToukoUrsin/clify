datasf API for agents (unofficial) — JSON over curl

San Francisco Open Data portal (data.sfgov.org, now served from data.sf.gov on Socrata): search the city's dataset catalog, read dataset metadata and columns, and query, export or map dataset records with SoQL.

Host: data.sfgov.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-datasets

Search or browse the SF open data catalog by keyword, category, tag, publishing department or asset type; returns dataset ids, names and stats Params: q, categories, tags, attribution, department, only, order, api_limit, offset Read-only

curl 'https://clify-dev.netlify.app/datasf/search-datasets?q=building+permits&categories=Housing+and+Buildings&tags=transit&attribution=SFMTA&only=dataset'

query-dataset-records

Fetch rows from a dataset as JSON with SoQL filtering, sorting, column selection, aggregation and paging. Use get-dataset to find column field names. Params: datasetId*, where, order, select, group, q, api_limit, offset Read-only

curl 'https://clify-dev.netlify.app/datasf/query-dataset-records?datasetId=i98e-djp9&where=street_name%3D%27Market%27&order=filed_date+DESC&api_limit=5'

get-dataset

Get a dataset's metadata: name, description, category, publishing department, update times, view and download counts, and its columns (fieldName, type, description) Params: datasetId* Read-only

curl 'https://clify-dev.netlify.app/datasf/get-dataset?datasetId=i98e-djp9'

export-dataset-csv

Export dataset rows as CSV text, with the same SoQL filter, sort and limit options as query-dataset-records Params: datasetId*, where, order, select, api_limit, offset Read-only

curl 'https://clify-dev.netlify.app/datasf/export-dataset-csv?datasetId=vw6y-z8j6&order=requested_datetime+DESC&api_limit=5'

get-dataset-geojson

Fetch rows of a geographic dataset (neighborhoods, districts, stops) as GeoJSON features with geometry, with optional SoQL filtering Params: datasetId*, where, select, api_limit, offset Read-only

curl 'https://clify-dev.netlify.app/datasf/get-dataset-geojson?datasetId=j2bu-swwd&api_limit=5'

list-catalog-filters

List the catalog's filter values: categories, Publishing Department options and popular tags, for use with search-datasets Params: none Read-only

curl 'https://clify-dev.netlify.app/datasf/list-catalog-filters'

suggest-dataset-titles

Quick dataset title suggestions for a partial keyword; use search-datasets to get ids Params: q*, api_limit Read-only

curl 'https://clify-dev.netlify.app/datasf/suggest-dataset-titles?q=muni+transit'
