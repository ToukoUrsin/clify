nuget API for agents (unofficial) — JSON over curl

nuget.org, the public .NET package gallery. This CLI searches packages, reads package and version metadata, licenses, owner profiles, and download statistics, and lists NuGet client tool downloads, all without logging in.

Host: nuget.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-packages

Search the NuGet gallery by keyword or tag (q=Tags:"bson"), with sort, framework, package-type and prerelease filters, 20 results per page Params: q*, sortby, frameworks, tfms, frameworkFilterMode, includeComputedFrameworks, packagetype, prerel, page Read-only

curl 'https://clify-dev.netlify.app/nuget/search-packages?q=json&frameworks=netstandard&page=2'

search-packages-v2

Search packages through the OData v2 API, which returns structured metadata (id, version, downloads, description) with offset paging Params: query*, includePrerelease, top, skip Read-only

curl 'https://clify-dev.netlify.app/nuget/search-packages-v2'

get-package

Get the gallery page for the latest version of a package: title, version, target frameworks, install command and README text Params: id* Read-only

curl 'https://clify-dev.netlify.app/nuget/get-package'

get-package-version

Get metadata for one package version through the OData v2 API: dependencies, downloads, hash, size, dates, project URL Params: id*, version* Read-only

curl 'https://clify-dev.netlify.app/nuget/get-package-version'

list-package-versions

List all versions of a package with their per-version download counts and publish dates (OData v2 FindPackagesById) Params: id*, skip Read-only

curl 'https://clify-dev.netlify.app/nuget/list-package-versions'

get-package-feed

Get the Atom feed of a package's versions, newest first, with update times and links Params: id* Read-only

curl 'https://clify-dev.netlify.app/nuget/get-package-feed'

get-package-license

curl 'https://clify-dev.netlify.app/nuget/get-package-license'
