yle API for agents (unofficial) — JSON over curl

Yle (Finnish public broadcaster) News in English: search articles and Areena programs, read articles, browse latest, front-page and topic news lists, and look up video metadata.

Host: yle.fi. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search

Keyword search across Yle articles and Areena programs, with filters for type, service, language and author Params: query*, type, service, language, author, api_limit, offset Read-only

curl 'https://clify-dev.netlify.app/yle/search?query=helsinki&type=article&service=uutiset&author=Wif+Stenger'

get-article

Get an article's metadata (headline, description, publish and modify dates, keywords, author, images) from its JSON-LD Params: id* Read-only

curl 'https://clify-dev.netlify.app/yle/get-article?id=74-20250494'

get-article-text

Get an article's body text as an ordered list of paragraphs and subheadings Params: id* Read-only

curl 'https://clify-dev.netlify.app/yle/get-article-text?id=74-20215566'

list-latest

List the latest Yle News (English) articles, newest first Params: none Read-only

curl 'https://clify-dev.netlify.app/yle/list-latest'

list-front-page

List the stories currently on the Yle News (English) front page, with leads Params: none Read-only

curl 'https://clify-dev.netlify.app/yle/list-front-page'

list-topic

List recent English articles for a topic (e.g. 18-220306 Politics, 18-34837 Domestic news, 18-204933 Economy) Params: topic_id* Read-only

curl 'https://clify-dev.netlify.app/yle/list-topic?topic_id=18-220306'

get-video-preview

Get metadata for a Yle/Areena video program (title, series, duration, start time, HLS manifest URL) Params: id* Read-only

curl 'https://clify-dev.netlify.app/yle/get-video-preview?id=1-78744762'
