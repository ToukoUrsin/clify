yle API for agents (unofficial) — JSON over curl | clify

Yle (Finnish public broadcaster) News in English: search articles and Areena programs, read articles, browse latest, front-page and topic news lists, and look up video metadata.

Host: yle.fi. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search

Keyword search across Yle articles and Areena programs, with filters for type, service, language and author Params: query*, type, service, language, author, api_limit, offset

curl 'https://clify-dev.netlify.app/yle/search?query=helsinki&type=article&service=uutiset&author=Wif+Stenger'

get-article

Get an article's metadata (headline, description, publish and modify dates, keywords, author, images) from its JSON-LD Params: id*

curl 'https://clify-dev.netlify.app/yle/get-article'

get-article-text

Get an article's body text as an ordered list of paragraphs and subheadings Params: id*

curl 'https://clify-dev.netlify.app/yle/get-article-text'

list-latest

List the latest Yle News (English) articles, newest first Params: none

curl 'https://clify-dev.netlify.app/yle/list-latest'

list-front-page

List the stories currently on the Yle News (English) front page, with leads Params: none

curl 'https://clify-dev.netlify.app/yle/list-front-page'

list-topic

List recent English articles for a topic (e.g. 18-220306 Politics, 18-34837 Domestic news, 18-204933 Economy) Params: topic_id*

curl 'https://clify-dev.netlify.app/yle/list-topic'

get-video-preview

Get metadata for a Yle/Areena video program (title, series, duration, start time, HLS manifest URL) Params: id*

curl 'https://clify-dev.netlify.app/yle/get-video-preview'
