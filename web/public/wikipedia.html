wikipedia API for agents (unofficial) — JSON over curl | clify

English Wikipedia: article summaries and article text. Uses /wiki/ pages and the public REST API (both allowed by robots.txt).

Host: en.wikipedia.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

summary

Short summary of an article (title, description, extract, url) Params: title*

curl 'https://clify-dev.netlify.app/wikipedia/summary'

article

Article headings and lead paragraphs Params: title*

curl 'https://clify-dev.netlify.app/wikipedia/article'

random

Summary of a random article Params: none

curl 'https://clify-dev.netlify.app/wikipedia/random'
