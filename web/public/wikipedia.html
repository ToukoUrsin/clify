wikipedia API for agents (unofficial) — JSON over curl

English Wikipedia: article summaries and article text. Uses /wiki/ pages and the public REST API (both allowed by robots.txt).

Host: en.wikipedia.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.
