caniuse API for agents (unofficial) — JSON over curl | clify

caniuse.com: browser support tables for web platform features (HTML, CSS, JS APIs). The CLI searches features, fetches per-browser support data, compares browser versions, reads the feature index, news, usage share and feature-suggestion list.

Host: caniuse.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-features

Search caniuse features by keyword; returns matching feature IDs (caniuse, wf-* web-features and mdn-* BCD IDs) Params: query*

curl 'https://clify-dev.netlify.app/caniuse/search-features?query=flexbox'

get-feature-support

Get full support data (title, description, spec, baseline status, per-browser per-version support stats) for one or more feature IDs Params: ids*

curl 'https://clify-dev.netlify.app/caniuse/get-feature-support'

compare-browsers

Compare feature support between browser versions; returns the raw comparison result (IDs of features whose support differs between the given versions) Params: compare*, cats

curl 'https://clify-dev.netlify.app/caniuse/compare-browsers?compare=chrome+120%2Cfirefox+120%2Csafari+17'

get-feature-page

Get a feature's detail page summary: title, spec link and status, description and global usage percentages (works for caniuse IDs, wf-* and mdn-* IDs) Params: id*

curl 'https://clify-dev.netlify.app/caniuse/get-feature-page'

list-features-index

List all features in the caniuse index (titles and links, grouped by category in page order: CSS, HTML5, ...); the feature ID is the last path segment of href (e.g. 'css-rrggbbaa') Params: none

curl 'https://clify-dev.netlify.app/caniuse/list-features-index'

list-news

List latest caniuse news / newly added features Params: none

curl 'https://clify-dev.netlify.app/caniuse/list-news'

get-usage-table

Get the browser usage-share table: per browser, the versions with their global usage percentage Params: none

curl 'https://clify-dev.netlify.app/caniuse/get-usage-table'

list-feature-suggestions

List the top suggested features not yet on caniuse, ranked by GitHub votes Params: none

curl 'https://clify-dev.netlify.app/caniuse/list-feature-suggestions'
