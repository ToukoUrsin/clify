dev-to API for agents (unofficial) — JSON over curl | clify

DEV Community (dev.to) is a developer blogging platform. This CLI reads its public JSON API: articles (filtered, latest, top, rising, series), article details, comment threads, users, organizations, tags, podcast episodes and videos.

Host: dev.to. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

list-articles

List published articles. Filter by one tag, any of several tags, excluded tags, author or organization username, feed state (fresh/rising), top articles of the last N days, or series (collection_id). Params: tag, tags, tags_exclude, username, state, top, collection_id, page, per_page

curl 'https://clify-dev.netlify.app/dev-to/list-articles?tag=react&tags=react%2Cjavascript&tags_exclude=ai&username=sylwia-lask&top=7&collection_id=43742&per_page=10'

list-latest-articles

List the newest published articles, newest first. Params: page, per_page

curl 'https://clify-dev.netlify.app/dev-to/list-latest-articles?per_page=10'

get-article

Get one article by numeric id, with metadata, tags, author and full body (body_html/body_markdown). Params: id*

curl 'https://clify-dev.netlify.app/dev-to/get-article'

get-article-by-path

Get one article by author username and slug (the two parts of its dev.to URL path). Params: username*, slug*

curl 'https://clify-dev.netlify.app/dev-to/get-article-by-path'

list-comments

List all comment threads on an article. Each comment has nested replies in children. Params: article_id*

curl 'https://clify-dev.netlify.app/dev-to/list-comments?article_id=4846656'

get-comment

Get one comment and all of its nested replies by comment id_code. Params: id_code*

curl 'https://clify-dev.netlify.app/dev-to/get-comment'

get-comment-reaction-counts

Get public reaction counts for the comments of an article, as a list of {id: numeric comment id, count}. Params: article_id*

curl 'https://clify-dev.netlify.app/dev-to/get-comment-reaction-counts?article_id=4846656'

get-user-by-username

Get a user's public profile by username. Params: username*

curl 'https://clify-dev.netlify.app/dev-to/get-user-by-username?username=sylwia-lask'

get-user

Get a user's public profile by numeric user id. Params: id*

curl 'https://clify-dev.netlify.app/dev-to/get-user'

get-organization

Get an organization's profile by its username. Params: username*

curl 'https://clify-dev.netlify.app/dev-to/get-organization'

list-organization-articles

List articles published under an organization. Params: username*, page, per_page

curl 'https://clify-dev.netlify.app/dev-to/list-organization-articles?per_page=5'

list-organization-users

List the members of an organization. Params: username*, page, per_page

curl 'https://clify-dev.netlify.app/dev-to/list-organization-users?per_page=5'

list-tags

List tags, most popular first. Params: page, per_page

curl 'https://clify-dev.netlify.app/dev-to/list-tags?per_page=20'

list-podcast-episodes

List recent podcast episodes hosted on DEV. Params: page, per_page

curl 'https://clify-dev.netlify.app/dev-to/list-podcast-episodes?per_page=5'

list-videos

List recent articles that contain a video. Params: page, per_page

curl 'https://clify-dev.netlify.app/dev-to/list-videos?per_page=5'
