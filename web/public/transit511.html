transit511 API for agents (unofficial) — JSON over curl

511.org is the San Francisco Bay Area traveler information site. This CLI reads its public transit and traffic data without an API key: transit and traffic alerts, agencies, transit centers, bike share, carpool spots, road speeds and the stop-ID finder.

Host: 511.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

list-transit-alerts

List current Bay Area transit service alerts for all agencies. Filter the output yourself by ServiceAlertEntities[].AgencyId (e.g. BA=BART, SC=VTA, CT=Caltrain, AC=AC Transit). Params: none Read-only

curl 'https://clify-dev.netlify.app/transit511/list-transit-alerts'

list-traffic-events

List active Bay Area traffic events (incidents, construction, closures) with road, direction, severity and schedule. Params: road_segments, road_closed Read-only

curl 'https://clify-dev.netlify.app/transit511/list-traffic-events'

get-alert-ticker

Get the site-wide alert ticker: the current critical alerts and major closures shown at the top of 511.org. Params: none Read-only

curl 'https://clify-dev.netlify.app/transit511/get-alert-ticker'

list-traffic-news

List breaking traffic news and scheduled closure announcements, with descriptions and expiry dates. Params: none Read-only

curl 'https://clify-dev.netlify.app/transit511/list-traffic-news'

list-transit-agencies

Search Bay Area transit agencies by name and mode. Returns description, modes, the detail-page URL (slug), the stop-ID finder link and the transit-centers link (which carries the agency filter id). Params: title, train, bus, ferry, shuttle, subway, sort Read-only

curl 'https://clify-dev.netlify.app/transit511/list-transit-agencies?title=transit'

list-transit-agency-codes

List every transit agency with its 2-letter agency code (used in alerts' AgencyId and in the stop-ID finder) and whether it has real-time data. Params: none Read-only

curl 'https://clify-dev.netlify.app/transit511/list-transit-agency-codes'

search-transit-centers

Search transit centers and stations by name and/or the agency serving them. Returns names and detail URLs (slug), 10 per page. Params: title, agency, page Read-only

curl 'https://clify-dev.netlify.app/transit511/search-transit-centers?title=BART'

list-all-transit-centers

Get all transit centers in one JSON list, with address, coordinates, agencies served and shuttles. Params: none Read-only

curl 'https://clify-dev.netlify.app/transit511/list-all-transit-centers'

get-transit-agency

Get a transit agency's detail page: description, website, address, phone, modes, paratransit link and how many transit centers it serves. Params: slug* Read-only

curl 'https://clify-dev.netlify.app/transit511/get-transit-agency?slug=bart'

get-transit-center

Get a transit center's detail page: name, address, agencies and info text, including links to route/stop/schedule maps. Params: slug* Read-only

curl 'https://clify-dev.netlify.app/transit511/get-transit-center?slug=embarcadero-bart-station'

list-bikeshare-stations

List Bay Wheels bike share stations with live counts of available bikes and docks. Params: none Read-only

curl 'https://clify-dev.netlify.app/transit511/list-bikeshare-stations'

list-casual-carpool-locations

List casual carpool pickup and drop-off locations with address, description and coordinates. Params: none Read-only

curl 'https://clify-dev.netlify.app/transit511/list-casual-carpool-locations'

get-traffic-speeds

Get live traffic flow (speeds, jam factor) for road segments inside a bounding box. Params: bbox*, functionalClasses Read-only

curl 'https://clify-dev.netlify.app/transit511/get-traffic-speeds?bbox=-123.3%2C36.9%2C-122.4%2C37.8'

search-site

Full-text search of 511.org pages (schedules, agency info, transit centers, programs). Returns page titles and URLs. Params: search* Read-only

curl 'https://clify-dev.netlify.app/transit511/search-site?search=Caltrain+schedule'
