aviationweather API for agents (unofficial) — JSON over curl | clify

AviationWeather.gov (NOAA Aviation Weather Center) public Data API. The CLI fetches METARs, TAFs, PIREPs, SIGMETs/AIRMETs, international SIGMETs, winds aloft, and airport/station info. No login is needed.

Host: aviationweather.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

get-metars

Get decoded METAR observations by station ICAO ids or inside a lat/lon bounding box, optionally with hours of history Params: ids, bbox, hours

curl 'https://clify-dev.netlify.app/aviationweather/get-metars?ids=KORD%2CKJFK&bbox=39%2C-106%2C41%2C-104&hours=6'

get-tafs

Get TAF terminal forecasts for ICAO station ids, optionally with the latest METAR Params: ids*, metar

curl 'https://clify-dev.netlify.app/aviationweather/get-tafs?ids=KORD%2CKJFK'

get-airport

Get airport details: name, location, elevation, runways and frequencies Params: ids*

curl 'https://clify-dev.netlify.app/aviationweather/get-airport?ids=KDEN'

get-station-info

Get weather station metadata: ICAO/IATA/WMO ids, site name, location, and product types (METAR/TAF) Params: ids*

curl 'https://clify-dev.netlify.app/aviationweather/get-station-info?ids=KSEA'

search-pireps

Search pilot reports (PIREPs/AIREPs) near a station by distance and age, or inside a bounding box, optionally filtered by intensity Params: id, distance, age, bbox, inten

curl 'https://clify-dev.netlify.app/aviationweather/search-pireps?id=KDEN&distance=200&age=6&bbox=20%2C-179%2C72%2C-44'

list-sigmets

List active domestic (US) SIGMETs and convective SIGMETs, optionally filtered by hazard Params: hazard

curl 'https://clify-dev.netlify.app/aviationweather/list-sigmets'

list-gairmets

List current G-AIRMETs: sierra (IFR/mountain obscuration), tango (turbulence/wind/LLWS), zulu (icing/freezing level) Params: type, hazard

curl 'https://clify-dev.netlify.app/aviationweather/list-gairmets'

list-international-sigmets

List active international SIGMETs by FIR (tropical cyclones, volcanic ash, turbulence, icing, thunderstorms) Params: hazard

curl 'https://clify-dev.netlify.app/aviationweather/list-international-sigmets'

get-winds-aloft

Get the FD winds/temperatures aloft forecast text for a region, altitude band and forecast period Params: region, level, fcst

curl 'https://clify-dev.netlify.app/aviationweather/get-winds-aloft?region=slc&level=low&fcst=06'
