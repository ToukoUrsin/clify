digitraffic API for agents (unofficial) — JSON over curl

Digitraffic (Fintraffic) offers open, real-time Finnish road, rail and marine traffic data. This CLI wraps its public JSON APIs (tie/rata/meri.digitraffic.fi), the status page and the announcements (tiedotteet) pages.

Host: digitraffic.fi. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

list-announcements

List Digitraffic announcements (tiedotteet), newest first. You can filter by traffic type or tag. Params: traffictype, tag Read-only

curl 'https://clify-dev.netlify.app/digitraffic/list-announcements?traffictype=rautatieliikenne&tag=rajapinnat'

get-announcement

Get the full text of one announcement by date and slug, as found in the URL /tiedotteet/YYYY/MM/DD/slug.html. Params: year*, month*, day*, slug* Read-only

curl 'https://clify-dev.netlify.app/digitraffic/get-announcement?year=2026&month=08&day=18&slug=road-datex2-3-7'

get-service-status

Get the current status (ok/disrupted/down) of every Digitraffic API system. Params: none Read-only

curl 'https://clify-dev.netlify.app/digitraffic/get-service-status'

list-status-issues

List incidents on the status page (outages, disruptions), newest first, with their resolution state. Params: none Read-only

curl 'https://clify-dev.netlify.app/digitraffic/list-status-issues'

list-traffic-messages

List current road traffic messages (announcements, road works, weight restrictions, exempted transports) as GeoJSON features. Params: situationType, inactiveHours Read-only

curl 'https://clify-dev.netlify.app/digitraffic/list-traffic-messages?situationType=TRAFFIC_ANNOUNCEMENT'

get-traffic-message

Get one road traffic message by its situationId, e.g. GUID50xxxxxx (take the id from list-traffic-messages). Params: situationId* Read-only

curl 'https://clify-dev.netlify.app/digitraffic/get-traffic-message?situationId=GUID50444128'

list-weather-station-data

Get the latest sensor readings from all road weather stations. Params: none Read-only

curl 'https://clify-dev.netlify.app/digitraffic/list-weather-station-data'

get-weather-station-data

Get the latest sensor readings (air/road temperature, wind, etc.) for one road weather station. Params: id* Read-only

curl 'https://clify-dev.netlify.app/digitraffic/get-weather-station-data?id=1001'

get-tms-station-data

Get live traffic measurement data (vehicle counts, average speeds) for one TMS station. Params: id* Read-only

curl 'https://clify-dev.netlify.app/digitraffic/get-tms-station-data?id=23001'

list-weathercam-stations

List all road weather camera stations, with location and state. Params: none Read-only

curl 'https://clify-dev.netlify.app/digitraffic/list-weathercam-stations'

get-weathercam-station

Get one weather camera station by id, including camera presets and image URLs. Params: id* Read-only

curl 'https://clify-dev.netlify.app/digitraffic/get-weathercam-station?id=C04507'

list-maintenance-routes

Get the latest road maintenance tracking points (snow ploughing, salting, etc.) as GeoJSON. Params: taskId, domain Read-only

curl 'https://clify-dev.netlify.app/digitraffic/list-maintenance-routes'

list-station-live-trains

List live trains arriving at and departing from a railway station, by station short code (e.g. HKI, TPE). Params: station*, arriving_trains, departing_trains, arrived_trains, departed_trains, include_nonstopping Read-only

curl 'https://clify-dev.netlify.app/digitraffic/list-station-live-trains?station=HKI'

list-trains-between-stations

List the next trains running from one station to another, by station short codes. Params: from*, to*, api_limit Read-only

curl 'https://clify-dev.netlify.app/digitraffic/list-trains-between-stations?from=HKI&to=TPE'

get-train

Get one train's timetable and live status by departure date (or 'latest') and train number. Params: date*, train_number* Read-only

curl 'https://clify-dev.netlify.app/digitraffic/get-train?date=latest&train_number=1'

get-train-composition

Get a train's composition (locomotives, wagons, length, max speed) by departure date and train number. Params: date*, train_number* Read-only

curl 'https://clify-dev.netlify.app/digitraffic/get-train-composition?date=2026-10-18&train_number=1'

list-rail-stations

List all railway stations with short codes, names, UIC codes and coordinates. Params: none Read-only

curl 'https://clify-dev.netlify.app/digitraffic/list-rail-stations'

list-train-locations

Get the latest GPS location and speed of every running train. Params: none Read-only

curl 'https://clify-dev.netlify.app/digitraffic/list-train-locations'

list-vessel-locations

Get the latest AIS vessel positions (GeoJSON). You can filter by MMSI or by a radius around a point. Params: mmsi, latitude, longitude, radius, from Read-only

curl 'https://clify-dev.netlify.app/digitraffic/list-vessel-locations'

get-vessel

Get AIS vessel metadata (name, call sign, IMO, ship type, destination) by MMSI. Params: mmsi* Read-only

curl 'https://clify-dev.netlify.app/digitraffic/get-vessel?mmsi=230629000'

list-port-calls

List port calls (vessel arrivals and departures) for a port, by UN/LOCODE (e.g. FIHEL). Params: locode, vesselName, mmsi Read-only

curl 'https://clify-dev.netlify.app/digitraffic/list-port-calls?locode=FIHEL'

list-sea-state

Get the latest sea state estimation (SSE) measurements from coastal sites: wind, wave, sea state. Params: none Read-only

curl 'https://clify-dev.netlify.app/digitraffic/list-sea-state'

list-aton-faults

List current faults in aids to navigation (buoys, lights, beacons) in Finnish waters. Params: language, fixed Read-only

curl 'https://clify-dev.netlify.app/digitraffic/list-aton-faults'
