lichess API for agents (unofficial) — JSON over curl

Lichess.org (free open-source chess server): read-only CLI over its server-rendered pages for FIDE player and federation data, broadcast search and calendar, rating leaderboards, online players, and tournament winners and details.

Host: lichess.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-fide-players

Search or list FIDE-rated players, sortable by name or classical/rapid/blitz rating, paginated 30 per page Params: q, order, page Read-only

curl 'https://clify-dev.netlify.app/lichess/search-fide-players?q=Kasparov&order=blitz&page=2'

list-fide-player-broadcasts

List recent broadcast tournaments a FIDE player took part in, newest first, paginated Params: id*, slug*, page Read-only

curl 'https://clify-dev.netlify.app/lichess/list-fide-player-broadcasts?id=4100018&slug=Kasparov_Garry&page=2'

list-fide-federations

List FIDE federations with player counts and average top ratings, paginated 30 per page Params: page Read-only

curl 'https://clify-dev.netlify.app/lichess/list-fide-federations?page=2'

get-fide-federation-stats

Get a FIDE federation's world rank, top-10 average rating and player count for classical, rapid and blitz (one item per category) Params: federation* Read-only

curl 'https://clify-dev.netlify.app/lichess/get-fide-federation-stats?federation=Norway'

list-fide-federation-players

List the FIDE players of one federation, sortable by name or rating, paginated 30 per page Params: federation*, order, page Read-only

curl 'https://clify-dev.netlify.app/lichess/list-fide-federation-players?federation=Norway&order=standard&page=2'

search-broadcasts

Search official live tournament broadcasts by keyword, or list live/upcoming ones when q is omitted, 24 per page Params: q, page Read-only

curl 'https://clify-dev.netlify.app/lichess/search-broadcasts?q=Norway+Chess&page=2'

list-broadcast-calendar

List all broadcast tournaments scheduled in the current month's broadcast calendar Params: none Read-only

curl 'https://clify-dev.netlify.app/lichess/list-broadcast-calendar'

list-leaderboards

List lichess's top-10 leaderboard for every rating category (bullet, blitz, rapid, classical, variants) Params: none Read-only

curl 'https://clify-dev.netlify.app/lichess/list-leaderboards'

list-online-players

List the strongest lichess players who are online right now, with their rating (username is the last path segment of url) Params: none Read-only

curl 'https://clify-dev.netlify.app/lichess/list-online-players'

list-tournament-winners

List recent winners of lichess's recurring arena tournaments (Elite, HyperBullet, Yearly, Monthly, Marathon...) by category Params: none Read-only

curl 'https://clify-dev.netlify.app/lichess/list-tournament-winners'

get-tournament

Get a lichess arena tournament's name, format/time control, start time, description and winner profile url Params: id* Read-only

curl 'https://clify-dev.netlify.app/lichess/get-tournament?id=yvqavUey'
