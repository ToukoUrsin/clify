nhl API for agents (unofficial) — JSON over curl | clify

NHL stats (nhl.com/stats) via the NHL public JSON APIs (api.nhle.com/stats/rest and api-web.nhle.com). Covers league leaders, skater, goalie and team stat reports, player search, profiles and game logs, game details, standings, scores and schedules.

Host: nhl.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

get-skater-leaders

Top-10 skater leaders for points, goals or assists in a season (optionally rookies or defensemen only) Params: stat*, cayenneExp

curl 'https://clify-dev.netlify.app/nhl/get-skater-leaders?cayenneExp=season%3D20262027+and+gameType%3D2+and+isRookie+%3D+%27Y%27'
