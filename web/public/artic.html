artic API for agents (unofficial) — JSON over curl

Art Institute of Chicago collection. The CLI queries the museum's official public JSON API (api.artic.edu) for artworks, artists, exhibitions, events, articles, category terms and IIIF manifests, and adds the website's related-artworks lookup.

Host: artic.edu. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-artworks

Full-text search of the collection's artworks, with optional filters (public domain, on view, department, artist id), sort by date and pagination Params: q, public_domain, on_view, department, artist_id, sort_date, api_fields, api_limit, page Read-only

curl 'https://clify-dev.netlify.app/artic/search-artworks?q=monet&public_domain=true&on_view=true&department=Arts+of+the+Americas&artist_id=34996'

facet-artworks

Get facet counts (aggregation buckets) over the whole artwork collection for a keyword field such as department, classification or artist Params: field, size Read-only

curl 'https://clify-dev.netlify.app/artic/facet-artworks?field=department_title.keyword'

get-artwork

Get full details of one artwork by numeric id (title, artist, date, medium, dimensions, credit line, gallery, description, image id) Params: id*, api_fields Read-only

curl 'https://clify-dev.netlify.app/artic/get-artwork'

get-artworks

Fetch several artworks at once by a comma-separated list of ids Params: ids*, api_fields Read-only

curl 'https://clify-dev.netlify.app/artic/get-artworks?ids=28560%2C111628'

get-artwork-manifest

Get the IIIF Presentation manifest for an artwork (image service URLs, label, metadata) Params: id* Read-only

curl 'https://clify-dev.netlify.app/artic/get-artwork-manifest'

search-artists

Search artists by name. The returned id works with get-artist and the artist_id filter of search-artworks. Params: q*, api_fields, api_limit, page Read-only

curl 'https://clify-dev.netlify.app/artic/search-artists?q=hopper'

get-artist

Get details of one artist by id (name, alternate names, birth and death dates, biography) Params: id* Read-only

curl 'https://clify-dev.netlify.app/artic/get-artist'

search-exhibitions

Search museum exhibitions (current and past) by keyword Params: q, api_fields, api_limit, page Read-only

curl 'https://clify-dev.netlify.app/artic/search-exhibitions?q=cassatt'

get-exhibition

Get details of one exhibition by id (dates, gallery, description, artworks shown) Params: id* Read-only

curl 'https://clify-dev.netlify.app/artic/get-exhibition'

search-events

Search museum events (tours, talks, programs) by keyword Params: q, api_fields, api_limit, page Read-only

curl 'https://clify-dev.netlify.app/artic/search-events?api_limit=5'

search-articles

Search the museum's editorial articles by keyword Params: q, api_fields, api_limit, page Read-only

curl 'https://clify-dev.netlify.app/artic/search-articles?q=nighthawks'

search-category-terms

Search category terms (styles, subjects, themes, classifications, materials, techniques, departments) Params: q, subtype, api_fields, api_limit, page Read-only

curl 'https://clify-dev.netlify.app/artic/search-category-terms?q=impressionism'
