smhi API for agents (unofficial) — JSON over curl

SMHI (Swedish Meteorological and Hydrological Institute): look up places, get current weather, 10-day forecasts and recent observed weather, see active weather warnings, search SMHI's open-data catalog, download station observations from the open metobs API, and search or read knowledge-bank and news articles.

Host: smhi.se. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-places

Find places in Sweden by name. Returns the geonameid and lat/lon that the forecast and warning commands take. Params: query* Read-only

curl 'https://clify-dev.netlify.app/smhi/search-places?query=Uppsala'

get-current-weather

Get the current weather (temperature and weather symbol) for a place, by geonameid. Params: geonameid* Read-only

curl 'https://clify-dev.netlify.app/smhi/get-current-weather?geonameid=2673730'

get-forecast

Get the 10-day weather forecast for a place, by geonameid. Returns one entry per day with a summary, midday values and hourly data. Params: geonameid* Read-only

curl 'https://clify-dev.netlify.app/smhi/get-forecast?geonameid=2666199'

get-recent-weather

Get the analysed/observed weather for the past hours at a place (MESAN analysis), by geonameid. Params: geonameid* Read-only

curl 'https://clify-dev.netlify.app/smhi/get-recent-weather?geonameid=2666199'

get-place-warnings

Get the most severe active warnings and advisories (level, type and count) at a lat/lon coordinate. Params: lat*, lon* Read-only

curl 'https://clify-dev.netlify.app/smhi/get-place-warnings?lat=59.85&lon=17.6333333'

get-national-warning-level

Get the most severe weather-warning level currently active anywhere in Sweden (e.g. YELLOW). Params: none Read-only

curl 'https://clify-dev.netlify.app/smhi/get-national-warning-level'

list-warnings

List all active weather warnings and advisories in Sweden, with level, event type, area, time window and descriptions. Params: none Read-only

curl 'https://clify-dev.netlify.app/smhi/list-warnings'

search-open-data

Search SMHI's open-data catalog for datasets by keyword. Use query 'all' to list every dataset. Params: query* Read-only

curl 'https://clify-dev.netlify.app/smhi/search-open-data?query=temperatur'

get-open-data-dataset

Get full metadata for one open-data catalog dataset, by its name slug (from search-open-data). Params: name* Read-only

curl 'https://clify-dev.netlify.app/smhi/get-open-data-dataset?name=se-acmf-meteorologiska-observationer-lufttemperatur-timvarde'

list-observation-stations

List the meteorological observation stations that measure a parameter (metobs open API). Returns station keys for get-station-observations. Params: parameter* Read-only

curl 'https://clify-dev.netlify.app/smhi/list-observation-stations?parameter=1'

get-latest-observations-all-stations

Get the latest-hour observed value of a parameter from every active station in one call. Params: parameter* Read-only

curl 'https://clify-dev.netlify.app/smhi/get-latest-observations-all-stations?parameter=1'

get-station

Get details for one observation station and parameter: owner, position history, active status and available data periods. Params: parameter*, station* Read-only

curl 'https://clify-dev.netlify.app/smhi/get-station?parameter=1&station=97510'

get-station-observations

Get observed values (timestamp in epoch ms, value, quality code) for one station, parameter and time period. Params: parameter*, station*, period Read-only

curl 'https://clify-dev.netlify.app/smhi/get-station-observations?parameter=1&station=97510&period=latest-months'

search-knowledge-bank

Search SMHI's knowledge bank (Kunskapsbanken) articles on meteorology, hydrology, oceanography and climate. Optionally filter by topic. Params: query*, topic, startAtHit Read-only

curl 'https://clify-dev.netlify.app/smhi/search-knowledge-bank?query=%C3%A5ska'

get-knowledge-article

Read a knowledge-bank article, by topic and slug (from the search-knowledge-bank url /kunskapsbanken/{topic}/{slug}). Params: topic*, slug* Read-only

curl 'https://clify-dev.netlify.app/smhi/get-knowledge-article?topic=meteorologi&slug=svenska-nederbordsrekord'

get-news-article

Read an SMHI news article, by slug (path segment after /nyheter/nyheter/). Params: slug* Read-only

curl 'https://clify-dev.netlify.app/smhi/get-news-article?slug=2026-10-08-wmo-el-nino-ar-fast-etablerad-och-blir-snabbt-starkare'
