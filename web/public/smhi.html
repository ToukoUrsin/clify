smhi API for agents (unofficial) — JSON over curl | clify

SMHI (Swedish Meteorological and Hydrological Institute): look up places, get current weather, 10-day forecasts and recent observed weather, see active weather warnings, search SMHI's open-data catalog, download station observations from the open metobs API, and search or read knowledge-bank and news articles.

Host: smhi.se. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-places

Find places in Sweden by name. Returns the geonameid and lat/lon that the forecast and warning commands take. Params: query*

curl 'https://clify-dev.netlify.app/smhi/search-places'

get-current-weather

Get the current weather (temperature and weather symbol) for a place, by geonameid. Params: geonameid*

curl 'https://clify-dev.netlify.app/smhi/get-current-weather'

get-forecast

Get the 10-day weather forecast for a place, by geonameid. Returns one entry per day with a summary, midday values and hourly data. Params: geonameid*

curl 'https://clify-dev.netlify.app/smhi/get-forecast'

get-recent-weather

Get the analysed/observed weather for the past hours at a place (MESAN analysis), by geonameid. Params: geonameid*

curl 'https://clify-dev.netlify.app/smhi/get-recent-weather'

get-place-warnings

Get the most severe active warnings and advisories (level, type and count) at a lat/lon coordinate. Params: lat*, lon*

curl 'https://clify-dev.netlify.app/smhi/get-place-warnings'

get-national-warning-level

Get the most severe weather-warning level currently active anywhere in Sweden (e.g. YELLOW). Params: none

curl 'https://clify-dev.netlify.app/smhi/get-national-warning-level'

list-warnings

List all active weather warnings and advisories in Sweden, with level, event type, area, time window and descriptions. Params: none

curl 'https://clify-dev.netlify.app/smhi/list-warnings'

search-open-data

Search SMHI's open-data catalog for datasets by keyword. Use query 'all' to list every dataset. Params: query*

curl 'https://clify-dev.netlify.app/smhi/search-open-data'

get-open-data-dataset

Get full metadata for one open-data catalog dataset, by its name slug (from search-open-data). Params: name*

curl 'https://clify-dev.netlify.app/smhi/get-open-data-dataset'

list-observation-stations

List the meteorological observation stations that measure a parameter (metobs open API). Returns station keys for get-station-observations. Params: parameter*

curl 'https://clify-dev.netlify.app/smhi/list-observation-stations'

get-latest-observations-all-stations

Get the latest-hour observed value of a parameter from every active station in one call. Params: parameter*

curl 'https://clify-dev.netlify.app/smhi/get-latest-observations-all-stations'

get-station

Get details for one observation station and parameter: owner, position history, active status and available data periods. Params: parameter*, station*

curl 'https://clify-dev.netlify.app/smhi/get-station'

get-station-observations

Get observed values (timestamp in epoch ms, value, quality code) for one station, parameter and time period. Params: parameter*, station*, period

curl 'https://clify-dev.netlify.app/smhi/get-station-observations'

search-knowledge-bank

Search SMHI's knowledge bank (Kunskapsbanken) articles on meteorology, hydrology, oceanography and climate. Optionally filter by topic. Params: query*, topic, startAtHit

curl 'https://clify-dev.netlify.app/smhi/search-knowledge-bank?query=%C3%A5ska'

get-knowledge-article

Read a knowledge-bank article, by topic and slug (from the search-knowledge-bank url /kunskapsbanken/{topic}/{slug}). Params: topic*, slug*

curl 'https://clify-dev.netlify.app/smhi/get-knowledge-article'

get-news-article

Read an SMHI news article, by slug (path segment after /nyheter/nyheter/). Params: slug*

curl 'https://clify-dev.netlify.app/smhi/get-news-article'
