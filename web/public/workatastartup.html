workatastartup API for agents (unofficial) — JSON over curl

Y Combinator's Work at a Startup job board: search YC startup jobs by keyword and location, browse role and location listings, and read job and company pages including application links.

Host: workatastartup.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-jobs

Search YC startup jobs with a plain-language query, e.g. 'backend engineer in San Francisco'. Returns job id, title, company, location, salary, type and apply link. Params: q* Read-only

curl 'https://clify-dev.netlify.app/workatastartup/search-jobs?q=backend+engineer+in+San+Francisco'

get-job

Get a job's page text: company, title, location, type, salary, equity, experience, visa and description. Use the id from search-jobs. Params: jobId* Read-only

curl 'https://clify-dev.netlify.app/workatastartup/get-job?jobId=92623'

get-company

Get a YC company's profile page text, including its batch and open jobs. Use the companySlug from search-jobs. Params: companySlug* Read-only

curl 'https://clify-dev.netlify.app/workatastartup/get-company?companySlug=getcrux'
