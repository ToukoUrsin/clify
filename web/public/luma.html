luma API for agents (unofficial) — JSON over curl

Luma (lu.ma / luma.com) event discovery: search public events by city, category or keyword, browse community calendars, and get event details, dates, venues and URLs through Luma's JSON API.

Host: lu.ma. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-events

List or keyword-search upcoming public events in a Luma city (default San Francisco) or a category such as ai/tech, with dates, area and event URL slug Params: placeId, query, slug, categoryId, latitude, longitude, api_limit, cursor Read-only

curl 'https://clify-dev.netlify.app/luma/search-events?placeId=discplace-BDj7GNbGlsF7Cka&query=AI&slug=ai&categoryId=cat-ai'

list-calendar-events

List upcoming or past events of a community calendar (e.g. an SF AI meetup group), optionally filtered by tag or keyword Params: calendarId*, period, query, tagId, api_limit, cursor Read-only

curl 'https://clify-dev.netlify.app/luma/list-calendar-events?calendarId=cal-S7gDcd9Akzu62RD&period=past'

get-event

Get full details of one event: name, start/end time, timezone, venue/address info, location type, host calendar and URL slug Params: eventId* Read-only

curl 'https://clify-dev.netlify.app/luma/get-event?eventId=evt-hDW5fCJ4INPvyVy'

resolve-url

Resolve a luma.com URL slug (city like sf, category like ai, calendar like genai-sf, or event slug) to its kind and ids plus embedded data Params: url* Read-only

curl 'https://clify-dev.netlify.app/luma/resolve-url?url=sf-hackersquad'

list-categories

List Luma discovery categories (AI, Tech, Crypto, ...) with slugs, ids and upcoming event counts Params: api_limit Read-only

curl 'https://clify-dev.netlify.app/luma/list-categories'

get-category

Get a category page (e.g. ai, tech): description, event count and featured timeline calendars such as conference side-event calendars Params: slug* Read-only

curl 'https://clify-dev.netlify.app/luma/get-category?slug=ai'

list-place-calendars

List featured community calendars (organizer groups) for a city, with slug, description and website Params: placeId* Read-only

curl 'https://clify-dev.netlify.app/luma/list-place-calendars?placeId=discplace-BDj7GNbGlsF7Cka'

list-calendar-map-events

List a calendar's events with name, start time, coordinates and full luma.com event URL (href) Params: calendarId*, period, api_limit Read-only

curl 'https://clify-dev.netlify.app/luma/list-calendar-map-events?calendarId=cal-S7gDcd9Akzu62RD'

get-map-events

List a city's events inside a map bounding box (north/south/east/west) with name, start time and coordinates Params: placeId*, north*, south*, east*, west* Read-only

curl 'https://clify-dev.netlify.app/luma/get-map-events?placeId=discplace-BDj7GNbGlsF7Cka&north=37.83806629645812&south=37.72858084335202&east=-122.33619373515201&west=-122.48450916484798'

get-place

Get a discovery city's details: name, slug, description, timezone, event count and featured event ids Params: placeId* Read-only

curl 'https://clify-dev.netlify.app/luma/get-place?placeId=discplace-BDj7GNbGlsF7Cka'

list-places

List Luma discovery cities (nearest first) with place ids, slugs and event counts Params: featuredPlaceId Read-only

curl 'https://clify-dev.netlify.app/luma/list-places'

list-featured-calendars

List major featured calendars on the Luma homepage (e.g. tech/climate weeks) with dates and slugs Params: none Read-only

curl 'https://clify-dev.netlify.app/luma/list-featured-calendars'
