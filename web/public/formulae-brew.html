formulae-brew API for agents (unofficial) — JSON over curl

Homebrew Formulae (formulae.brew.sh), the official Homebrew package index. This CLI searches formulae and casks, fetches full package metadata (versions, dependencies, bottles, artifacts, install analytics), lists every formula, cask and cask font, and reads Homebrew's public install analytics rankings.

Host: formulae.brew.sh. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-packages

Keyword search across Homebrew formulae and casks (Algolia index used by the site's search box); returns matching package page URLs and names Params: query*, page, hits_per_page Read-only

curl 'https://clify-dev.netlify.app/formulae-brew/search-packages?query=python'

get-formula

Get full metadata for one homebrew-core formula by name: description, versions, license, dependencies, bottles, caveats and install analytics Params: name* Read-only

curl 'https://clify-dev.netlify.app/formulae-brew/get-formula?name=python%403.15'

get-cask

Get full metadata for one homebrew-cask cask (macOS app or font) by token: name, version, download URL, artifacts, dependencies, conflicts and analytics Params: token* Read-only

curl 'https://clify-dev.netlify.app/formulae-brew/get-cask?token=firefox'

list-formulae

List every homebrew-core formula with full metadata (very large response, several thousand items) Params: none Read-only

curl 'https://clify-dev.netlify.app/formulae-brew/list-formulae'

list-casks

List every homebrew-cask cask (apps and fonts) with full metadata (very large response, several thousand items) Params: none Read-only

curl 'https://clify-dev.netlify.app/formulae-brew/list-casks'

list-cask-fonts

List all font casks (token and detail URL) from the cask-font index page; much smaller than list-casks Params: none Read-only

curl 'https://clify-dev.netlify.app/formulae-brew/list-cask-fonts'

get-analytics

Get Homebrew's ranked install analytics (top formulae installs, installs-on-request, cask installs, build errors, or macOS versions) for a 30/90/365-day period Params: category*, period Read-only

curl 'https://clify-dev.netlify.app/formulae-brew/get-analytics?category=install-on-request&period=30d'
