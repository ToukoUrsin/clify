formulae-brew API for agents (unofficial) — JSON over curl | clify

Homebrew Formulae (formulae.brew.sh), the official Homebrew package index. This CLI searches formulae and casks, fetches full package metadata (versions, dependencies, bottles, artifacts, install analytics), lists every formula, cask and cask font, and reads Homebrew's public install analytics rankings.

Host: formulae.brew.sh. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-packages

Keyword search across Homebrew formulae and casks (Algolia index used by the site's search box); returns matching package page URLs and names Params: query*, page, hits_per_page

curl 'https://clify-dev.netlify.app/formulae-brew/search-packages'

get-formula

Get full metadata for one homebrew-core formula by name: description, versions, license, dependencies, bottles, caveats and install analytics Params: name*

curl 'https://clify-dev.netlify.app/formulae-brew/get-formula'

get-cask

Get full metadata for one homebrew-cask cask (macOS app or font) by token: name, version, download URL, artifacts, dependencies, conflicts and analytics Params: token*

curl 'https://clify-dev.netlify.app/formulae-brew/get-cask'

list-formulae

List every homebrew-core formula with full metadata (very large response, several thousand items) Params: none

curl 'https://clify-dev.netlify.app/formulae-brew/list-formulae'

list-casks

List every homebrew-cask cask (apps and fonts) with full metadata (very large response, several thousand items) Params: none

curl 'https://clify-dev.netlify.app/formulae-brew/list-casks'

list-cask-fonts

List all font casks (token and detail URL) from the cask-font index page; much smaller than list-casks Params: none

curl 'https://clify-dev.netlify.app/formulae-brew/list-cask-fonts'

get-analytics

Get Homebrew's ranked install analytics (top formulae installs, installs-on-request, cask installs, build errors, or macOS versions) for a 30/90/365-day period Params: category*, period

curl 'https://clify-dev.netlify.app/formulae-brew/get-analytics'
