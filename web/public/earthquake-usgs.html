earthquake-usgs API for agents (unofficial) — JSON over curl | clify

USGS Earthquake Hazards Program (Latest Earthquakes map). This CLI queries real-time earthquake feeds, the ComCat FDSN event search and count APIs, event details with products such as PAGER, ShakeMap and aftershock forecasts, geoserve nearby-place and region lookups, and catalog/contributor metadata.

Host: earthquake.usgs.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

get-feed

Get a real-time earthquake summary feed (GeoJSON) for a magnitude threshold and time window, e.g. M2.5+ past day or significant past month Params: magnitude, period

curl 'https://clify-dev.netlify.app/earthquake-usgs/get-feed'

search-earthquakes

Search the ComCat earthquake catalog (FDSN) by time range, magnitude, bounding box or radius, depth, PAGER alert level and event type, with sorting and paging Params: starttime, endtime, minmagnitude, maxmagnitude, minlatitude, maxlatitude, minlongitude, maxlongitude, latitude, longitude, maxradiuskm, mindepth, maxdepth, alertlevel, eventtype, catalog, producttype, orderby, api_limit, offset

curl 'https://clify-dev.netlify.app/earthquake-usgs/search-earthquakes?starttime=2026-10-01&endtime=2026-10-18&minmagnitude=5&orderby=magnitude&api_limit=20'

count-earthquakes

Count catalog events that match search filters (time, magnitude, location radius or bbox, depth, event type) without downloading them Params: starttime, endtime, minmagnitude, maxmagnitude, latitude, longitude, maxradiuskm, minlatitude, maxlatitude, minlongitude, maxlongitude, mindepth, maxdepth, alertlevel, eventtype

curl 'https://clify-dev.netlify.app/earthquake-usgs/count-earthquakes?starttime=2026-10-01&minmagnitude=4&latitude=7.5868&longitude=-80.769&maxradiuskm=400'

get-event

Get full detail for one earthquake event by id, including all products (origin, shakemap, losspager, dyfi, moment-tensor, oaf) and their content file URLs Params: eventid*

curl 'https://clify-dev.netlify.app/earthquake-usgs/get-event'

get-aftershock-forecast

Get the aftershock forecast (oaf product forecast.json: observed counts, model parameters, probabilities) for an event's oaf product Params: productId*

curl 'https://clify-dev.netlify.app/earthquake-usgs/get-aftershock-forecast'

get-shakemap-contours

Get ShakeMap intensity (MMI) contour lines as GeoJSON for an event's shakemap product Params: productId*

curl 'https://clify-dev.netlify.app/earthquake-usgs/get-shakemap-contours'

find-nearby-places

Find populated places (GeoNames) near a latitude/longitude within a radius, optionally filtered by minimum population Params: latitude*, longitude*, maxradiuskm, minpopulation, api_limit

curl 'https://clify-dev.netlify.app/earthquake-usgs/find-nearby-places?latitude=34.05&longitude=-118.25&maxradiuskm=50&minpopulation=10000'

get-event-places

Get the 5 reference places the event page lists near an epicenter (distance and azimuth), as used in event titles Params: latitude*, longitude*

curl 'https://clify-dev.netlify.app/earthquake-usgs/get-event-places?latitude=7.5868&longitude=-80.769'

get-regions

Get regional info for a lat/lon: admin region/country, Flinn-Engdahl region, authoritative network, NEIC catalog/response regions, offshore and tectonic summary Params: latitude*, longitude*

curl 'https://clify-dev.netlify.app/earthquake-usgs/get-regions?latitude=7.5868&longitude=-80.769'

get-catalog-metadata

List the allowed values for FDSN search filters: catalogs, contributors, product types, event types and magnitude types Params: none

curl 'https://clify-dev.netlify.app/earthquake-usgs/get-catalog-metadata'

list-contributors

List ComCat contributing seismic networks with id, full name, aliases and info URL Params: none

curl 'https://clify-dev.netlify.app/earthquake-usgs/list-contributors'
