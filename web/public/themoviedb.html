themoviedb API for agents (unofficial) — JSON over curl

The Movie Database (TMDB), a community database of movies, TV shows and people. This CLI scrapes the public, logged-out website for trending and popular titles, search, discover and preset listings, movie, TV, season, person and collection details, cast, reviews and keyword/genre listings.

Host: themoviedb.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

get-trending

Trending movies and TV shows today or this week (home page scroller, 20 items) Params: group Read-only

curl 'https://clify-dev.netlify.app/themoviedb/get-trending?group=today'

list-popular-home

Home page 'What's Popular' titles by channel (streaming, on TV, in theatres) Params: group Read-only

curl 'https://clify-dev.netlify.app/themoviedb/list-popular-home?group=streaming'

search

Keyword search on TMDB, filtered to one result type (movie, tv, person, collection, keyword, company, network) Params: query*, type, page Read-only

curl 'https://clify-dev.netlify.app/themoviedb/search?query=star+wars&page=2'

discover-movies

Discover movies with filters (genres, keywords, rating, vote count, dates, language, runtime) and sort order, paginated Params: page, sort_by, with_genres, with_keywords, vote_count_gte, vote_average_gte, vote_average_lte, release_date_gte, release_date_lte, with_original_language, runtime_gte, runtime_lte, discover_preset Read-only

curl 'https://clify-dev.netlify.app/themoviedb/discover-movies'
