producthunt API for agents (unofficial) — JSON over curl

Product Hunt (producthunt.com), a site where new tech products launch daily. This CLI reads Product Hunt's public Atom feed of the latest featured launches, optionally filtered by topic, and returns each launch's post id, launch date, product name, tagline, product page URL and author.

Host: producthunt.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

list-launches

List the latest featured Product Hunt launches, newest first, optionally filtered by topic slug. Each entry has the post id, launch date, product name, tagline, product page URL and author. Params: category Read-only

curl 'https://clify-dev.netlify.app/producthunt/list-launches?category=productivity'
