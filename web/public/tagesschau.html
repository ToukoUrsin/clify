tagesschau API for agents (unofficial) — JSON over curl

tagesschau.de is the ARD-aktuell German news site. This CLI searches news, lists top, ressort, regional, daily-archive and topic news, fetches full articles as JSON, and lists live streams.

Host: tagesschau.de. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-news

Full-text search of tagesschau news via the public api2u API. Returns stories with title, date, teaser and detail URLs, newest first. Params: searchText*, pageSize, resultPage Read-only

curl 'https://clify-dev.netlify.app/tagesschau/search-news?searchText=Klimawandel&pageSize=10&resultPage=1'

search-site

Website search with a media-type filter (article, video, audio, image gallery). Returns per-type counts and result items, newest first. Params: searchText*, documentType, pageIndex Read-only

curl 'https://clify-dev.netlify.app/tagesschau/search-site?searchText=Klimawandel&documentType=article&pageIndex=1'

get-homepage-news

Current top news shown on the tagesschau.de homepage, as JSON. Params: none Read-only

curl 'https://clify-dev.netlify.app/tagesschau/get-homepage-news'

list-news

Latest news, optionally filtered by ressort (section) and German federal-state region(s). Params: ressort, regions Read-only

curl 'https://clify-dev.netlify.app/tagesschau/list-news?ressort=wirtschaft&regions=1'

get-article

Full article as JSON (text blocks, tags, images, video), looked up by its 3-segment web path ressort/subressort/slug. Params: ressort*, subressort*, slug* Read-only

curl 'https://clify-dev.netlify.app/tagesschau/get-article'

list-channels

Live channels and streams (e.g. tagesschau24) with stream URLs. Params: none Read-only

curl 'https://clify-dev.netlify.app/tagesschau/list-channels'

list-news-by-date

All news published on a given day, from the 7-day 'alle Meldungen' archive. Defaults to today. Params: datum Read-only

curl 'https://clify-dev.netlify.app/tagesschau/list-news-by-date?datum=2026-10-17'

list-topic-news

Latest articles on a topic/tag page (e.g. ukraine, antarktis). Params: topic* Read-only

curl 'https://clify-dev.netlify.app/tagesschau/list-topic-news'
