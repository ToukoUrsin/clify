data-cdc API for agents (unofficial) — JSON over curl

data.cdc.gov is the CDC's open-data portal (Socrata). This CLI searches the dataset catalog, lists categories and tags, reads dataset metadata, and queries or exports dataset rows through the public Socrata Discovery, SODA and views APIs.

Host: data.cdc.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-datasets

Search the data.cdc.gov catalog by keyword, with optional category/tag/type filters, sort order and paging Params: q, categories, tags, only, order, api_limit, offset Read-only

curl 'https://clify-dev.netlify.app/data-cdc/search-datasets?q=influenza&categories=Vaccinations&tags=flu&only=dataset&order=updatedAt'

list-categories

List all dataset categories on data.cdc.gov with their dataset counts Params: none Read-only

curl 'https://clify-dev.netlify.app/data-cdc/list-categories'

list-tags

List the most-used dataset tags on data.cdc.gov with their counts Params: none Read-only

curl 'https://clify-dev.netlify.app/data-cdc/list-tags'

autocomplete-datasets

Suggest dataset titles that match a partial search term Params: q* Read-only

curl 'https://clify-dev.netlify.app/data-cdc/autocomplete-datasets?q=influ'

get-dataset

Get full metadata for one dataset by its 4x4 id, including columns, field names, data types and stats Params: id* Read-only

curl 'https://clify-dev.netlify.app/data-cdc/get-dataset'

get-dataset-metadata

Get a dataset's catalog metadata: tags, contact info, custom fields, ISO update dates and API/web URIs Params: id* Read-only

curl 'https://clify-dev.netlify.app/data-cdc/get-dataset-metadata'

query-rows

Query a dataset's rows with SoQL (SODA API): filter, full-text search, select/aggregate, group, sort and page Params: id*, where, q, select, group, order, api_limit, offset Read-only

curl 'https://clify-dev.netlify.app/data-cdc/query-rows?where=jurisdiction%3D%27United+States%27&q=Texas&select=geography%2Ccount%28*%29&group=geography&order=week_ending_date+DESC&api_limit=5'

run-soql-query

Run a full SoQL query string against a dataset through the v3 query API, e.g. 'select jurisdiction, sum(influenza_deaths) group by jurisdiction limit 10' Params: id*, query* Read-only

curl 'https://clify-dev.netlify.app/data-cdc/run-soql-query?query=select+jurisdiction%2C+sum%28influenza_deaths%29+group+by+jurisdiction+limit+10'

export-rows

Download a dataset export in JSON: view metadata under meta, rows as positional arrays under data Params: id*, max_rows Read-only

curl 'https://clify-dev.netlify.app/data-cdc/export-rows?max_rows=5'

get-data-catalog

Get the full DCAT (Project Open Data) catalog of every public dataset on data.cdc.gov Params: none Read-only

curl 'https://clify-dev.netlify.app/data-cdc/get-data-catalog'
