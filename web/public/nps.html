nps API for agents (unofficial) — JSON over curl

National Park Service (nps.gov): find parks by state, activity, topic or location; read park details, alerts, parking and conditions; search articles and multimedia; get photo metadata, video captions and NWS weather for parks.

Host: nps.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-parks

Find National Park Service units, filtered by state, activity or topic, or sorted by distance from a lat/lng point Params: states, activities, topics, lat, lng, sort Read-only

curl 'https://clify-dev.netlify.app/nps/search-parks?states=CA&activities=3&topics=125&lat=37.84835&lng=-119.55696'

search-parks-by-name

Search parks by name or keyword (e.g. 'Yosemite') and get park codes, descriptions and coordinates Params: q*, pageSize Read-only

curl 'https://clify-dev.netlify.app/nps/search-parks-by-name?q=Yosemite'

list-park-filters

List all filter values for search-parks: topic ids, activity ids, state codes, and every park code with its name Params: none Read-only

curl 'https://clify-dev.netlify.app/nps/list-park-filters'

list-related-subjects

Get NPS subject/topic pages related to a set of activity and topic ids, with the park codes linked to each Params: activities, topics, randomcount Read-only

curl 'https://clify-dev.netlify.app/nps/list-related-subjects?activities=3'

get-park

Get a park's overview (schema.org linked data): description, phone, address, visitor centers and opening hours Params: code* Read-only

curl 'https://clify-dev.netlify.app/nps/get-park?code=jotr'

get-park-facilities

Get a park's structured operational data: addresses plus parking lots with capacity, live status, schedules and predicted occupancy Params: code* Read-only

curl 'https://clify-dev.netlify.app/nps/get-park-facilities?code=yose'

get-park-alerts

Get current alerts for one park: closures, road closures, cautions and information Params: code* Read-only

curl 'https://clify-dev.netlify.app/nps/get-park-alerts?code=jotr'

list-nps-alerts

List the nationwide sitewide alerts for all parks (closures, dangers, information) with park and state Params: none Read-only

curl 'https://clify-dev.netlify.app/nps/list-nps-alerts'

get-park-banner-image

Get a park's banner photo: image path, credit, alt text and crops Params: sitecode* Read-only

curl 'https://clify-dev.netlify.app/nps/get-park-banner-image?sitecode=jotr'

search-multimedia

Search NPS photos, videos, audio and webcams by keyword, with optional Solr filter (type, park) and sort Params: q, fq, sort, start Read-only

curl 'https://clify-dev.netlify.app/nps/search-multimedia?q=grizzly+bear&fq=Parks_Item%3A%22Yellowstone+National+Park%22&sort=score+desc'

search-articles

Search NPS articles, people and places pages by keyword (returns /articles/... URLs) Params: q*, rows, start Read-only

curl 'https://clify-dev.netlify.app/nps/search-articles?q=campfire'

get-article

Read an NPS article page by slug (/articles/{slug}.htm) Params: slug* Read-only

curl 'https://clify-dev.netlify.app/nps/get-article?slug=campfires'

get-photo

Get NPGallery photo/asset metadata: title, description, credit/copyright, license, dimensions and EXIF Params: id* Read-only

curl 'https://clify-dev.netlify.app/nps/get-photo?id=02FF546C-1DD8-B71B-0BAB-26F1AE8E2D57'

get-video-captions

Download the WebVTT closed-caption transcript of an NPS video Params: id* Read-only

curl 'https://clify-dev.netlify.app/nps/get-video-captions?id=8E8EE545-035D-3BF9-1D8E7C7B978B392C'

geocode-suggest

Get place suggestions for a location string, with magicKeys to resolve into coordinates (US only) Params: text*, maxSuggestions Read-only

curl 'https://clify-dev.netlify.app/nps/geocode-suggest?text=Yosemite'

geocode-location

Resolve a geocode-suggest magicKey into lat/lng (location.y / location.x) for search-parks Params: magicKey* Read-only

curl 'https://clify-dev.netlify.app/nps/geocode-location?magicKey=dHA9MCN0dj02NWI4NWUyYyNsb2M9MjUzNjQ2NyNsbmc9NDEjcGw9MzIyNTc1NiNsYnM9MTQ6ODU1NjUxODIjbG49V29ybGQ%3D'

get-weather-point

Look up the NWS forecast grid (office, gridX, gridY), nearest city, time zone and sunrise/sunset for a lat/lng Params: lat*, lng* Read-only

curl 'https://clify-dev.netlify.app/nps/get-weather-point?lat=34.0114&lng=-116.0975'

get-weather-forecast

Get the 7-day NWS forecast periods for a grid point (from get-weather-point) Params: office*, gridX*, gridY* Read-only

curl 'https://clify-dev.netlify.app/nps/get-weather-forecast?office=PSR&gridX=16&gridY=103'

get-weather-alerts

Get active NWS watches, warnings and advisories, optionally limited to a lat,lng point (e.g. a park location) or a state/area code Params: point, area, severity, api_limit Read-only

curl 'https://clify-dev.netlify.app/nps/get-weather-alerts?point=34.0114%2C-116.0975&area=NC&api_limit=20'

get-weather-observation

Get the latest observed conditions (temperature, wind, etc.) from an NWS weather station Params: station* Read-only

curl 'https://clify-dev.netlify.app/nps/get-weather-observation?station=LTHC1'
