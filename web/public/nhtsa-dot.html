nhtsa-dot API for agents (unofficial) — JSON over curl

NHTSA vPIC (Product Information Catalog and Vehicle Listing): decode VINs and WMIs, look up makes, models and manufacturers through the public vPIC REST API, browse Canadian Vehicle Specifications, list approved replica manufacturers, and view MID manufacturer and vehicle-modifier detail pages.

Host: vpic.nhtsa.dot.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

decode-vin

Decode a full or partial VIN (use * as a wildcard) into a flat record with make, model, year, body, engine, safety equipment, plant and more Params: vin*, modelyear Read-only

curl 'https://clify-dev.netlify.app/nhtsa-dot/decode-vin?modelyear=2011'

decode-wmi

Decode a World Manufacturer Identifier (the first 3 or 6 VIN characters) into its manufacturer, make and vehicle type Params: wmi* Read-only

curl 'https://clify-dev.netlify.app/nhtsa-dot/decode-wmi'

list-models-for-make-year

List the models a make offers in a given model year Params: make*, year* Read-only

curl 'https://clify-dev.netlify.app/nhtsa-dot/list-models-for-make-year'

list-models-for-make-id

List all models for a make, identified by its numeric vPIC Make_ID Params: makeId* Read-only

curl 'https://clify-dev.netlify.app/nhtsa-dot/list-models-for-make-id'

list-all-makes

List every make in vPIC with its Make_ID (a large list, roughly 10k entries) Params: none Read-only

curl 'https://clify-dev.netlify.app/nhtsa-dot/list-all-makes'

get-manufacturer-details

Look up manufacturers by full or partial name (or numeric manufacturer ID) and get address, country and vehicle types Params: manufacturer*, page Read-only

curl 'https://clify-dev.netlify.app/nhtsa-dot/get-manufacturer-details'

list-wmis-for-manufacturer

List the WMI codes assigned to a manufacturer, matched by full or partial name or ID Params: manufacturer* Read-only

curl 'https://clify-dev.netlify.app/nhtsa-dot/list-wmis-for-manufacturer'

list-canadian-spec-makes

List the makes that have Canadian Vehicle Specifications data for a model year Params: year* Read-only

curl 'https://clify-dev.netlify.app/nhtsa-dot/list-canadian-spec-makes?year=2020'

list-canadian-spec-models

List the Canadian Vehicle Specifications model names for a year, optionally limited to one make Params: year*, make Read-only
