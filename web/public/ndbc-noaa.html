ndbc-noaa API for agents (unofficial) — JSON over curl

NOAA National Data Buoy Center (NDBC): marine buoy and C-MAN weather observations. This CLI fetches latest observations, realtime and 5-day station data, and station metadata from NDBC's static data files.

Host: ndbc.noaa.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

get-latest-observation

Get the most recent marine weather observation for one station (wind, waves, pressure, temperatures) as an RSS item with an HTML-formatted description Params: station* Read-only

curl 'https://clify-dev.netlify.app/ndbc-noaa/get-latest-observation'

get-realtime-data

Get realtime standard meteorological data for a station (about the last 45 days, newest first) as a whitespace-delimited text table: WDIR, WSPD/GST in m/s, WVHT in m, PRES in hPa, ATMP/WTMP/DEWP in de Params: station* Read-only

curl 'https://clify-dev.netlify.app/ndbc-noaa/get-realtime-data'

get-5day-data

Get the last 5 days of standard meteorological data for a station (newest first) as a whitespace-delimited text table: WDIR, WSPD/GST in m/s, WVHT in m, PRES in hPa, temps in degC; 'MM' means missing Params: station* Read-only

curl 'https://clify-dev.netlify.app/ndbc-noaa/get-5day-data'

list-latest-observations

Get the latest observation for every reporting station in one whitespace-delimited text table (columns include STN, LAT, LON, WDIR, WSPD, GST, WVHT, PRES, ATMP, WTMP; m/s, m, hPa, degC; 'MM' means mis Params: none Read-only

curl 'https://clify-dev.netlify.app/ndbc-noaa/list-latest-observations'

list-active-stations

List all active NDBC stations with ID, name, coordinates, owner, program, type and whether each reports met data Params: none Read-only

curl 'https://clify-dev.netlify.app/ndbc-noaa/list-active-stations'

get-station-table

Get the full station metadata table (ID, owner, type, hull, name, payload, location, timezone, forecast, note) as pipe-delimited text Params: none Read-only

curl 'https://clify-dev.netlify.app/ndbc-noaa/get-station-table'
