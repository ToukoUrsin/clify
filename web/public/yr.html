yr API for agents (unofficial) — JSON over curl | clify

yr.no (Norwegian Meteorological Institute / NRK weather service): search places and get forecasts, current weather, nowcasts, long-range, coastal/tide/water-level, air quality, aurora, sun/moon, observation history, warnings, mountain pass conditions and meteorologist posts via yr.no's public /api/v0 JSON API.

Host: yr.no. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-locations

Search places worldwide by name; returns location ids (e.g. 1-92416) used by all location commands Params: q*, language

curl 'https://clify-dev.netlify.app/yr/search-locations?q=Bergen'

get-location

Get details for a location id: name, coordinates, elevation, region, time zone and which data types are available (_links) Params: id*, language

curl 'https://clify-dev.netlify.app/yr/get-location'

get-forecast

Daily weather forecast (~9-10 days) for a location: symbols, min/max temperature, precipitation, wind Params: id*

curl 'https://clify-dev.netlify.app/yr/get-forecast'

get-current-weather

Weather for the current hour at a location: symbol, temperature, feels-like, precipitation, wind, UV index Params: id*

curl 'https://clify-dev.netlify.app/yr/get-current-weather'

get-nowcast

Radar-based precipitation nowcast for the next 90 minutes in 5-minute steps (Nordic locations) Params: id*, language

curl 'https://clify-dev.netlify.app/yr/get-nowcast'

get-long-range-forecast

21-day (3 weeks) long-range forecast for a location with daily temperature/precipitation percentiles and weekly summaries Params: id*

curl 'https://clify-dev.netlify.app/yr/get-long-range-forecast'

get-coast-forecast

Coastal/sea forecast for a coastal location: waves, currents, sea temperature plus wind and air temperature per day Params: id*, language

curl 'https://clify-dev.netlify.app/yr/get-coast-forecast'

get-tide

curl 'https://clify-dev.netlify.app/yr/get-tide'

get-water-level

Hourly sea water level for ~9 days (astronomical prediction vs. weather-adjusted forecast, cm) Params: id*, language

curl 'https://clify-dev.netlify.app/yr/get-water-level'

get-air-quality

Hourly air quality forecast (index, severity, health description) for a Norwegian location Params: id*, language

curl 'https://clify-dev.netlify.app/yr/get-air-quality'

get-aurora-forecast

curl 'https://clify-dev.netlify.app/yr/get-aurora-forecast'
