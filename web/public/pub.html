pub API for agents (unofficial) — JSON over curl

pub.dev is the official registry for Dart and Flutter packages. This CLI searches packages and reads package metadata, versions, scores, metrics, docs status, publishers, topics and the atom feeds through pub.dev's public JSON API.

Host: pub.dev. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-packages

Search pub.dev packages by keyword and/or qualifiers (topic:, platform:, sdk:, dependency:, publisher:, is:, license:, has:, updated:), with sort and pagination. Params: q*, sort, page Read-only

curl 'https://clify-dev.netlify.app/pub/search-packages?q=http&sort=like&page=2'

get-package

Get a package's latest version: version number, pubspec (description, dependencies, SDK constraint, repository), archive URL and publish date. Params: name* Read-only

curl 'https://clify-dev.netlify.app/pub/get-package'

list-package-versions

List all published versions of a package, oldest first, with publish date and archive URL. Params: name* Read-only

curl 'https://clify-dev.netlify.app/pub/list-package-versions'

get-package-version

Get the pubspec, archive URL/sha256 and publish date of one specific package version. Params: name*, version* Read-only

curl 'https://clify-dev.netlify.app/pub/get-package-version'

get-package-score

Get a package's pub points (granted/max), like count, 30-day downloads and tags (sdk, platform, publisher, license, etc.). Params: name* Read-only

curl 'https://clify-dev.netlify.app/pub/get-package-score'

get-package-metrics

Get the full analysis scorecard for a package: score, pana report sections, licenses, repository verification, all dependencies and weekly download history. Params: name* Read-only

curl 'https://clify-dev.netlify.app/pub/get-package-metrics'

get-package-likes

Get the number of likes for a package. Params: name* Read-only

curl 'https://clify-dev.netlify.app/pub/get-package-likes'

get-package-publisher

Get the verified publisher ID that owns a package (null if it has no publisher). Params: name* Read-only

curl 'https://clify-dev.netlify.app/pub/get-package-publisher'

get-package-options

Check whether a package is discontinued or unlisted, and which package replaces it. Params: name* Read-only

curl 'https://clify-dev.netlify.app/pub/get-package-options'

get-package-docs-status

List a package's versions with their API documentation (dartdoc) build status and availability. Params: name* Read-only

curl 'https://clify-dev.netlify.app/pub/get-package-docs-status'

get-package-feed

Get the Atom feed of a package's recently published versions, including changelog excerpts. Params: name* Read-only

curl 'https://clify-dev.netlify.app/pub/get-package-feed'

get-publisher

Get a verified publisher's description, website URL and contact email. Params: publisher* Read-only

curl 'https://clify-dev.netlify.app/pub/get-publisher'

curl 'https://clify-dev.netlify.app/pub/list-publisher-packages'
