swpc-noaa API for agents (unofficial) — JSON over curl

NOAA Space Weather Prediction Center (SWPC): a CLI for live space-weather data. It reads the NOAA R/S/G scales, the planetary K-index, solar wind and F10.7 summaries, GOES X-ray, proton and electron feeds, alerts, text forecasts and the HAPI time-series API.

Host: swpc.noaa.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

get-noaa-scales

Current NOAA space weather scales and forecast probabilities: R (radio blackout), S (solar radiation) and G (geomagnetic storm). Key -1 is yesterday, 0 is now, 1-3 are forecast days. Params: none Read-only

curl 'https://clify-dev.netlify.app/swpc-noaa/get-noaa-scales'

get-planetary-k-index

Observed 3-hourly planetary Kp index for the last ~7 days, with running a-index and station count. Params: none Read-only

curl 'https://clify-dev.netlify.app/swpc-noaa/get-planetary-k-index'

get-kp-forecast

Planetary K-index observations plus the 3-day forecast (observed, estimated and predicted Kp per 3-hour slot). Params: none Read-only

curl 'https://clify-dev.netlify.app/swpc-noaa/get-kp-forecast'

get-summary

Latest single-value summary: solar wind speed, solar wind magnetic field (Bt/Bz) or the 10.7cm radio flux. Params: metric* Read-only

curl 'https://clify-dev.netlify.app/swpc-noaa/get-summary'

get-goes-feed

GOES satellite particle/X-ray time series (flux per energy band) for a satellite slot, instrument and time range. Params: satellite, instrument*, range Read-only

curl 'https://clify-dev.netlify.app/swpc-noaa/get-goes-feed'

list-alerts

Active and recent SWPC space weather alerts, watches and warnings with their full message text. Params: none Read-only

curl 'https://clify-dev.netlify.app/swpc-noaa/list-alerts'

get-text-product

Plain-text SWPC bulletin: 3-day forecast, 27-day outlook or forecast discussion. Params: product* Read-only

curl 'https://clify-dev.netlify.app/swpc-noaa/get-text-product'

list-hapi-datasets

Catalog of the roughly 85 HAPI time-series datasets (ACE/DSCOVR/active mag and plasma, Kp, etc.) with ids for get-hapi-info and get-hapi-data. Params: none Read-only

curl 'https://clify-dev.netlify.app/swpc-noaa/list-hapi-datasets'

get-hapi-info

Metadata for one HAPI dataset: available parameters, units, cadence and start/stop dates. Params: id* Read-only

curl 'https://clify-dev.netlify.app/swpc-noaa/get-hapi-info?id=kp-pt1h'

get-hapi-data

Download a HAPI dataset as CSV (time_tag plus the chosen parameters) over a time range: solar wind speed/density, IMF Bt/Bz, Kp/ap, etc. Params: id*, parameters, time_min*, time_max* Read-only

curl 'https://clify-dev.netlify.app/swpc-noaa/get-hapi-data?id=kp-pt1h&parameters=kp%2Cap&time_min=2026-10-11T00%3A00%3A00Z&time_max=2026-10-22T23%3A59%3A59Z'
