hackage-haskell API for agents (unofficial) — JSON over curl

Hackage, the Haskell community's package archive: search packages, read package metadata, versions, dependencies, reverse dependencies, changelogs, documentation indexes, tags, categories, recent uploads, deprecated and candidate packages, and maintainer profiles.

Host: hackage.haskell.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-packages

Search Hackage packages by keyword, with optional filter expressions in the query, sorting and pagination (50 results per page) Params: query*, sort, direction, page Read-only

curl 'https://clify-dev.netlify.app/hackage-haskell/search-packages?query=json+parser'

get-package

Get a package's detail page: synopsis, description, latest version, modules and changelog link Params: package* Read-only

curl 'https://clify-dev.netlify.app/hackage-haskell/get-package?package=parsec3'

get-package-versions
