arxiv API for agents (unofficial) — JSON over curl | clify

arXiv.org, the open-access preprint archive. This CLI browses category listings (new, recent, monthly), daily catch-up, archive overviews, yearly stats, the category taxonomy and RSS feeds, and fetches paper abstract pages and BibTeX citations.

Host: arxiv.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

list-recent

List papers from the last 5 announcement days in an arXiv category or archive (e.g. cs.LG, math.NT, cs), paged. Results alternate: an {id,url} item, then that paper's {title,authors,subjects,comments} Params: category*, skip, show

curl 'https://clify-dev.netlify.app/arxiv/list-recent'

list-new

List the latest announcement (new submissions, cross-lists, replacements) in a category, with abstracts. Results alternate: an {id,url} item, then that paper's {title,authors,subjects,abstract} item. Params: category*, skip, show

curl 'https://clify-dev.netlify.app/arxiv/list-new'

list-month

List all papers in a category or archive for a given month (YYYY-MM) or year (YYYY), paged. Results alternate: an {id,url} item, then that paper's {title,authors,subjects,comments} item. Params: category*, month*, skip, show

curl 'https://clify-dev.netlify.app/arxiv/list-month'

catchup

Show everything announced in an archive on a given day (new, cross-lists, replacements). Use for catching up since a date. Results alternate: an {id,url} item, then that paper's {title,authors,subject Params: archive*, date*, abs, page

curl 'https://clify-dev.netlify.app/arxiv/catchup'

get-paper

Get a paper's abstract page: title, authors, abstract, comments, subjects, submission history and PDF/HTML links Params: id*

curl 'https://clify-dev.netlify.app/arxiv/get-paper'

get-bibtex

Export the BibTeX citation for a paper Params: id*

curl 'https://clify-dev.netlify.app/arxiv/get-bibtex'

get-rss-feed

Get the raw RSS 2.0 XML feed of the latest announcement in a category: items with title, link, description, dc:creator, category and arxiv:announce_type. Empty on weekends and holidays. Params: category*

curl 'https://clify-dev.netlify.app/arxiv/get-rss-feed'

get-archive

Get an archive overview (e.g. cs, math, physics): its subject categories with descriptions and browse links Params: archive*

curl 'https://clify-dev.netlify.app/arxiv/get-archive'

get-year-stats

Get monthly article counts for an archive in a given year Params: archive*, year*

curl 'https://clify-dev.netlify.app/arxiv/get-year-stats'

list-categories

List the full arXiv category taxonomy (category ids, names and descriptions across all groups) Params: none

curl 'https://clify-dev.netlify.app/arxiv/list-categories'
