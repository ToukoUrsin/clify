grants API for agents (unofficial) — JSON over curl | clify

Grants.gov / Simpler.Grants.gov: US federal grant opportunities. The CLI searches and exports funding opportunities, gets opportunity details from the classic Grants.gov web service, looks up agencies, searches site content, reads CMS pages, and lists the daily XML database extracts and RSS feeds.

Host: grants.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-opportunities

Search federal funding opportunities on simpler.grants.gov by keyword, with status, funding-instrument, eligibility and category filters, sort and paging. Returns the raw Next.js RSC text payload, whi Params: query, sortby, status, fundingInstrument, eligibility, category, page

curl 'https://clify-dev.netlify.app/grants/search-opportunities?query=climate+resilience&status=posted&fundingInstrument=grant&eligibility=nonprofits_non_higher_education_with_501c3&category=health'

export-opportunities-csv

Export opportunity search results as CSV. Takes the same keyword, filter and sort params as search-opportunities. Params: query, sortby, status, fundingInstrument, eligibility, category

curl 'https://clify-dev.netlify.app/grants/export-opportunities-csv?query=health&sortby=postedDateDesc&status=posted&fundingInstrument=grant&eligibility=nonprofits_non_higher_education_with_501c3&category=health'

search-site-content

Search Grants.gov website content (help articles, forms, learning pages) through the Search.gov API. Params: query*, offset, api_limit

curl 'https://clify-dev.netlify.app/grants/search-site-content?query=SF-424'

get-content-page

Get a published Grants.gov CMS page (Storyblok story) by slug. Params: slug*

curl 'https://clify-dev.netlify.app/grants/get-content-page'

list-xml-extracts

List the daily Grants.gov XML database extract files (GrantsDBExtractYYYYMMDDv2.zip), with download URL, size and date. Params: none

curl 'https://clify-dev.netlify.app/grants/list-xml-extracts'

list-rss-feeds

List the Grants.gov RSS feed links for new and modified opportunities, by agency and by category. Params: none

curl 'https://clify-dev.netlify.app/grants/list-rss-feeds'
