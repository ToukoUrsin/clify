inspirehep API for agents (unofficial) — JSON over curl | clify

INSPIRE-HEP is the high-energy physics literature database. This CLI searches and fetches papers, citations, references, BibTeX/LaTeX exports, authors, jobs, conferences, seminars, institutions and experiments through INSPIRE's public JSON API.

Host: inspirehep.net. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-literature

Search HEP papers with INSPIRE query syntax, with optional filters for document type, date range, author count and subject, plus sorting and paging Params: q*, sort, doc_type, earliest_date, author_count, subject, size, page

curl 'https://clify-dev.netlify.app/inspirehep/search-literature?q=dark+matter&sort=mostcited&doc_type=review&earliest_date=2020--2026&author_count=10+authors+or+less&subject=Astrophysics'

list-citing-papers

List the papers that cite a given literature record (by recid) Params: recid*, sort, size, page

curl 'https://clify-dev.netlify.app/inspirehep/list-citing-papers?page=2'

get-literature-facets

Get facet counts and aggregations for a literature query: doc types, subjects, authors, collaborations, citations-by-year, citation summary Params: q, facet_name, search_type, author, doc_type

curl 'https://clify-dev.netlify.app/inspirehep/get-literature-facets?q=recid%3A648746&facet_name=citations-by-year&author=1019524_Gianfranco+Bertone'

get-literature

Get full metadata for one paper: title, authors, abstract, DOIs, arXiv id, publication info, citation counts Params: id*

curl 'https://clify-dev.netlify.app/inspirehep/get-literature'

list-literature-authors

List all authors of a paper with their affiliations and INSPIRE author ids Params: id*

curl 'https://clify-dev.netlify.app/inspirehep/list-literature-authors'

list-literature-references

List the references cited by a paper, paginated Params: id*, size, page

curl 'https://clify-dev.netlify.app/inspirehep/list-literature-references'

export-literature

Export one paper's citation as BibTeX, LaTeX (EU/US) or CV text Params: id*, format

curl 'https://clify-dev.netlify.app/inspirehep/export-literature?format=bibtex'

export-literature-search

Bulk-export every paper matching a query as BibTeX or LaTeX ('cite all') Params: q*, format, sort, size, page

curl 'https://clify-dev.netlify.app/inspirehep/export-literature-search?q=a+G.Bertone.1&format=bibtex&size=10'

search-authors

Search author profiles by name Params: q*, sort, size, page

curl 'https://clify-dev.netlify.app/inspirehep/search-authors?q=witten'

get-author

Get an author profile: name, positions, advisors, students, ids (BAI/ORCID). The author key for list-author-publications is '{control_number}_{name.preferred_name}' Params: id*

curl 'https://clify-dev.netlify.app/inspirehep/get-author'

search-jobs

Search HEP job postings, filtered by rank, region and open/closed status Params: q, status, rank, region, field_of_interest, sort, size, page

curl 'https://clify-dev.netlify.app/inspirehep/search-jobs?q=postdoc&status=open&rank=POSTDOC&region=Europe'

get-job

Get a job posting's details: description, deadline, contacts, institution Params: id*

curl 'https://clify-dev.netlify.app/inspirehep/get-job'

search-conferences

Search conferences, upcoming or all Params: q, start_date, sort, size, page

curl 'https://clify-dev.netlify.app/inspirehep/search-conferences?q=neutrino&start_date=upcoming'

get-conference

Get a conference's details: dates, location, contacts, description Params: id*

curl 'https://clify-dev.netlify.app/inspirehep/get-conference'

search-seminars

Search seminars (upcoming or all), including seminars by a speaker or about a paper Params: q, start_date, sort, size, page

curl 'https://clify-dev.netlify.app/inspirehep/search-seminars?q=dark+matter&start_date=upcoming'

get-seminar

Get a seminar's details: speaker, time, timezone, abstract, join URL Params: id*

curl 'https://clify-dev.netlify.app/inspirehep/get-seminar'

search-institutions

Search research institutions by name Params: q*, sort, size, page

curl 'https://clify-dev.netlify.app/inspirehep/search-institutions?q=CERN'

get-institution

Get an institution's details: names, addresses, ROR/GRID ids, paper count Params: id*

curl 'https://clify-dev.netlify.app/inspirehep/get-institution'

search-experiments

curl 'https://clify-dev.netlify.app/inspirehep/get-experiment'
