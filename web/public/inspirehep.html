inspirehep API for agents (unofficial) — JSON over curl

INSPIRE-HEP is the high-energy physics literature database. This CLI searches and fetches papers, citations, references, BibTeX/LaTeX exports, authors, jobs, conferences, seminars, institutions and experiments through INSPIRE's public JSON API.

Host: inspirehep.net. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

search-literature

Search HEP papers with INSPIRE query syntax, with optional filters for document type, date range, author count and subject, plus sorting and paging Params: q*, sort, doc_type, earliest_date, author_count, subject, size, page Read-only

curl 'https://clify-dev.netlify.app/inspirehep/search-literature?q=dark+matter&sort=mostcited&doc_type=review&earliest_date=2020--2026&author_count=10+authors+or+less&subject=Astrophysics'
