rnz API for agents (unofficial) — JSON over curl | clify

RNZ (Radio New Zealand): search and read NZ news, tag, section and author listings, Life articles, podcasts and episodes, radio schedules, RSS feeds and video metadata.

Host: rnz.co.nz. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-content

Keyword search across RNZ news stories and audio items, with paging. Params: query*, page

curl 'https://clify-dev.netlify.app/rnz/search-content?query=housing&page=2'

list-tag-stories

List stories tagged with a topic slug, e.g. housing. Params: tag*, page

curl 'https://clify-dev.netlify.app/rnz/list-tag-stories?page=2'

list-section-news

List the latest news stories in a news section, e.g. education, political, world, business or sport. Params: section*, page

curl 'https://clify-dev.netlify.app/rnz/list-section-news'

list-author-articles

List articles written by an RNZ reporter, identified by author slug. Params: author*, page

curl 'https://clify-dev.netlify.app/rnz/list-author-articles'

get-news-feed

Get the latest stories in a news category from its RSS feed (structured title, link, date, description). Params: category*

curl 'https://clify-dev.netlify.app/rnz/get-news-feed'

list-rss-feeds

List all available RNZ RSS feeds and their URLs. Params: none

curl 'https://clify-dev.netlify.app/rnz/list-rss-feeds'

get-news-article

Get a news article's headline, description, publish time and body text. Params: section*, id*, slug*

curl 'https://clify-dev.netlify.app/rnz/get-news-article'

get-audio-item

Get metadata (headline, description, dates, image) for a radio programme audio item. Params: programme*, id*, slug*

curl 'https://clify-dev.netlify.app/rnz/get-audio-item'

list-life-articles

List RNZ Life (arts, culture, music, lifestyle) articles in a category such as music. Params: category*

curl 'https://clify-dev.netlify.app/rnz/list-life-articles'

get-life-article

Get an RNZ Life article's headline, description and body text. Params: category*, slug*

curl 'https://clify-dev.netlify.app/rnz/get-life-article'

list-podcasts

List all RNZ podcasts (A–Z) with their slugs. Params: none

curl 'https://clify-dev.netlify.app/rnz/list-podcasts'

get-podcast-episodes

Get a podcast's recent episodes from its RSS feed, including title, date, duration and MP3 URL. Params: podcast*

curl 'https://clify-dev.netlify.app/rnz/get-podcast-episodes'

list-podcast-episodes-by-year

List a podcast's episodes published in a given year (an archive beyond the RSS feed's latest items). Params: podcast*, year*

curl 'https://clify-dev.netlify.app/rnz/list-podcast-episodes-by-year'

get-national-schedule

Get the RNZ National radio schedule (programmes) for a date; returns today's schedule when no date is given. Params: date*

curl 'https://clify-dev.netlify.app/rnz/get-national-schedule'

list-video-series

List RNZ video series and documentaries, with their slugs. Params: none

curl 'https://clify-dev.netlify.app/rnz/list-video-series'
