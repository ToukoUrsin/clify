radio-browser API for agents (unofficial) — JSON over curl

radio-browser.info is a free, community-maintained directory of about 62,000 internet radio stations. This CLI searches stations, shows station details, check results, clicks and edit history, lists countries, tags, languages and codecs, reads global stats, and can get a stream URL (which counts a click) or vote for a station.

Host: radio-browser.info. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-stations

Search radio stations by name, tag, country code, language or codec, with sorting and offset pagination Params: name, tagList, countrycode, language, codec, order, reverse, hidebroken, offset, api_limit Read-only

curl 'https://clify-dev.netlify.app/radio-browser/search-stations'

get-station

Get full details of one station by its stationuuid Params: uuid* Read-only

curl 'https://clify-dev.netlify.app/radio-browser/get-station'

get-station-checks

List recent stream health checks for a station (ok flag, codec, bitrate, timing, metadata) Params: uuid* Read-only

curl 'https://clify-dev.netlify.app/radio-browser/get-station-checks'

get-check-steps

Get the individual check steps (URLs tried, URL type, errors) for one or more stations Params: uuids* Read-only

curl 'https://clify-dev.netlify.app/radio-browser/get-check-steps?uuids=2ce23ee2-95c5-407d-9df8-54c3cdde2825'

get-station-clicks

List click (play) events for a station within a recent time window Params: uuid*, seconds Read-only

curl 'https://clify-dev.netlify.app/radio-browser/get-station-clicks'

get-station-history

Get the edit history (all recorded versions) of a station Params: uuid* Read-only

curl 'https://clify-dev.netlify.app/radio-browser/get-station-history'

list-countries

List country codes with station counts, optionally filtered by a substring Params: filter, order, reverse, hidebroken, api_limit Read-only

curl 'https://clify-dev.netlify.app/radio-browser/list-countries'

list-tags

List station tags with station counts. Pass a filter for tag suggestions matching a substring Params: filter, order, reverse, hidebroken, api_limit Read-only

curl 'https://clify-dev.netlify.app/radio-browser/list-tags'

list-languages

List languages (with ISO 639 code) and station counts, optionally filtered by a substring Params: filter, order, reverse, hidebroken, api_limit Read-only

curl 'https://clify-dev.netlify.app/radio-browser/list-languages'

list-codecs

List stream codecs (MP3, AAC+, OGG, …) with station counts, optionally filtered by a substring Params: filter, order, reverse, hidebroken, api_limit Read-only

curl 'https://clify-dev.netlify.app/radio-browser/list-codecs'

get-stats

Get global directory stats: station, broken-station, tag, language and country counts, plus recent clicks Params: none Read-only

curl 'https://clify-dev.netlify.app/radio-browser/get-stats'

play-station

Get a station's playable stream URL. This registers one click (play) for the station on radio-browser Params: uuid* Read-only

curl 'https://clify-dev.netlify.app/radio-browser/play-station'
