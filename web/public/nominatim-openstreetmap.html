nominatim-openstreetmap API for agents (unofficial) — JSON over curl

Nominatim (OpenStreetMap geocoder): search places by free text or structured address, reverse-geocode coordinates, fetch full place details by OSM id, and check server/data status.

Host: nominatim.openstreetmap.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-places

Free-text geocoding search for places, addresses or POIs by name. Returns matching OSM objects with coordinates. Params: q*, api_limit, countrycodes, accept_language, layer, exclude_place_ids, addressdetails, polygon_geojson Read-only

curl 'https://clify-dev.netlify.app/nominatim-openstreetmap/search-places?q=Brandenburg+Gate+Berlin&api_limit=5&countrycodes=us&accept_language=en&layer=address&exclude_place_ids=W518071791'

search-structured

Structured address/POI search using separate fields (amenity, street, city, county, state, country, postalcode). Can be restricted to a bounding box. Params: amenity, street, city, county, state, country, postalcode, viewbox, bounded, dedupe, polygon_threshold, api_limit, countrycodes, accept_language, exclude_place_ids, addressdetails, polygon_geojson Read-only

curl 'https://clify-dev.netlify.app/nominatim-openstreetmap/search-structured?amenity=cafe&street=10+Downing+Street&city=London&country=United+Kingdom&postalcode=75004&viewbox=2.33%2C48.86%2C2.37%2C48.84&polygon_threshold=0.01'

get-place-details

Get full details of an OSM place by type and id: names, extratags (wikidata, population, website), address hierarchy, linked places, centroid. Optionally includes child places or search keywords. Params: osmtype*, osmid*, class, hierarchy, keywords, polygon_geojson Read-only

curl 'https://clify-dev.netlify.app/nominatim-openstreetmap/get-place-details?osmtype=R&osmid=2027202&class=boundary'

reverse-geocode

Reverse geocode a latitude/longitude to the nearest OSM object and its address, at a chosen detail level (zoom). Params: lat*, lon*, zoom, layer, accept_language, polygon_geojson Read-only

curl 'https://clify-dev.netlify.app/nominatim-openstreetmap/reverse-geocode?lat=43.29882129999999&lon=-72.4817747&zoom=18'

get-status

Check Nominatim server status, software/database version and when the OSM data was last updated. Params: none Read-only

curl 'https://clify-dev.netlify.app/nominatim-openstreetmap/get-status'
