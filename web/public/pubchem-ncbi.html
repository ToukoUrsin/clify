pubchem-ncbi API for agents (unofficial) — JSON over curl | clify

PubChem (NCBI) open chemistry database. This CLI searches compounds, genes, bioassays and literature, runs structure searches, fetches compound, gene, assay and element records, exports 2D/3D structures, and browses the periodic table, classification trees and data sources.

Host: pubchem.ncbi.nlm.nih.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-compounds

Keyword search of PubChem compounds (name, synonym, formula, etc.) with sorting and paging Params: q*, sort, start, api_limit

curl 'https://clify-dev.netlify.app/pubchem-ncbi/search-compounds'

curl 'https://clify-dev.netlify.app/pubchem-ncbi/search-genes'

search-bioassays

Keyword search of PubChem bioassays (AIDs) Params: q*, sort, start, api_limit

curl 'https://clify-dev.netlify.app/pubchem-ncbi/search-bioassays'

curl 'https://clify-dev.netlify.app/pubchem-ncbi/count-search-hits'
