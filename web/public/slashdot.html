slashdot API for agents (unofficial) — JSON over curl

Slashdot (tech news and discussion). The CLI reads the front page, sections, tag/firehose listings, stories and comments, popular and recent submissions, polls, user profiles and comments, the story archive and the RSS feed, and can vote in polls.

Host: slashdot.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

list-stories

List the latest front-page stories on Slashdot, with id, title, link, byline and summary. Params: page Read-only

curl 'https://clify-dev.netlify.app/slashdot/list-stories'

list-section-stories

List the stories on a section front page (subdomain such as science, yro, linux, hardware, developers, news). Params: section*, page Read-only

curl 'https://clify-dev.netlify.app/slashdot/list-section-stories?section=science'

list-by-tag

List firehose items (stories and submissions) filtered by a tag or topic keyword, e.g. ubuntu, space, crime, medicine. Params: tag*, page Read-only

curl 'https://clify-dev.netlify.app/slashdot/list-by-tag?tag=ubuntu'

list-popular

List popular firehose submissions. Params: none Read-only

curl 'https://clify-dev.netlify.app/slashdot/list-popular'

list-recent-submissions

List the most recent user submissions to the firehose, with pagination. The summary starts with '<submitter> writes:'. Params: page Read-only

curl 'https://clify-dev.netlify.app/slashdot/list-recent-submissions?page=1'

get-story

Get a story's title, byline, summary text and firehose id. The story is identified by its sid date path yy/mm/dd/id. Params: yy*, mm*, dd*, id* Read-only

curl 'https://clify-dev.netlify.app/slashdot/get-story?yy=26&mm=10&dd=18&id=050211'

list-story-comments

List the comments shown on a story page (the default threshold view), with subject, author, score and text. Params: yy*, mm*, dd*, id* Read-only

curl 'https://clify-dev.netlify.app/slashdot/list-story-comments?yy=26&mm=10&dd=17&id=1915216'

list-polls

List Slashdot polls. Each summary has the comment count, question, vote count and posting date; the url holds the poll id for get-poll-results. Params: none Read-only

curl 'https://clify-dev.netlify.app/slashdot/list-polls'

get-poll-results

Get the results of a poll by id: each answer with its vote count and percentage. Params: id* Read-only

curl 'https://clify-dev.netlify.app/slashdot/get-poll-results?id=3281'

get-user-activity

Get a user's profile page: their recent activity (comments, stories, submissions) with scores and links. Params: nick* Read-only

curl 'https://clify-dev.netlify.app/slashdot/get-user-activity?nick=gweihir'

list-user-comments

List a user's recent comments with subject, comment link, date and the story each is attached to. Params: nick* Read-only

curl 'https://clify-dev.netlify.app/slashdot/list-user-comments?nick=gweihir'

list-archive-stories

Browse the story archive: last week by default, or stories for a topic/section keyword and year, or by time for a year. Params: op, keyword, year Read-only

curl 'https://clify-dev.netlify.app/slashdot/list-archive-stories?op=topics&keyword=ai&year=2017'

get-rss-feed

Get the main Slashdot RSS (RDF) feed of current stories, with title, link, author, date and description. Params: none Read-only

curl 'https://clify-dev.netlify.app/slashdot/get-rss-feed'
