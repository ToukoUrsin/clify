greenhouse API for agents (unofficial) — JSON over curl

Public Greenhouse job boards: list and search a company's open jobs, get job details with application questions and apply links, and browse company info, departments, offices and degree options.

Host: boards.greenhouse.io. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

list-jobs

List all open jobs on a company's Greenhouse board, with title, location, apply link (absolute_url) and publish dates Params: boardToken*, content Read-only

curl 'https://clify-dev.netlify.app/greenhouse/list-jobs?boardToken=anthropic'

search-board-jobs

Search one company's job board by keyword, with optional department and office filters (50 jobs per page) Params: boardToken*, keyword, department, office, page Read-only

curl 'https://clify-dev.netlify.app/greenhouse/search-board-jobs?boardToken=anthropic&keyword=engineer&department=4019632008&office=4001218008'

get-job

Get one job post: description, location, departments, offices, apply link (absolute_url) and application form questions Params: boardToken*, jobId*, questions Read-only

curl 'https://clify-dev.netlify.app/greenhouse/get-job?boardToken=anthropic&jobId=5283063008'

get-board

Get a company's job board info: company name and board description Params: boardToken* Read-only

curl 'https://clify-dev.netlify.app/greenhouse/get-board?boardToken=anthropic'

list-departments

List a company's departments (ids for the department filter), each with its open jobs Params: boardToken* Read-only

curl 'https://clify-dev.netlify.app/greenhouse/list-departments?boardToken=anthropic'

get-department

Get one department and its open jobs Params: boardToken*, departmentId* Read-only

curl 'https://clify-dev.netlify.app/greenhouse/get-department?boardToken=anthropic&departmentId=4019632008'

list-offices

List a company's offices/locations (ids for the office filter), with their departments and jobs Params: boardToken* Read-only

curl 'https://clify-dev.netlify.app/greenhouse/list-offices?boardToken=anthropic'

get-office

Get one office/location with its departments and open jobs Params: boardToken*, officeId* Read-only

curl 'https://clify-dev.netlify.app/greenhouse/get-office?boardToken=anthropic&officeId=4001218008'

list-degrees

List degree options used in Greenhouse application education questions Params: boardToken*, page Read-only

curl 'https://clify-dev.netlify.app/greenhouse/list-degrees?boardToken=anthropic'
