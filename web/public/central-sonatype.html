central-sonatype API for agents (unofficial) — JSON over curl | clify

Maven Central (central.sonatype.com): search Maven components, browse namespaces and categories, and look up artifact details, versions, dependencies and dependents via the site's internal JSON API.

Host: central.sonatype.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-components

Keyword search over Maven Central components (groupId/artifactId); returns latest version, description, popularity Params: query*, page, size

curl 'https://clify-dev.netlify.app/central-sonatype/search-components'

list-namespace-components

List all components (artifacts) published under a Maven namespace/groupId, optionally narrowed by keyword Params: namespace*, query, page, size

curl 'https://clify-dev.netlify.app/central-sonatype/list-namespace-components'

search-components-by-category

Search or browse components within a category (e.g. JSON, Web Frameworks, Testing) Params: category*, query, page, size

curl 'https://clify-dev.netlify.app/central-sonatype/search-components-by-category'

get-component

Get full details of one artifact version: description, licenses, URLs (scm/issues), files, classifiers, categories, popularity Params: namespace*, name*, version*

curl 'https://clify-dev.netlify.app/central-sonatype/get-component'

list-versions

List all published versions of an artifact (newest first by default) with publish dates and dependent counts Params: namespace*, name*, sortDirection, page, size

curl 'https://clify-dev.netlify.app/central-sonatype/list-versions'

list-dependencies

List the dependencies of a specific artifact version (direct or transitive), with scope and versions Params: namespace*, name*, version*, type, query, page, size

curl 'https://clify-dev.netlify.app/central-sonatype/list-dependencies'

list-dependents

List artifacts that depend on a specific artifact version (reverse dependencies) Params: namespace*, name*, version*, type, query, page, size

curl 'https://clify-dev.netlify.app/central-sonatype/list-dependents'

get-homepage-url

Get the project homepage URL for an artifact version given its package URL (purl) Params: purl*

curl 'https://clify-dev.netlify.app/central-sonatype/get-homepage-url'
