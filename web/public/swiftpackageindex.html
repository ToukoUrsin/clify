swiftpackageindex API for agents (unofficial) — JSON over curl

Swift Package Index (swiftpackageindex.com) is a search engine and catalogue of Swift packages. This CLI searches packages, lists them by author, keyword or curated collection, and reads package details, README, releases, build compatibility results, build logs, DocC documentation, maintainer score info, recent builds and Swift 6 readiness stats.

Host: swiftpackageindex.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-packages

Search Swift packages by keyword. Supports inline filters such as stars:>500, platform:ios,linux, last_activity:>2025-01-01 and product:library inside the query. Params: query*, page Read-only

curl 'https://clify-dev.netlify.app/swiftpackageindex/search-packages?query=networking&page=2'

get-package

Get details for a package: summary, authors, history, activity, dependencies, license, stars, products, data race safety, latest stable version, default branch and keywords. Params: owner*, repo* Read-only

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-package?owner=apple&repo=swift-nio'

get-package-readme

Get the rendered README text of a package. Params: owner*, repo* Read-only

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-package-readme?owner=apple&repo=swift-nio'

get-package-releases

Get the release notes of a package, newest first: version, release date and changes. Params: owner*, repo* Read-only

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-package-releases?owner=Alamofire&repo=Alamofire'

get-package-builds

Get a package's build compatibility matrix: one row per platform per Swift version, with results for the latest stable release and the default branch, plus build ids. Params: owner*, repo* Read-only

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-package-builds?owner=Alamofire&repo=Alamofire'

get-build

Get one build's status, Swift version, platform, build command and full build log by build id (UUID). Params: id* Read-only

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-build?id=166991FD-C368-433C-936F-43B8689BD33D'

list-author-packages

List all packages by an author/owner as a JSON package collection (repo URL, summary, license, keywords, versions with verified compatibility). Params: owner* Read-only

curl 'https://clify-dev.netlify.app/swiftpackageindex/list-author-packages?owner=Alamofire'

list-keyword-packages

List packages tagged with a keyword/topic, e.g. networking, 20 per page. Params: keyword*, page Read-only

curl 'https://clify-dev.netlify.app/swiftpackageindex/list-keyword-packages?keyword=networking&page=2'

get-collection

List the packages in a curated custom package collection, e.g. sswg-graduated. Params: slug*, page Read-only

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-collection?slug=sswg-graduated'

get-documentation-index

Get the DocC documentation navigation index (modules, symbols, articles with paths) for a package version. Params: owner*, repo*, version* Read-only

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-documentation-index?owner=apple&repo=swift-nio&version=2.104.0'

get-documentation-page

Get a DocC documentation page as JSON (abstract, overview content, topic sections) for a module or symbol path in a package version. Params: owner*, repo*, version*, path* Read-only

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-documentation-page?owner=apple&repo=swift-nio&version=2.104.0&path=nio'

get-package-score

Get a package's maintainer information: total package score and the per-trait score breakdown used for search ranking. Params: owner*, repo* Read-only

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-package-score?owner=Alamofire&repo=Alamofire'

list-recent-builds

List the most recent builds across all packages (build monitor): package, author, status, time, reference, Swift version and platform. Params: none Read-only

curl 'https://clify-dev.netlify.app/swiftpackageindex/list-recent-builds'

list-recent-activity

List recently added packages and recent package releases from the home page. Params: none Read-only

curl 'https://clify-dev.netlify.app/swiftpackageindex/list-recent-activity'

get-swift6-readiness

Get the Ready for Swift 6 stats: time series of packages with zero data race safety errors and total errors, for all packages and subsets. Params: none Read-only

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-swift6-readiness'
