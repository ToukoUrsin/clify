swiftpackageindex API for agents (unofficial) — JSON over curl | clify

Swift Package Index (swiftpackageindex.com) is a search engine and catalogue of Swift packages. This CLI searches packages, lists them by author, keyword or curated collection, and reads package details, README, releases, build compatibility results, build logs, DocC documentation, maintainer score info, recent builds and Swift 6 readiness stats.

Host: swiftpackageindex.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-packages

Search Swift packages by keyword. Supports inline filters such as stars:>500, platform:ios,linux, last_activity:>2025-01-01 and product:library inside the query. Params: query*, page

curl 'https://clify-dev.netlify.app/swiftpackageindex/search-packages?query=networking&page=2'

get-package

Get details for a package: summary, authors, history, activity, dependencies, license, stars, products, data race safety, latest stable version, default branch and keywords. Params: owner*, repo*

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-package'

get-package-readme

Get the rendered README text of a package. Params: owner*, repo*

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-package-readme'

get-package-releases

Get the release notes of a package, newest first: version, release date and changes. Params: owner*, repo*

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-package-releases'

get-package-builds

Get a package's build compatibility matrix: one row per platform per Swift version, with results for the latest stable release and the default branch, plus build ids. Params: owner*, repo*

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-package-builds'

get-build

Get one build's status, Swift version, platform, build command and full build log by build id (UUID). Params: id*

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-build'

list-author-packages

List all packages by an author/owner as a JSON package collection (repo URL, summary, license, keywords, versions with verified compatibility). Params: owner*

curl 'https://clify-dev.netlify.app/swiftpackageindex/list-author-packages'

list-keyword-packages

List packages tagged with a keyword/topic, e.g. networking, 20 per page. Params: keyword*, page

curl 'https://clify-dev.netlify.app/swiftpackageindex/list-keyword-packages?page=2'

get-collection

List the packages in a curated custom package collection, e.g. sswg-graduated. Params: slug*, page

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-collection'

get-documentation-index

Get the DocC documentation navigation index (modules, symbols, articles with paths) for a package version. Params: owner*, repo*, version*

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-documentation-index'

get-documentation-page

Get a DocC documentation page as JSON (abstract, overview content, topic sections) for a module or symbol path in a package version. Params: owner*, repo*, version*, path*

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-documentation-page'

get-package-score

Get a package's maintainer information: total package score and the per-trait score breakdown used for search ranking. Params: owner*, repo*

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-package-score'

list-recent-builds

List the most recent builds across all packages (build monitor): package, author, status, time, reference, Swift version and platform. Params: none

curl 'https://clify-dev.netlify.app/swiftpackageindex/list-recent-builds'

list-recent-activity

List recently added packages and recent package releases from the home page. Params: none

curl 'https://clify-dev.netlify.app/swiftpackageindex/list-recent-activity'

get-swift6-readiness

Get the Ready for Swift 6 stats: time series of packages with zero data race safety errors and total errors, for all packages and subsets. Params: none

curl 'https://clify-dev.netlify.app/swiftpackageindex/get-swift6-readiness'
