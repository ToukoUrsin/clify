artifacthub API for agents (unofficial) — JSON over curl

Artifact Hub (artifacthub.io) is the CNCF hub for cloud-native packages such as Helm charts, operators, kubectl/krew plugins and policies. This CLI searches packages and reads package details, versions, default values, templates, changelogs, security reports, views, stars, RSS feeds and site statistics through the public /api/v1 API.

Host: artifacthub.io. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-packages

Search Artifact Hub packages by keyword, with filters for kind, category, publisher, repo, org and license, plus sorting and offset paging. Params: query, kind, category, verified_publisher, official, cncf, operators, deprecated, license, repo, org, sort, facets, api_limit, offset Read-only

curl 'https://clify-dev.netlify.app/artifacthub/search-packages?query=nginx&kind=0&category=5&verified_publisher=true&license=Apache-2.0'

get-package

Get full details of a package's latest version: readme, available versions, repository, keywords, links and data. Params: kind*, repo*, name* Read-only

curl 'https://clify-dev.netlify.app/artifacthub/get-package?kind=helm&repo=ingress-nginx&name=ingress-nginx'

get-package-version

Get details of a specific version of a package. Params: kind*, repo*, name*, version* Read-only

curl 'https://clify-dev.netlify.app/artifacthub/get-package-version?kind=helm&repo=ingress-nginx&name=ingress-nginx&version=4.14.0'

get-package-values

Get the default values.yaml of a Helm chart version as raw YAML text. Params: package_id*, version* Read-only

curl 'https://clify-dev.netlify.app/artifacthub/get-package-values?package_id=625a0f57-5ab0-44ea-91ac-5e8cd8234ad0&version=4.15.1'

get-package-templates

Get the template files of a Helm chart version. Each file's data field is base64-encoded. Params: package_id*, version* Read-only

curl 'https://clify-dev.netlify.app/artifacthub/get-package-templates?package_id=625a0f57-5ab0-44ea-91ac-5e8cd8234ad0&version=4.15.1'

get-package-changelog

Get a package's changelog: changes per version, with timestamps and security-update flags. Params: package_id* Read-only

curl 'https://clify-dev.netlify.app/artifacthub/get-package-changelog?package_id=625a0f57-5ab0-44ea-91ac-5e8cd8234ad0'

get-security-report

Get the Trivy vulnerability scan report for each container image of a package version. Params: package_id*, version* Read-only

curl 'https://clify-dev.netlify.app/artifacthub/get-security-report?package_id=625a0f57-5ab0-44ea-91ac-5e8cd8234ad0&version=4.14.0'
