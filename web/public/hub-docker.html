hub-docker API for agents (unofficial) — JSON over curl

Docker Hub (hub.docker.com), the public container image registry. This CLI searches images by category, lists tags and image layers, reads repository, publisher and organization info, browses the Docker MCP server catalog, and fetches Docker Scout vulnerability summaries.

Host: hub.docker.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

list-categories

List Docker Hub image categories. Their slugs are the --category values for search-category-images. Params: none Read-only

curl 'https://clify-dev.netlify.app/hub-docker/list-categories'

search-category-images

Search repositories within one category by keyword, with filters for product type and trust badge, a sort order and page number. Params: category*, q, sort, order, type, badges, page Read-only

curl 'https://clify-dev.netlify.app/hub-docker/search-category-images?category=databases-and-storage&q=postgres&sort=pull_count&order=desc'

get-official-image

Get details of a Docker Official Image (library/*), such as nginx: description, categories, pull count, stars, last updated date and full overview (full_description). Params: image* Read-only

curl 'https://clify-dev.netlify.app/hub-docker/get-official-image?image=nginx'

list-official-image-tags

List the tags of a Docker Official Image, with a name filter, sort order and page number. Includes the tag digest, size, last update and per-architecture images (architecture, os, digest, size). Params: image*, tag_name, ordering, page, page_size Read-only

curl 'https://clify-dev.netlify.app/hub-docker/list-official-image-tags?image=nginx&tag_name=alpine'

get-repository

Get details of a community or verified-publisher repository such as grafana/grafana: description, pull count, stars, categories, last updated date and full overview (full_description). Params: namespace*, repo* Read-only

curl 'https://clify-dev.netlify.app/hub-docker/get-repository?namespace=grafana&repo=grafana'

list-repository-tags

List the tags of a non-official repository (namespace/repo), with a name filter, sort order and page number. Includes digest, size, last update and per-architecture images. Params: namespace*, repo*, tag_name, ordering, page, page_size Read-only

curl 'https://clify-dev.netlify.app/hub-docker/list-repository-tags?namespace=grafana&repo=grafana'

get-image-layers

Get details of one tag's image: per-architecture digests, sizes, last pulled date and the Dockerfile layer commands. Params: namespace*, repo*, tag*, digest* Read-only

curl 'https://clify-dev.netlify.app/hub-docker/get-image-layers?namespace=library&repo=nginx&tag=1.31-alpine&digest=sha256-7ddef4fb1b16816185c5e3ca4c76086e2db0d37f2e9eee57b9a3fb5182cca562'

get-image-vulnerabilities

Get the Docker Scout vulnerability counts (critical/high/medium/low/unspecified/total) and SBOM state for an image digest. Params: digest*, repoName* Read-only

curl 'https://clify-dev.netlify.app/hub-docker/get-image-vulnerabilities?digest=sha256%3Ac87fac26236ceccacc9a595dd0e0bb5c7e5c8ad9c5723bc3149a704933163ef2&repoName=nginx'

get-organization

Get public info for a Docker Hub organization or namespace: full name, company, location, website, join date and verified-publisher badge. Params: namespace* Read-only

curl 'https://clify-dev.netlify.app/hub-docker/get-organization?namespace=grafana'

list-publisher-repositories

List the public repositories a publisher or user owns, with a name search, sort order and page number. Params: namespace*, search, ordering, page, page_size Read-only

curl 'https://clify-dev.netlify.app/hub-docker/list-publisher-repositories?namespace=grafana&search=loki'

search-mcp-servers

Search the Docker MCP Catalog of containerized MCP servers by keyword, optionally filtered by category. Params: search, categories Read-only

curl 'https://clify-dev.netlify.app/hub-docker/search-mcp-servers?search=github'

get-mcp-server

Get details of an MCP catalog server: description, image, source repo, readme/tools URLs and config. Params: id* Read-only

curl 'https://clify-dev.netlify.app/hub-docker/get-mcp-server?id=github-official'

list-mcp-server-tools

List the tools an MCP catalog server exposes, with their names and descriptions. Params: id* Read-only

curl 'https://clify-dev.netlify.app/hub-docker/list-mcp-server-tools?id=github-official'
