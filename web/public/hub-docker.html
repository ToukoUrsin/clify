hub-docker API for agents (unofficial) — JSON over curl | clify

Docker Hub (hub.docker.com), the public container image registry. This CLI searches images by category, lists tags and image layers, reads repository, publisher and organization info, browses the Docker MCP server catalog, and fetches Docker Scout vulnerability summaries.

Host: hub.docker.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

list-categories

List Docker Hub image categories. Their slugs are the --category values for search-category-images. Params: none

curl 'https://clify-dev.netlify.app/hub-docker/list-categories'

search-category-images

Search repositories within one category by keyword, with filters for product type and trust badge, a sort order and page number. Params: category*, q, sort, order, type, badges, page

curl 'https://clify-dev.netlify.app/hub-docker/search-category-images?q=postgres&sort=pull_count&order=desc'

get-official-image

Get details of a Docker Official Image (library/*), such as nginx: description, categories, pull count, stars, last updated date and full overview (full_description). Params: image*

curl 'https://clify-dev.netlify.app/hub-docker/get-official-image'

list-official-image-tags

List the tags of a Docker Official Image, with a name filter, sort order and page number. Includes the tag digest, size, last update and per-architecture images (architecture, os, digest, size). Params: image*, tag_name, ordering, page, page_size

curl 'https://clify-dev.netlify.app/hub-docker/list-official-image-tags?tag_name=alpine'

get-repository

Get details of a community or verified-publisher repository such as grafana/grafana: description, pull count, stars, categories, last updated date and full overview (full_description). Params: namespace*, repo*

curl 'https://clify-dev.netlify.app/hub-docker/get-repository'

list-repository-tags

List the tags of a non-official repository (namespace/repo), with a name filter, sort order and page number. Includes digest, size, last update and per-architecture images. Params: namespace*, repo*, tag_name, ordering, page, page_size

curl 'https://clify-dev.netlify.app/hub-docker/list-repository-tags'

get-image-layers

Get details of one tag's image: per-architecture digests, sizes, last pulled date and the Dockerfile layer commands. Params: namespace*, repo*, tag*, digest*

curl 'https://clify-dev.netlify.app/hub-docker/get-image-layers'

get-image-vulnerabilities

Get the Docker Scout vulnerability counts (critical/high/medium/low/unspecified/total) and SBOM state for an image digest. Params: digest*, repoName*

curl 'https://clify-dev.netlify.app/hub-docker/get-image-vulnerabilities'

get-organization

Get public info for a Docker Hub organization or namespace: full name, company, location, website, join date and verified-publisher badge. Params: namespace*

curl 'https://clify-dev.netlify.app/hub-docker/get-organization'

list-publisher-repositories

List the public repositories a publisher or user owns, with a name search, sort order and page number. Params: namespace*, search, ordering, page, page_size

curl 'https://clify-dev.netlify.app/hub-docker/list-publisher-repositories?search=loki'

search-mcp-servers

Search the Docker MCP Catalog of containerized MCP servers by keyword, optionally filtered by category. Params: search, categories

curl 'https://clify-dev.netlify.app/hub-docker/search-mcp-servers?search=github'

get-mcp-server

Get details of an MCP catalog server: description, image, source repo, readme/tools URLs and config. Params: id*

curl 'https://clify-dev.netlify.app/hub-docker/get-mcp-server'

list-mcp-server-tools

List the tools an MCP catalog server exposes, with their names and descriptions. Params: id*

curl 'https://clify-dev.netlify.app/hub-docker/list-mcp-server-tools'
