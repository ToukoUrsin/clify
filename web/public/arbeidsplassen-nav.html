arbeidsplassen-nav API for agents (unofficial) — JSON over curl

arbeidsplassen.nav.no is NAV's Norwegian public job board. This CLI searches job ads with filters, sorting and paging, opens individual ads, and reads a few informational pages. The site is server-rendered, so most commands parse HTML.

Host: arbeidsplassen.nav.no. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-jobs

Search job ads (ledige stillinger) by keyword, with filters for county, publish date, category, extent, remote work, sector, experience and under-18, plus sorting and paging (25 results per page) Params: q, county, published, occupationLevel1, extent, remote, sector, experience, under18, sort, from Read-only

curl 'https://clify-dev.netlify.app/arbeidsplassen-nav/search-jobs?q=utvikler&county=OSLO&occupationLevel1=IT&remote=Hybridkontor&experience=ingen+krav+til+arbeidserfaring&sort=published'

get-job

Get one job ad by its UUID: title, employer, location, employment details, application deadline, apply link and full description Params: id* Read-only

curl 'https://clify-dev.netlify.app/arbeidsplassen-nav/get-job?id=ef5ee155-d2f6-493b-84bc-8c925761d94e'

get-auth-status

Check whether the current session is logged in to arbeidsplassen.no (returns ok and isAuthenticated) Params: none Read-only

curl 'https://clify-dev.netlify.app/arbeidsplassen-nav/get-auth-status'

list-youth-shortcuts

List the youth landing-page shortcuts (/ung), such as jobs for under-18s and jobs that need no experience, with their search URLs Params: none Read-only

curl 'https://clify-dev.netlify.app/arbeidsplassen-nav/list-youth-shortcuts'

get-import-api-info

Read NAV's info page about the job-ad import API (how employers and vendors can publish ads to arbeidsplassen.no) Params: none Read-only

curl 'https://clify-dev.netlify.app/arbeidsplassen-nav/get-import-api-info'
