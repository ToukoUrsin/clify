collection-sciencemuseumgroup API for agents (unofficial) — JSON over curl | clify

Science Museum Group Collection (collection.sciencemuseumgroup.org.uk), the online catalogue of over 500,000 museum objects and archives. This CLI reads only the public homepage: featured collections, top-level collection categories, and 'on this day' anniversary highlights.

Host: collection.sciencemuseumgroup.org.uk. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

list-featured-collections

List the featured collections shown in the homepage 'Explore' carousel (for example BBC Heritage Collection), with title, description and link Params: none

curl 'https://clify-dev.netlify.app/collection-sciencemuseumgroup/list-featured-collections'

list-collection-categories

List the top-level collection themes on the homepage (for example Medicine), with their description and subcategory text (for example Pharmacology, Surgery, Asian medicine) Params: none

curl 'https://clify-dev.netlify.app/collection-sciencemuseumgroup/list-collection-categories'

list-anniversaries

List the homepage 'anniversary' highlights: collection objects linked to events from N years ago today, with the anniversary text and a link to the object Params: none

curl 'https://clify-dev.netlify.app/collection-sciencemuseumgroup/list-anniversaries'
