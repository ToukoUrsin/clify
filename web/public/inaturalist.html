inaturalist API for agents (unofficial) — JSON over curl

iNaturalist, a citizen-science biodiversity platform. This CLI searches and reads observations, taxa, places, projects and users through iNaturalist's documented public read-only API (api.inaturalist.org/v1), which the iNaturalist web app itself calls.

Host: inaturalist.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-observations

Search wildlife observations by text, taxon, place, user, quality grade and date range, with sorting and pagination Params: q, taxon_id, place_id, user_id, project_id, quality_grade, iconic_taxa, d1, d2, photos, order_by, order, per_page, page Read-only

curl 'https://clify-dev.netlify.app/inaturalist/search-observations?q=oak&taxon_id=47851&place_id=14&user_id=kueda'

get-observation

Get full details of one observation by its numeric id: taxon, photos, location, identifications and observer Params: id* Read-only

curl 'https://clify-dev.netlify.app/inaturalist/get-observation'

list-species-counts

Count observed species (leaf taxa) matching observation filters, e.g. the most-observed species in a place Params: place_id, taxon_id, user_id, project_id, quality_grade, d1, d2, per_page, page Read-only

curl 'https://clify-dev.netlify.app/inaturalist/list-species-counts?place_id=14'

list-top-observers

List the users with the most observations that match the given filters (taxon, place, project) Params: taxon_id, place_id, project_id, quality_grade, per_page, page Read-only

curl 'https://clify-dev.netlify.app/inaturalist/list-top-observers?taxon_id=47851'

search-taxa

Search taxa (species, genera, families and so on) by scientific or common name, optionally filtered by rank Params: q*, rank, is_active, per_page, page Read-only

curl 'https://clify-dev.netlify.app/inaturalist/search-taxa?q=oak'

get-taxon

Get details of a taxon by numeric id: name, rank, ancestry, common name, conservation status and Wikipedia summary Params: id* Read-only

curl 'https://clify-dev.netlify.app/inaturalist/get-taxon'

search-places

Find places (countries, states, parks and so on) by name to get the place_id that the observation filters use Params: q*, per_page Read-only

curl 'https://clify-dev.netlify.app/inaturalist/search-places?q=California'

search-projects

Search iNaturalist projects (bioblitzes, collections, umbrella projects) by name Params: q*, place_id, per_page, page Read-only

curl 'https://clify-dev.netlify.app/inaturalist/search-projects?q=bioblitz'

get-user

Get a user's public profile (login, name, observation and species counts) by login or numeric id Params: id* Read-only

curl 'https://clify-dev.netlify.app/inaturalist/get-user'

list-identifications

List identifications (species IDs that users added to observations), filterable by taxon, identifier and whether they are current Params: taxon_id, user_id, observation_id, current, per_page, page Read-only

curl 'https://clify-dev.netlify.app/inaturalist/list-identifications?taxon_id=47851'
