jsr API for agents (unofficial) — JSON over curl

JSR (jsr.io), the open-source JavaScript/TypeScript package registry. This CLI searches and browses packages and reads package metadata, versions, dependencies, dependents, scores, docs indexes, source files, scopes and users through JSR's public JSON APIs. All commands are read-only.

Host: jsr.io. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-packages

Search JSR packages by keyword, or list all packages when no query is given (public management API) Params: query, page, api_limit Read-only

curl 'https://clify-dev.netlify.app/jsr/search-packages?query=http+server'

search-packages-by-runtime

Full-text package search with an optional runtime-compatibility filter, using the site's Algolia autocomplete index Params: query*, filters, hitsPerPage, page Read-only

curl 'https://clify-dev.netlify.app/jsr/search-packages-by-runtime'

get-package

Get metadata for one package: description, latest version, score, runtime compatibility, GitHub repo Params: scope*, package* Read-only

curl 'https://clify-dev.netlify.app/jsr/get-package'

get-package-meta

Registry meta.json for a package: latest version and the map of all versions (with yanked flags) Params: scope*, package* Read-only

curl 'https://clify-dev.netlify.app/jsr/get-package-meta'

curl 'https://clify-dev.netlify.app/jsr/list-package-dependents'
