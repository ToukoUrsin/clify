riksdagen API for agents (unofficial) — JSON over curl

Sveriges riksdag (riksdagen.se) is the Swedish Parliament's public website. This CLI searches parliamentary documents, members, web-TV, the calendar and news, and fetches detail pages (motions, committee reports, member profiles, videos, calendar events, parties) as CMS JSON through the site's /api/data proxy.

Host: riksdagen.se. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search

Search riksdagen.se by keyword. Filter by category (documents, members, web-TV, calendar, news, web pages), document type, party and riksmöte, sort the results, and page through them. Params: sok*, avd, doktyp, parti, rm, sort, sortorder, p Read-only

curl 'https://clify-dev.netlify.app/riksdagen/search'

list-members

List current members of parliament (ledamöter), optionally filtered by party. Params: parti Read-only

curl 'https://clify-dev.netlify.app/riksdagen/list-members'

get-member

Get a member of parliament's profile: party, constituency, assignments and recent activity (motions, speeches, questions). Params: slug* Read-only

curl 'https://clify-dev.netlify.app/riksdagen/get-member'

get-party

Get a party page: description, leadership and members. Params: party* Read-only

curl 'https://clify-dev.netlify.app/riksdagen/get-party'

get-document

Get a parliamentary document's detail page (motion, betänkande/committee report, föredragningslista, talarlista, etc.) including its proposals, case history, debate and decision. Params: doctype*, slug* Read-only

curl 'https://clify-dev.netlify.app/riksdagen/get-document'

get-planned-chamber-items

Get the list of planned items (upcoming debates and decisions) for the Chamber (kammaren). Params: none Read-only

curl 'https://clify-dev.netlify.app/riksdagen/get-planned-chamber-items'

get-webtv-video

Get a web-TV video (debate) detail: metadata, speaker list and related documents (talarlista, föredragningslista). Params: category*, slug* Read-only

curl 'https://clify-dev.netlify.app/riksdagen/get-webtv-video'

get-calendar

Get the parliament calendar page (upcoming chamber sessions, committee meetings and events). Params: none Read-only

curl 'https://clify-dev.netlify.app/riksdagen/get-calendar'

get-calendar-event

Get a single calendar event's detail (time, place, agenda, related documents). Params: category*, year*, month*, day*, slug* Read-only

curl 'https://clify-dev.netlify.app/riksdagen/get-calendar-event'

list-news

Get the latest news (Aktuellt) from the Riksdag. Params: none Read-only

curl 'https://clify-dev.netlify.app/riksdagen/list-news'

get-news-category

Get a news/theme page under Aktuellt, e.g. valet-2026 or allmanna-motionstiden. Params: slug* Read-only

curl 'https://clify-dev.netlify.app/riksdagen/get-news-category'

get-page

Generic fallback: fetch the CMS JSON for any riksdagen.se page path, e.g. a search URL with extra filters, an open-data documentation page, or a member page with an activity filter. Params: path* Read-only

curl 'https://clify-dev.netlify.app/riksdagen/get-page?path=%2Fsv%2Fdokument-och-lagar%2Friksdagens-oppna-data%2Fdokument%2F'
