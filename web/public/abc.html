abc API for agents (unofficial) — JSON over curl

ABC News (Australian Broadcasting Corporation): search news, read top stories by state edition, browse topics, sections, authors and article metadata from abc.net.au/news.

Host: abc.net.au. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-news

Keyword search across ABC News content (articles, video, audio) via the site's Algolia index Params: query*, page, hitsPerPage, filters Read-only

curl 'https://clify-dev.netlify.app/abc/search-news'

get-top-stories

Homepage top stories for the national edition or a state edition Params: view Read-only

curl 'https://clify-dev.netlify.app/abc/get-top-stories?view=national'

list-topic-stories

Paginated JSON list of stories for a topic, by the topic's internal documentId (e.g. 1450 = Climate Change) Params: documentId*, offset, size Read-only

curl 'https://clify-dev.netlify.app/abc/list-topic-stories?documentId=1450&offset=25'

list-topic-page

Latest stories on a topic page by topic slug (first page, server-rendered) Params: topic* Read-only

curl 'https://clify-dev.netlify.app/abc/list-topic-page'

list-section-stories

Story headlines from a news section page, e.g. justin (latest news), politics, world, business Params: section* Read-only

curl 'https://clify-dev.netlify.app/abc/list-section-stories'

get-article

Article metadata (headline, description, dates, authors, keywords) from an article URL's date, slug and id Params: date*, slug*, id* Read-only

curl 'https://clify-dev.netlify.app/abc/get-article'

list-author-stories

Latest stories by an ABC reporter, from their profile page Params: author*, id* Read-only

curl 'https://clify-dev.netlify.app/abc/list-author-stories'

list-topics

A-Z topics library: topics starting with a letter (links to /news/topic/{slug}) Params: letter* Read-only

curl 'https://clify-dev.netlify.app/abc/list-topics'

list-location-topics

A-Z location topics (places) starting with a letter Params: letter* Read-only

curl 'https://clify-dev.netlify.app/abc/list-location-topics'
