tvmaze API for agents (unofficial) — JSON over curl

TVmaze is a TV show database and guide. This CLI uses its free public JSON API (api.tvmaze.com) to search shows and people, look up shows by external IDs, and fetch show details, episodes, seasons, cast, crew, alternate titles, images, characters, person credits, TV and streaming schedules, and recent show updates.

Host: tvmaze.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-shows

Fuzzy-search shows by name; returns scored matches with full show objects Params: q* Read-only

curl 'https://clify-dev.netlify.app/tvmaze/search-shows?q=breaking+bad'

search-people

Fuzzy-search people (actors, crew) by name Params: q* Read-only

curl 'https://clify-dev.netlify.app/tvmaze/search-people?q=bryan+cranston'

single-search-show

Return the single best-matching show for a name, optionally with embedded episodes, cast or other data Params: q*, embed Read-only

curl 'https://clify-dev.netlify.app/tvmaze/single-search-show?q=breaking+bad'

lookup-show

Find a show by external ID (IMDb, TheTVDB or TVRage). Pass exactly one ID. Params: imdb, thetvdb, tvrage Read-only

curl 'https://clify-dev.netlify.app/tvmaze/lookup-show?imdb=tt0903747'

get-show

Get a show's main details by TVmaze show ID, optionally with embedded cast or next/previous episode Params: id*, embed Read-only

curl 'https://clify-dev.netlify.app/tvmaze/get-show?id=169'

list-show-episodes

List all episodes of a show in airing order, optionally including specials Params: id*, specials Read-only

curl 'https://clify-dev.netlify.app/tvmaze/list-show-episodes?id=169'

get-episode-by-number

Get one episode of a show by season and episode number Params: id*, season*, number* Read-only

curl 'https://clify-dev.netlify.app/tvmaze/get-episode-by-number?id=169&season=1&number=1'

list-episodes-by-date

List a show's episodes that aired on a given date Params: id*, date* Read-only

curl 'https://clify-dev.netlify.app/tvmaze/list-episodes-by-date?id=169&date=2008-01-20'

list-show-seasons

curl 'https://clify-dev.netlify.app/tvmaze/list-show-seasons?id=169'

list-season-episodes

curl 'https://clify-dev.netlify.app/tvmaze/list-season-episodes?id=1'

list-show-cast

curl 'https://clify-dev.netlify.app/tvmaze/list-show-akas?id=169'
