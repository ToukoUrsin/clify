tvmaze API for agents (unofficial) — JSON over curl | clify

TVmaze is a TV show database and guide. This CLI uses its free public JSON API (api.tvmaze.com) to search shows and people, look up shows by external IDs, and fetch show details, episodes, seasons, cast, crew, alternate titles, images, characters, person credits, TV and streaming schedules, and recent show updates.

Host: tvmaze.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-shows

Fuzzy-search shows by name; returns scored matches with full show objects Params: q*

curl 'https://clify-dev.netlify.app/tvmaze/search-shows?q=breaking+bad'

search-people

Fuzzy-search people (actors, crew) by name Params: q*

curl 'https://clify-dev.netlify.app/tvmaze/search-people?q=bryan+cranston'

single-search-show

Return the single best-matching show for a name, optionally with embedded episodes, cast or other data Params: q*, embed

curl 'https://clify-dev.netlify.app/tvmaze/single-search-show?q=breaking+bad'

lookup-show

Find a show by external ID (IMDb, TheTVDB or TVRage). Pass exactly one ID. Params: imdb, thetvdb, tvrage

curl 'https://clify-dev.netlify.app/tvmaze/lookup-show?imdb=tt0903747'

get-show

Get a show's main details by TVmaze show ID, optionally with embedded cast or next/previous episode Params: id*, embed

curl 'https://clify-dev.netlify.app/tvmaze/get-show'

list-show-episodes

List all episodes of a show in airing order, optionally including specials Params: id*, specials

curl 'https://clify-dev.netlify.app/tvmaze/list-show-episodes'

get-episode-by-number

Get one episode of a show by season and episode number Params: id*, season*, number*

curl 'https://clify-dev.netlify.app/tvmaze/get-episode-by-number?season=1&number=1'

list-episodes-by-date

List a show's episodes that aired on a given date Params: id*, date*

curl 'https://clify-dev.netlify.app/tvmaze/list-episodes-by-date?date=2008-01-20'

list-show-seasons

List a show's seasons with their season IDs, dates, episode counts and networks Params: id*

curl 'https://clify-dev.netlify.app/tvmaze/list-show-seasons'

list-season-episodes

List the episodes of a season by its TVmaze season ID (from list-show-seasons) Params: id*

curl 'https://clify-dev.netlify.app/tvmaze/list-season-episodes'

list-show-cast

List a show's main cast: each person with the character they play Params: id*

curl 'https://clify-dev.netlify.app/tvmaze/list-show-cast'

list-show-crew

List a show's crew (creators, producers and so on) with their crew type Params: id*

curl 'https://clify-dev.netlify.app/tvmaze/list-show-crew'

list-show-akas

List a show's alternate titles (AKAs) by country Params: id*

curl 'https://clify-dev.netlify.app/tvmaze/list-show-akas'

list-show-images

List a show's images (posters, banners, backgrounds) with their URLs Params: id*

curl 'https://clify-dev.netlify.app/tvmaze/list-show-images'

list-shows

Page through the full show index, ordered by show ID (up to 250 shows per page) Params: page

curl 'https://clify-dev.netlify.app/tvmaze/list-shows?page=0'

get-episode

Get an episode's details by episode ID, with its parent show embedded Params: id*

curl 'https://clify-dev.netlify.app/tvmaze/get-episode'

list-episode-guest-cast

List the guest cast of an episode: each person with the character they play Params: id*

curl 'https://clify-dev.netlify.app/tvmaze/list-episode-guest-cast'

get-person

Get a person's details (birthday, country, gender, image) by person ID Params: id*

curl 'https://clify-dev.netlify.app/tvmaze/get-person'

list-person-cast-credits

List the shows a person was main cast in, with show details embedded Params: id*

curl 'https://clify-dev.netlify.app/tvmaze/list-person-cast-credits'

list-person-crew-credits

List a person's crew credits (for example Creator or Executive Producer), with show details embedded Params: id*

curl 'https://clify-dev.netlify.app/tvmaze/list-person-crew-credits'

list-person-guest-credits

List the episodes a person guest-starred in, with episode details embedded Params: id*

curl 'https://clify-dev.netlify.app/tvmaze/list-person-guest-credits'

get-character

Get a character's details by character ID Params: id*

curl 'https://clify-dev.netlify.app/tvmaze/get-character'

get-schedule

List the episodes airing on broadcast/cable TV in a country on a date, with show details Params: country, date

curl 'https://clify-dev.netlify.app/tvmaze/get-schedule?country=US&date=2026-10-18'

get-web-schedule

List the episodes released on web/streaming channels on a date, optionally for one country Params: date, country

curl 'https://clify-dev.netlify.app/tvmaze/get-web-schedule?date=2026-10-18'

list-show-updates

Get the shows updated in a recent time window, as a map of show ID to last-updated Unix timestamp Params: since

curl 'https://clify-dev.netlify.app/tvmaze/list-show-updates?since=day'
