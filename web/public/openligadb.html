openligadb API for agents (unofficial) — JSON over curl

OpenLigaDB: a free community sports-results database for the Bundesliga and many other leagues. This CLI wraps its public JSON API at api.openligadb.de to list leagues, teams, matchdays, fixtures/results, standings, top scorers and change timestamps.

Host: openligadb.de. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

list-leagues

List all available leagues across all sports and seasons, with shortcut and season ids for the other commands Params: none Read-only

curl 'https://clify-dev.netlify.app/openligadb/list-leagues'

list-leagues-by-season

List leagues for one season from the website's league overview (name, created info, results/schedule links that contain the league shortcut) Params: season* Read-only

curl 'https://clify-dev.netlify.app/openligadb/list-leagues-by-season?season=2025'

list-sports

List all sports available in OpenLigaDB Params: none Read-only

curl 'https://clify-dev.netlify.app/openligadb/list-sports'

list-teams

List the teams of a league in a season, with the teamId values used by match commands Params: league*, season* Read-only

curl 'https://clify-dev.netlify.app/openligadb/list-teams'

list-matchdays

List the matchdays (groups) of a league season, with groupOrderID used as the matchday number Params: league*, season* Read-only

curl 'https://clify-dev.netlify.app/openligadb/list-matchdays'

get-current-matchday

Get the current matchday (group) of a league Params: league* Read-only

curl 'https://clify-dev.netlify.app/openligadb/get-current-matchday'

list-matchday-matches

List all matches (fixtures and results) of one matchday in a league season Params: league*, season*, matchday* Read-only

curl 'https://clify-dev.netlify.app/openligadb/list-matchday-matches'

search-team-matches

List a league season's matches for teams whose name contains the given text Params: league*, season*, team* Read-only

curl 'https://clify-dev.netlify.app/openligadb/search-team-matches'

get-match

Get full details of one match by matchID: teams, results, goals, location and viewers Params: matchId* Read-only

curl 'https://clify-dev.netlify.app/openligadb/get-match'

get-head-to-head

List all recorded matches between two teams, identified by teamId Params: team1*, team2* Read-only

curl 'https://clify-dev.netlify.app/openligadb/get-head-to-head'

list-team-matches

List a team's matches in a time window around today, given as weeks in the past and weeks in the future Params: teamId*, weeksPast, weeksFuture Read-only

curl 'https://clify-dev.netlify.app/openligadb/list-team-matches'

get-next-match

curl 'https://clify-dev.netlify.app/openligadb/get-next-match'

curl 'https://clify-dev.netlify.app/openligadb/get-last-match'

Get the league table (standings) for a league season Params: league*, season* Read-only

curl 'https://clify-dev.netlify.app/openligadb/get-standings'

get-top-scorers

Get the goal scorers ranking for a league season Params: league*, season* Read-only

curl 'https://clify-dev.netlify.app/openligadb/get-top-scorers'

get-last-change

Get the timestamp of the last data change for one matchday; a cheap poll before refetching match data Params: league*, season*, matchday* Read-only

curl 'https://clify-dev.netlify.app/openligadb/get-last-change'
