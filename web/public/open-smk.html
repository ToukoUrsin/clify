open-smk API for agents (unofficial) — JSON over curl

SMK Open, the art collection of Statens Museum for Kunst (the National Gallery of Denmark). The CLI searches and filters artworks through the public SMK API and fetches artwork details, similar works, enrichment data, curated themes and IIIF image metadata.

Host: open.smk.dk. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-artworks

Search the SMK collection by keyword, with optional facet filters, a date or geo range, language and offset pagination. Params: query, lang, filters, range, offset, rows Read-only

curl 'https://clify-dev.netlify.app/open-smk/search-artworks?query=hammersh%C3%B8i&filters=%5Bartist%3AVilhelm+Hammersh%C3%B8i%5D&range=%5Bproduction_dates_end%3A%7B1900-01-01T00%3A00%3A00.000Z%3B*%7D%5D'

list-search-facets

List facet values with counts (artists, creators, work types, colours and so on) for a keyword search. Use the values as filters in search-artworks. Params: query, facets, filters, lang Read-only

curl 'https://clify-dev.netlify.app/open-smk/list-search-facets?query=hammersh%C3%B8i&filters=%5Bhas_image%3Atrue%5D'

get-artworks

Get full metadata for one or more artworks by object number (comma-separated): title, creator, dates, dimensions, exhibitions, literature and image URLs. Params: object_number*, lang Read-only

curl 'https://clify-dev.netlify.app/open-smk/get-artworks?object_number=KMS6658'

get-similar-artworks

Get the object numbers of artworks that are visually similar to an artwork. Params: object_number* Read-only

curl 'https://clify-dev.netlify.app/open-smk/get-similar-artworks?object_number=KMS6658'

get-artwork-enrichment

Get enrichment records for an artwork, such as visual feature extraction (brightness, contrast, saturation, colour temperature) and similar-image data. Params: object_number* Read-only

curl 'https://clify-dev.netlify.app/open-smk/get-artwork-enrichment'

list-themes

List curated themes (e.g. '10 Highlights', 'Animals') with their Danish and English titles and the object numbers of their artworks. Params: none Read-only

curl 'https://clify-dev.netlify.app/open-smk/list-themes'

get-theme

Get one curated theme: titles, HTML description in Danish and English, and the object numbers of its artworks. Params: id* Read-only

curl 'https://clify-dev.netlify.app/open-smk/get-theme'

get-iiif-manifest

Get the IIIF Presentation 3 manifest for an artwork: label, rights, attribution, metadata, and canvases with image size and image service URLs. Params: id* Read-only

curl 'https://clify-dev.netlify.app/open-smk/get-iiif-manifest?id=KMS6658'

get-iiif-image-info

Get IIIF Image API info.json for an artwork image: full width and height, available sizes, tiles and supported formats, for building zoom or crop URLs. Params: image_id* Read-only

curl 'https://clify-dev.netlify.app/open-smk/get-iiif-image-info'
