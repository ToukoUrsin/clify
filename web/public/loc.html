loc API for agents (unofficial) — JSON over curl | clify

Library of Congress (loc.gov): read the homepage's featured stories, trending content, top searches and gallery highlights, and fetch WebVTT captions for LOC webcast videos.

Host: loc.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

list-featured-stories

List the featured stories in the rotating banner on the Library of Congress homepage (title, description, link). Params: none

curl 'https://clify-dev.netlify.app/loc/list-featured-stories'

list-trending

List trending items on the homepage (blog posts, magazine articles, videos), with their format (Blog, Magazine, Watch) and link. Params: none

curl 'https://clify-dev.netlify.app/loc/list-trending'

list-top-searches

List the 'Top Searches' terms shown on the homepage, with their loc.gov search URLs. Params: none

curl 'https://clify-dev.netlify.app/loc/list-top-searches'

list-gallery-highlights

List the captioned collection photos in the homepage masonry gallery. Params: none

curl 'https://clify-dev.netlify.app/loc/list-gallery-highlights'

get-webcast-captions

Fetch the WebVTT caption/transcript track for a Library of Congress webcast video served from tile.loc.gov. Params: media_id*, track

curl 'https://clify-dev.netlify.app/loc/get-webcast-captions'
