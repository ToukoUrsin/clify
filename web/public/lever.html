lever API for agents (unofficial) — JSON over curl

Lever-hosted company job boards (jobs.lever.co/{company}): list and filter a company's open postings by location, team, work type and workplace type, and fetch posting details with apply links via Lever's public postings API.

Host: jobs.lever.co. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

list-postings

List a company's open job postings on Lever, optionally filtered by location, team, department, commitment (work type) or workplace type; returns title, location, team, apply link. Params: company*, location, team, department, commitment, workplaceType, api_limit, skip Read-only

curl 'https://clify-dev.netlify.app/lever/list-postings?company=palantir&location=New+York%2C+NY&team=Software+Engineering&commitment=Full-time'

get-posting

Get full details of one Lever job posting (title, location, team, commitment, workplace type, plain-text description, hosted and apply URLs). Params: company*, postingId* Read-only

curl 'https://clify-dev.netlify.app/lever/get-posting?company=palantir&postingId=ac978161-6f46-4f6b-ad9e-a258e642751c'

get-posting-schema

Get a posting's schema.org JobPosting data from its public job page (hiring organization, location address, employment type, date posted, HTML description). Params: company*, postingId* Read-only

curl 'https://clify-dev.netlify.app/lever/get-posting-schema?company=spotify&postingId=223f9722-3579-4ff2-b123-e4cc7b0c1a64'
