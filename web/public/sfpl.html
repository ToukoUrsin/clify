sfpl API for agents (unofficial) — JSON over curl

San Francisco Public Library (sfpl.org): search the catalog, databases and site content, find branches and their hours, and browse library events.

Host: sfpl.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-events

Search and filter upcoming library events by keyword, branch location, topic and audience; returns event titles, dates, branches and /events/YYYY/MM/DD/slug links Params: keys, location, topic, audience, sort_order, page Read-only

curl 'https://clify-dev.netlify.app/sfpl/search-events?keys=book+club&location=31&topic=394&audience=25'

list-locations

List all SFPL branches with their weekly opening hours, today's hours, branch page URL and location ID Params: none Read-only

curl 'https://clify-dev.netlify.app/sfpl/list-locations'

search-locations

Search branches by keyword and optionally only those open right now; returns branch name, URL, location ID, today's hours and weekly hours Params: search_keys, open_now, sort_by, sort_order Read-only

curl 'https://clify-dev.netlify.app/sfpl/search-locations?search_keys=mission'

get-event-ics

Download an event as an iCalendar (ICS) text: title, start/end time, location and description Params: nid* Read-only

curl 'https://clify-dev.netlify.app/sfpl/get-event-ics?nid=165338'

get-event-page

Resolve an event page URL (/events/YYYY/MM/DD/slug) to its node ID; path.currentPath is 'node/N', and N is used by get-event and get-event-ics Params: year*, month*, day*, slug* Read-only

curl 'https://clify-dev.netlify.app/sfpl/get-event-page?year=2026&month=12&day=09&slug=book-club-susanna-kwans-awake-floating-city'

get-location

Look up a branch page by slug and get its location ID; path.currentPath is 'taxonomy/term/N', and N is the location filter for search-events Params: slug* Read-only

curl 'https://clify-dev.netlify.app/sfpl/get-location?slug=mission-bay'
