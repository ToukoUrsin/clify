ssb API for agents (unofficial) — JSON over curl | clify

Statistics Norway (SSB, ssb.no): search articles and statistics, read statistic, article and topic pages, and query Statbank (PxWebApi v2) tables, metadata and data, plus Klass classifications.

Host: ssb.no. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-content

Full-text search of ssb.no content (statistics, articles, analyses, fact pages), with subject/content-type filters and date sort Params: query*, start, count, language, subject, content_type, sort

curl 'https://clify-dev.netlify.app/ssb/search-content?query=befolkning&subject=Befolkning&content_type=artikkel'

get-topic

List the sub-topics (category links) on an ssb.no main topic page Params: topic*

curl 'https://clify-dev.netlify.app/ssb/get-topic'

get-statistic

Get a statistic page's overview: title, ingress, last and next update, subjects and keywords Params: subject*, area*, slug*

curl 'https://clify-dev.netlify.app/ssb/get-statistic'

get-statistic-tables

Get the 'selected figures' tables shown on a statistic page (caption, header and rows as text) Params: subject*, area*, slug*

curl 'https://clify-dev.netlify.app/ssb/get-statistic-tables'

get-article

Get an ssb.no article: title, ingress, publish date, authors and body text Params: subject*, area*, slug*

curl 'https://clify-dev.netlify.app/ssb/get-article'

search-tables

Search or list Statbank (PxWebApi v2) tables by keyword Params: query, lang, include_discontinued, page, page_size

curl 'https://clify-dev.netlify.app/ssb/search-tables?query=folkemengde'

get-table

Get Statbank table info: label, period range, variables, subject paths, update time Params: table_id*, lang

curl 'https://clify-dev.netlify.app/ssb/get-table'

get-table-metadata

Get Statbank table metadata (json-stat2): dimensions with all value codes and labels, notes, roles Params: table_id*, lang, default_selection

curl 'https://clify-dev.netlify.app/ssb/get-table-metadata'

get-table-default-selection

Get the default variable/value selection and layout the Statbank uses for a table Params: table_id*, lang

curl 'https://clify-dev.netlify.app/ssb/get-table-default-selection'

get-table-data

Fetch Statbank table data (json-stat2). Without selections it returns the table's default selection. Params: table_id*, lang, output_format, time, region, region_codelist, contents

curl 'https://clify-dev.netlify.app/ssb/get-table-data?time=top%284%29'

search-classifications

Search Klass, SSB's statistical classifications and code lists (e.g. NACE, municipalities, occupations) Params: query*, page, size

curl 'https://clify-dev.netlify.app/ssb/search-classifications?query=kommune'
