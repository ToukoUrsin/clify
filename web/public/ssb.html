ssb API for agents (unofficial) — JSON over curl

Statistics Norway (SSB, ssb.no): search articles and statistics, read statistic, article and topic pages, and query Statbank (PxWebApi v2) tables, metadata and data, plus Klass classifications.

Host: ssb.no. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-content

Full-text search of ssb.no content (statistics, articles, analyses, fact pages), with subject/content-type filters and date sort Params: query*, start, count, language, subject, content_type, sort Read-only

curl 'https://clify-dev.netlify.app/ssb/search-content?query=befolkning&subject=Befolkning&content_type=artikkel'

get-topic

List the sub-topics (category links) on an ssb.no main topic page Params: topic* Read-only

curl 'https://clify-dev.netlify.app/ssb/get-topic?topic=sosiale-forhold-og-kriminalitet'

get-statistic

Get a statistic page's overview: title, ingress, last and next update, subjects and keywords Params: subject*, area*, slug* Read-only

curl 'https://clify-dev.netlify.app/ssb/get-statistic?subject=befolkning&area=folketall&slug=befolkning'

get-statistic-tables

Get the 'selected figures' tables shown on a statistic page (caption, header and rows as text) Params: subject*, area*, slug* Read-only

curl 'https://clify-dev.netlify.app/ssb/get-statistic-tables?subject=befolkning&area=folketall&slug=befolkning'

get-article

Get an ssb.no article: title, ingress, publish date, authors and body text Params: subject*, area*, slug* Read-only

curl 'https://clify-dev.netlify.app/ssb/get-article?subject=befolkning&area=navn&slug=kjaert-navn-har-mange-barn'

search-tables

Search or list Statbank (PxWebApi v2) tables by keyword Params: query, lang, include_discontinued, page, page_size Read-only

curl 'https://clify-dev.netlify.app/ssb/search-tables?query=folkemengde'

get-table

Get Statbank table info: label, period range, variables, subject paths, update time Params: table_id*, lang Read-only

curl 'https://clify-dev.netlify.app/ssb/get-table?table_id=01222'

get-table-metadata

Get Statbank table metadata (json-stat2): dimensions with all value codes and labels, notes, roles Params: table_id*, lang, default_selection Read-only

curl 'https://clify-dev.netlify.app/ssb/get-table-metadata?table_id=01222'

get-table-default-selection

Get the default variable/value selection and layout the Statbank uses for a table Params: table_id*, lang Read-only

curl 'https://clify-dev.netlify.app/ssb/get-table-default-selection?table_id=01222'

get-table-data

Fetch Statbank table data (json-stat2). Without selections it returns the table's default selection. Params: table_id*, lang, output_format, time, region, region_codelist, contents Read-only

curl 'https://clify-dev.netlify.app/ssb/get-table-data?table_id=01222&time=top%284%29'

search-classifications

Search Klass, SSB's statistical classifications and code lists (e.g. NACE, municipalities, occupations) Params: query*, page, size Read-only

curl 'https://clify-dev.netlify.app/ssb/search-classifications?query=kommune'
