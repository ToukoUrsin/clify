arstechnica API for agents (unofficial) — JSON over curl | clify

Ars Technica (WordPress news site plus XenForo 'Civis' forum). The CLI reads article feeds by site, section, tag and author, fetches full articles, and reads forum threads and article comment threads.

Host: arstechnica.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

list-latest-articles

List the newest articles across the whole site from the sitewide RSS feed (title, link, date, author, excerpt). Params: page

curl 'https://clify-dev.netlify.app/arstechnica/list-latest-articles?page=2'

list-section-articles

List the newest articles in a site section (e.g. gadgets, security, science) from the section RSS feed. Params: section*, page

curl 'https://clify-dev.netlify.app/arstechnica/list-section-articles?page=2'

list-tag-articles

List articles with a given tag from the tag RSS feed. Items include the full article content. Params: tag*, page

curl 'https://clify-dev.netlify.app/arstechnica/list-tag-articles?page=2'

list-author-articles

List the newest articles by one Ars Technica author from the author RSS feed. Params: author*, page

curl 'https://clify-dev.netlify.app/arstechnica/list-author-articles?page=2'

get-article

Fetch one article: title, description, author, publish date, body text and the link to its forum comment thread. Params: section*, year*, month*, slug*

curl 'https://clify-dev.netlify.app/arstechnica/get-article'

get-thread-posts

Read the posts in a forum thread, including an article's comment thread, one page at a time. Can sort by vote score. Params: thread*, page, order

curl 'https://clify-dev.netlify.app/arstechnica/get-thread-posts'

list-forum-threads

List threads in a forum, e.g. News Discussion (article comment threads): title, url, author, latest activity. Params: forum*, page

curl 'https://clify-dev.netlify.app/arstechnica/list-forum-threads'

list-new-forum-posts

List forum threads with the most recent new posts, from Civis 'What's new > New posts'. Params: none

curl 'https://clify-dev.netlify.app/arstechnica/list-new-forum-posts'
