arstechnica API for agents (unofficial) — JSON over curl

Ars Technica (WordPress news site plus XenForo 'Civis' forum). The CLI reads article feeds by site, section, tag and author, fetches full articles, and reads forum threads and article comment threads.

Host: arstechnica.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

list-latest-articles

List the newest articles across the whole site from the sitewide RSS feed (title, link, date, author, excerpt). Params: page Read-only

curl 'https://clify-dev.netlify.app/arstechnica/list-latest-articles?page=2'

list-section-articles

List the newest articles in a site section (e.g. gadgets, security, science) from the section RSS feed. Params: section*, page Read-only

curl 'https://clify-dev.netlify.app/arstechnica/list-section-articles?section=gadgets&page=2'

list-tag-articles

List articles with a given tag from the tag RSS feed. Items include the full article content. Params: tag*, page Read-only

curl 'https://clify-dev.netlify.app/arstechnica/list-tag-articles?tag=quantum-computing&page=2'

list-author-articles

List the newest articles by one Ars Technica author from the author RSS feed. Params: author*, page Read-only

curl 'https://clify-dev.netlify.app/arstechnica/list-author-articles?author=dan-goodin&page=2'

get-article

Fetch one article: title, description, author, publish date, body text and the link to its forum comment thread. Params: section*, year*, month*, slug* Read-only

curl 'https://clify-dev.netlify.app/arstechnica/get-article?section=security&year=2026&month=09&slug=cloudflare-plans-to-issue-quantum-safe-tls-certificates'

get-thread-posts

Read the posts in a forum thread, including an article's comment thread, one page at a time. Can sort by vote score. Params: thread*, page, order Read-only

curl 'https://clify-dev.netlify.app/arstechnica/get-thread-posts?thread=cloudflare-plans-to-issue-quantum-safe-tls-certificates.1515011&page=1'

list-forum-threads

List threads in a forum, e.g. News Discussion (article comment threads): title, url, author, latest activity. Params: forum*, page Read-only

curl 'https://clify-dev.netlify.app/arstechnica/list-forum-threads?forum=news-discussion.2&page=2'

list-new-forum-posts

List forum threads with the most recent new posts, from Civis 'What's new > New posts'. Params: none Read-only

curl 'https://clify-dev.netlify.app/arstechnica/list-new-forum-posts'
