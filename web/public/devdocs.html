devdocs API for agents (unofficial) — JSON over curl | clify

DevDocs (devdocs.io) is a single site that bundles many API documentation sets. This CLI lists the available docs, fetches a doc's index of entries and categories, and retrieves documentation pages or full offline bundles as static JSON or HTML from documents.devdocs.io.

Host: devdocs.io. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

list-docs

List every documentation set on DevDocs with its slug, version, release, mtime and size. Use the slug in the other commands. Params: none

curl 'https://clify-dev.netlify.app/devdocs/list-docs'

list-entries

List all entries (name, path, type) in one documentation set's search index. DevDocs search is done on the client against this list, so filter the result by name to search. Params: slug*

curl 'https://clify-dev.netlify.app/devdocs/list-entries'

list-types

List the categories (types) of one documentation set, with entry counts and slugs, e.g. 'Branching and Merging' for git or 'Elements' for html. Params: slug*

curl 'https://clify-dev.netlify.app/devdocs/list-types'

get-doc-home

Get the HTML home/overview page of one documentation set. Params: slug*

curl 'https://clify-dev.netlify.app/devdocs/get-doc-home'

get-page

Get the HTML content of one documentation page, using the slug and an entry path from list-entries. Params: slug*, path*

curl 'https://clify-dev.netlify.app/devdocs/get-page'

download-doc

Download the full offline bundle of one documentation set: a JSON object that maps each page path to its HTML. This can be very large. Params: slug*

curl 'https://clify-dev.netlify.app/devdocs/download-doc'
