airnow API for agents (unofficial) — JSON over curl

AirNow.gov (EPA) U.S. air quality: current and forecast AQI by location, reporting-area and monitor-site history, state tables, national top AQI list, state alerts and site search. The CLI calls airnowgovapi.com and related JSON endpoints directly.

Host: airnow.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

suggest-reporting-areas

Autocomplete AirNow reporting area names (e.g. 'Denver-Boulder, CO') from a city name or ZIP fragment Params: term*, maxSuggestions Read-only

curl 'https://clify-dev.netlify.app/airnow/suggest-reporting-areas?term=Denver'

geocode-location

Resolve a U.S. city, region or ZIP code to latitude/longitude (x=longitude, y=latitude) for use with get-current-aqi and get-weather Params: location*, maxLocations Read-only

curl 'https://clify-dev.netlify.app/airnow/geocode-location?location=94103'

get-current-aqi

Get current observed AQI and today/tomorrow forecasts per pollutant for the reporting area nearest a latitude/longitude Params: latitude*, longitude*, stateCode, maxDistance Read-only

curl 'https://clify-dev.netlify.app/airnow/get-current-aqi?latitude=39.738453&longitude=-104.984853&stateCode=CO'

get-reporting-area-location

Get the latitude/longitude of a named reporting area Params: reportingArea*, stateCode* Read-only

curl 'https://clify-dev.netlify.app/airnow/get-reporting-area-location?reportingArea=Austin&stateCode=TX'
