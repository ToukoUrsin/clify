finlex API for agents (unofficial) — JSON over curl | clify

Finlex, the Finnish government's free legal database (statutes, Statute Book, translations and Supreme Court case law). This CLI searches all datasets, lists Statute Book entries and Supreme Court precedents, and fetches statute, translation and precedent detail pages and translation PDFs.

Host: finlex.fi. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search

Keyword search across all Finlex data (legislation, government proposals, treaties, case law, officials). Returns hit count, category counts and hits as a Next.js server-action text stream. Params: search*, page, api_limit, sort

curl 'https://clify-dev.netlify.app/finlex/search'

list-latest-statutes

List the latest statutes published in the Statute Book, as shown on the Finlex home page. Params: none

curl 'https://clify-dev.netlify.app/finlex/list-latest-statutes'

get-statute

Get a statute by number and year, e.g. 55/2001 (Employment Contracts Act). Returns the title and statute text. Params: year*, number*

curl 'https://clify-dev.netlify.app/finlex/get-statute'

get-statute-translation

Get the English translation page of a statute by year and number, including the translation PDF link. Params: year*, number*

curl 'https://clify-dev.netlify.app/finlex/get-statute-translation'

list-supreme-court-collections

List the Supreme Court material collections (precedents, rulings other than precedents, etc.) with last-update dates. Params: none

curl 'https://clify-dev.netlify.app/finlex/list-supreme-court-collections'

list-latest-precedents

List the latest Supreme Court precedents (KKO). Params: none

curl 'https://clify-dev.netlify.app/finlex/list-latest-precedents'

get-precedent

Get the full text of a Supreme Court precedent by year and number, e.g. KKO 2026:74. Params: year*, number*

curl 'https://clify-dev.netlify.app/finlex/get-precedent'
