finlex API for agents (unofficial) — JSON over curl

Finlex, the Finnish government's free legal database (statutes, Statute Book, translations and Supreme Court case law). This CLI searches all datasets, lists Statute Book entries and Supreme Court precedents, and fetches statute, translation and precedent detail pages and translation PDFs.

Host: finlex.fi. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search

Keyword search across all Finlex data (legislation, government proposals, treaties, case law, officials). Returns hit count, category counts and hits as a Next.js server-action text stream. Params: search*, page, api_limit, sort Read-only

curl 'https://clify-dev.netlify.app/finlex/search?search=employment+contract&page=1&api_limit=20'

list-latest-statutes

List the latest statutes published in the Statute Book, as shown on the Finlex home page. Params: none Read-only

curl 'https://clify-dev.netlify.app/finlex/list-latest-statutes'

get-statute

Get a statute by number and year, e.g. 55/2001 (Employment Contracts Act). Returns the title and statute text. Params: year*, number* Read-only

curl 'https://clify-dev.netlify.app/finlex/get-statute?year=2001&number=55'

get-statute-translation

Get the English translation page of a statute by year and number, including the translation PDF link. Params: year*, number* Read-only

curl 'https://clify-dev.netlify.app/finlex/get-statute-translation?year=2001&number=55'

list-supreme-court-collections

List the Supreme Court material collections (precedents, rulings other than precedents, etc.) with last-update dates. Params: none Read-only

curl 'https://clify-dev.netlify.app/finlex/list-supreme-court-collections'

list-latest-precedents

List the latest Supreme Court precedents (KKO). Params: none Read-only

curl 'https://clify-dev.netlify.app/finlex/list-latest-precedents'

get-precedent

Get the full text of a Supreme Court precedent by year and number, e.g. KKO 2026:74. Params: year*, number* Read-only

curl 'https://clify-dev.netlify.app/finlex/get-precedent?year=2026&number=74'
