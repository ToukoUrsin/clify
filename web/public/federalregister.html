federalregister API for agents (unofficial) — JSON over curl | clify

Federal Register (federalregister.gov): search and read U.S. federal rules, proposed rules, notices and presidential documents, agencies, public inspection filings and topic searches through the official public JSON API.

Host: federalregister.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-documents

Search published Federal Register documents by keyword, with optional filters for type, agency, publication date and significance, plus sort and paging Params: term, type, agency, published_since, published_before, significant, order, per_page, page

curl 'https://clify-dev.netlify.app/federalregister/search-documents?term=climate&type=RULE&agency=environmental-protection-agency&published_since=2026-10-01'

get-document

Get full metadata for one Federal Register document by its document number: abstract, action, dates, CFR references, dockets and full-text links Params: document_number*

curl 'https://clify-dev.netlify.app/federalregister/get-document'

get-documents

Get metadata for several Federal Register documents at once, given a comma-separated list of document numbers Params: document_numbers*

curl 'https://clify-dev.netlify.app/federalregister/get-documents'

count-documents-by-facet

Count documents matching a search, grouped by agency, document type, topic, section or publication period (facet counts) Params: facet*, term, type, agency, published_since, published_before

curl 'https://clify-dev.netlify.app/federalregister/count-documents-by-facet?term=climate'

export-documents-csv

Export documents matching a search as CSV text (document number, title, type, date, agencies, citation, URLs) Params: term, type, agency, published_since, published_before, order, per_page, page

curl 'https://clify-dev.netlify.app/federalregister/export-documents-csv?term=climate'

list-agencies

List all Federal Register agencies with id, slug, short name, parent and child agencies Params: none

curl 'https://clify-dev.netlify.app/federalregister/list-agencies'

get-agency

Get one agency's details (description, short name, logo, parent/child agencies, recent-documents link) by slug or numeric id Params: slug*

curl 'https://clify-dev.netlify.app/federalregister/get-agency'

list-current-public-inspection

List documents currently on public inspection, which are filed but not yet published in the Federal Register Params: none

curl 'https://clify-dev.netlify.app/federalregister/list-current-public-inspection'

list-public-inspection-by-date

List the documents that were on public inspection on a given date Params: date*

curl 'https://clify-dev.netlify.app/federalregister/list-public-inspection-by-date?date=2026-10-16'

get-public-inspection-document

Get one public inspection document by document number: filing time, scheduled publication date, PDF and raw-text links Params: document_number*

curl 'https://clify-dev.netlify.app/federalregister/get-public-inspection-document'

list-suggested-searches

List curated topic searches (e.g. Dodd-Frank, stock trading), grouped by section, with saved search conditions and recent document counts Params: none

curl 'https://clify-dev.netlify.app/federalregister/list-suggested-searches'

get-suggested-search

Get one curated topic search by slug, including its description and the search conditions to reuse with search-documents Params: slug*

curl 'https://clify-dev.netlify.app/federalregister/get-suggested-search'

get-image

Get metadata and download URLs (large, medium, original size) for an image embedded in a Federal Register document Params: identifier*

curl 'https://clify-dev.netlify.app/federalregister/get-image'
