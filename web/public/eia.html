eia API for agents (unofficial) — JSON over curl

U.S. Energy Information Administration (EIA): energy statistics through the public Open Data API v2 (routes, data queries, facets, legacy series IDs), dnav data tables, Today in Energy articles, daily and weekly fuel prices, glossary and FAQs.

Host: eia.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

list-api-datasets

List the top-level EIA Open Data API v2 dataset categories (coal, electricity, natural-gas, petroleum, ...). Params: none Read-only

curl 'https://clify-dev.netlify.app/eia/list-api-datasets'

get-api-route

Get metadata for a top-level API v2 category (e.g. natural-gas, electricity): its child routes. Params: route* Read-only

curl 'https://clify-dev.netlify.app/eia/get-api-route'

list-api-facet-values

List the allowed values (id and name) of one facet of a two-level API v2 dataset, e.g. all stateid codes for electricity/retail-sales. Params: category*, dataset*, facet* Read-only

curl 'https://clify-dev.netlify.app/eia/list-api-facet-values'

get-data-table

Read a dnav summary data table (e.g. U.S. or state natural gas prices): one row per series with the latest values and a link to its history. Params: program, table* Read-only

curl 'https://clify-dev.netlify.app/eia/get-data-table'

get-series-history-table

Read the full-history table of a dnav series, one row per decade (e.g. Texas natural gas wellhead price, annual). Params: program, series* Read-only

curl 'https://clify-dev.netlify.app/eia/get-series-history-table'

list-recent-articles

List the latest Today in Energy articles with type, date, title, link and tags. Params: none Read-only

curl 'https://clify-dev.netlify.app/eia/list-recent-articles'

get-article

Get the full text of a Today in Energy article by id. Params: id* Read-only

curl 'https://clify-dev.netlify.app/eia/get-article?id=68305'

list-articles-by-tag

List all Today in Energy articles that carry a tag (e.g. electricity, natural gas, solar). Params: tag* Read-only

curl 'https://clify-dev.netlify.app/eia/list-articles-by-tag?tag=electricity'

list-article-tags

List every Today in Energy article tag. Params: none Read-only

curl 'https://clify-dev.netlify.app/eia/list-article-tags'

list-article-archive

List Today in Energy articles for one year from the archive, grouped by month in the page. Params: year Read-only

curl 'https://clify-dev.netlify.app/eia/list-article-archive?year=2025'

get-daily-prices

Get Today in Energy daily prices: wholesale spot petroleum, natural gas and electricity, retail fuel, prompt-month futures and financial indicators. Params: none Read-only

curl 'https://clify-dev.netlify.app/eia/get-daily-prices'

get-gasoline-diesel-prices

Get the weekly U.S., regional and state retail prices for regular gasoline and on-highway diesel (Gasoline and Diesel Fuel Update). Params: none Read-only

curl 'https://clify-dev.netlify.app/eia/get-gasoline-diesel-prices'

list-glossary-terms

List EIA glossary terms and definitions for a fuel topic or a starting letter. Params: topic* Read-only

curl 'https://clify-dev.netlify.app/eia/list-glossary-terms?topic=coal'

get-faq

Get an EIA FAQ answer and the related FAQs on the same topic. Params: id*, t Read-only

curl 'https://clify-dev.netlify.app/eia/get-faq?id=2&t=9'
