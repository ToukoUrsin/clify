citybik API for agents (unofficial) — JSON over curl

CityBikes (citybik.es) collects open bike-sharing data from around the world. This CLI queries the public CityBikes API (api.citybik.es/v2) for networks, network details and live station availability, and lists the projects showcased as built on CityBikes.

Host: citybik.es. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

list-networks

List all bike-sharing networks worldwide, with id, name, city, country, operating company and API href Params: api_fields Read-only

curl 'https://clify-dev.netlify.app/citybik/list-networks?api_fields=id%2Cname%2Chref'

get-network

Get details of one bike-sharing network by id (name, location, company, GBFS feed, system), without the station list Params: network_id* Read-only

curl 'https://clify-dev.netlify.app/citybik/get-network?network_id=velib'

list-network-stations

List the live stations of a bike-sharing network, with available bikes, empty docks, coordinates and last update time Params: network_id* Read-only

curl 'https://clify-dev.netlify.app/citybik/list-network-stations?network_id=bicing'

list-projects

List the apps and projects that the CityBikes showcase page lists as built on CityBikes data Params: none Read-only

curl 'https://clify-dev.netlify.app/citybik/list-projects'
