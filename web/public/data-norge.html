data-norge API for agents (unofficial) — JSON over curl

data.norge.no (Felles datakatalog) is Norway's national data portal. This CLI searches and looks up datasets, APIs (data services), concepts, information models, public services/events and publishing organizations through the portal's public JSON APIs.

Host: data.norge.no. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

data.cdc.gov

data.cdc.gov is the CDC's open-data portal (Socrata). This CLI searches the dataset catalog, lists categories and tags, reads dataset metadata, and queries or exports dataset rows through the public Socrata Discovery, SODA and views APIs.
