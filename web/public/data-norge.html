data-norge API for agents (unofficial) — JSON over curl | clify

data.norge.no (Felles datakatalog) is Norway's national data portal. This CLI searches and looks up datasets, APIs (data services), concepts, information models, public services/events and publishing organizations through the portal's public JSON APIs.

Host: data.norge.no. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

suggest-resources

Quick title suggestions (top 10 matching resources of any type) for a search term Params: q*

curl 'https://clify-dev.netlify.app/data-norge/suggest-resources?q=befolkning'

ai-search

Natural-language AI search over the catalog metadata (e.g. 'Hvor mange bor i Oslo'); returns the most relevant resources Params: query*, type

curl 'https://clify-dev.netlify.app/data-norge/ai-search'

get-dataset

Get full metadata for a dataset by id (JSON via the resource service): description, distributions, themes, publisher, contact Params: id*

curl 'https://clify-dev.netlify.app/data-norge/get-dataset'

get-data-service

Get full metadata for an API (data service) by id (JSON via the resource service): endpoint URLs, documentation, formats, publisher Params: id*

curl 'https://clify-dev.netlify.app/data-norge/get-data-service'

get-concept

Get a concept (term definition) by id: preferred labels, definition and sources, remarks, subject, related concepts, publisher Params: id*

curl 'https://clify-dev.netlify.app/data-norge/get-concept'

get-resource-rdf

Get the raw RDF (Turtle) description of a dataset or data service, exactly as harvested Params: type*, id*

curl 'https://clify-dev.netlify.app/data-norge/get-resource-rdf'

list-organizations

List publishing organizations with org number, orgPath and counts of datasets, concepts, APIs and information models Params: includeEmpty

curl 'https://clify-dev.netlify.app/data-norge/list-organizations?includeEmpty=true'

get-organization

Get an organization's profile by org number: details plus counts of datasets (open, authoritative, quality score), APIs, concepts and information models Params: orgId*

curl 'https://clify-dev.netlify.app/data-norge/get-organization'

list-data-themes

List EU data theme codes and labels, for the dataTheme filter Params: none

curl 'https://clify-dev.netlify.app/data-norge/list-data-themes'

list-los-themes

List the LOS (Norwegian public sector) themes and words with paths and synonyms, for the losTheme filter Params: none

curl 'https://clify-dev.netlify.app/data-norge/list-los-themes'
