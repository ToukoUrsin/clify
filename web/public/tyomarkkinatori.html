tyomarkkinatori API for agents (unofficial) — JSON over curl | clify

Työmarkkinatori (tyomarkkinatori.fi), the Finnish public employment services portal. This CLI searches open job postings and reads their details, searches public trainings and services and reads course and service details, lists occupation info pages, and reads the code lists the site's filters use (municipalities, regions, working time, languages and so on).

Host: tyomarkkinatori.fi. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-jobs

Full-text search of open job postings, with optional municipality and publish-date filters, sorting and paging Params: query*, municipality, publishedAfter, sort, page, pageSize

curl 'https://clify-dev.netlify.app/tyomarkkinatori/search-jobs'

get-job-posting

Get the full public details of one job posting by its UUID: description, employer, location, contacts, application info Params: id*

curl 'https://clify-dev.netlify.app/tyomarkkinatori/get-job-posting'

list-codes

List the codes in a KOPA code list, e.g. municipalities, regions, working time, employment relationship or languages. Use these codes to interpret job posting fields and job search filters. Params: codeset*, validOn*

curl 'https://clify-dev.netlify.app/tyomarkkinatori/list-codes?validOn=2026-10-18'

list-isco-occupations

Get the ISCO occupation group hierarchy (notation codes with fi/sv/en labels and nested narrower groups). Job search uses these as occupation groups. Params: none

curl 'https://clify-dev.netlify.app/tyomarkkinatori/list-isco-occupations'

search-trainings

Search public trainings and services (courses, labour market training) by keyword, with offset paging Params: query*, pageSize, offset

curl 'https://clify-dev.netlify.app/tyomarkkinatori/search-trainings'

get-training

Get one training or course implementation by token: dates, location, description, language requirements, registration link and provider Params: token*

curl 'https://clify-dev.netlify.app/tyomarkkinatori/get-training'

get-service

Get the general description of a service or training product (description, requirements, target groups, category, its offerings) by service token Params: token*

curl 'https://clify-dev.netlify.app/tyomarkkinatori/get-service'

list-service-categories

List the service and training categories (codes like PK1, PK7.3 with names) used in the trainings and services catalogue Params: language

curl 'https://clify-dev.netlify.app/tyomarkkinatori/list-service-categories'

list-service-codes

List a code set used by the trainings and services catalogue, e.g. target groups, language skill levels or education codes Params: codeset*, language

curl 'https://clify-dev.netlify.app/tyomarkkinatori/list-service-codes'

list-professions

List all occupations that have an occupation info page (label and slug path), for use with get-profession Params: locale

curl 'https://clify-dev.netlify.app/tyomarkkinatori/list-professions?locale=fi'

list-profession-fields

List occupational fields (ammattialat) with their info page paths Params: locale

curl 'https://clify-dev.netlify.app/tyomarkkinatori/list-profession-fields?locale=fi'

get-profession

Read an occupation info page (job description, education, outlook) by slug Params: slug*

curl 'https://clify-dev.netlify.app/tyomarkkinatori/get-profession'
