eventbrite API for agents (unofficial) — JSON over curl

Eventbrite: discover public events by city, category and date, with venues, prices, event URLs, ticket info and organizer listings.

Host: eventbrite.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-events

List upcoming events in a place, filtered by category tag and date range. Returns name, URL, date, venue and lowest price. Params: placeId, tag, dates, online_only, sort, page_size, page Read-only

curl 'https://clify-dev.netlify.app/eventbrite/search-events?placeId=85922583&tag=EventbriteCategory%2F102'

list-home-feed

Home-page event feed for a place: all upcoming, today, or this weekend. Params: placeId*, tab Read-only

curl 'https://clify-dev.netlify.app/eventbrite/list-home-feed?placeId=85922583&tab=all'

get-event

Event page details: title, description, start/end time, image and canonical URL. Params: slug* Read-only

curl 'https://clify-dev.netlify.app/eventbrite/get-event?slug=powering-the-ai-economy-tickets-1991588433617'

get-ticket-info

Ticket prices and availability for an event: min/max price, free, sold out, sales window. Params: eventId*, organizationId*, eventTimezone Read-only

curl 'https://clify-dev.netlify.app/eventbrite/get-ticket-info?eventId=1991588433617&organizationId=13560180433'

list-related-events

Events similar to a given event, with dates, venue and formatted price. Params: eventId*, organizerId* Read-only

curl 'https://clify-dev.netlify.app/eventbrite/list-related-events?eventId=2003316175609&organizerId=74429624673'

list-organizer-events

An organizer's upcoming events from a date, soonest first. Params: organizerId*, from_date*, page, page_size Read-only

curl 'https://clify-dev.netlify.app/eventbrite/list-organizer-events?organizerId=74429624673&from_date=2026-10-21'

list-organizer-past-events

An organizer's past events, newest first. Params: organizerId*, page, pageSize Read-only

curl 'https://clify-dev.netlify.app/eventbrite/list-organizer-past-events?organizerId=74429624673'

get-organizer-stats

Organizer track record: years hosting, total events, attendees hosted, verified/badge. Params: organizerId* Read-only

curl 'https://clify-dev.netlify.app/eventbrite/get-organizer-stats?organizerId=74429624673'

get-urgency-signals

Demand signals for an event, e.g. goingFast, fewTickets, salesEndSoon. Params: eventId* Read-only

curl 'https://clify-dev.netlify.app/eventbrite/get-urgency-signals?eventId=1991588433617'

get-current-place

Place Eventbrite infers from the caller's IP: placeId, city name and slug. Params: none Read-only

curl 'https://clify-dev.netlify.app/eventbrite/get-current-place'
