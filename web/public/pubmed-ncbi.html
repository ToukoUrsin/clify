pubmed-ncbi API for agents (unofficial) — JSON over curl | clify

PubMed (NCBI biomedical literature database): search articles by keyword, author or field-tagged query, with filters, sorting and pagination, and fetch full abstract records, MEDLINE text exports and PMID lists. All commands read the server-rendered search page.

Host: pubmed.ncbi.nlm.nih.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-articles

Search PubMed articles by keyword or field-tagged query with optional filters, sort, author ID and pagination; returns summary results (PMID, title, authors, citation, snippet) Params: term*, sort, sort_order, filter, filter2, filter3, cauthor_id, page, size

curl 'https://clify-dev.netlify.app/pubmed-ncbi/search-articles?term=crispr&filter=simsearch2.ffrft&filter2=pubt.review&filter3=datesearch.y_5&cauthor_id=27699445'

get-articles

Get full article records (title, authors, affiliations, PMID/PMCID/DOI, journal, abstract, full-text links) for a query, typically a list of PMIDs; this replaces the blocked article detail pages Params: term*, sort, filter, page, size

curl 'https://clify-dev.netlify.app/pubmed-ncbi/get-articles?term=31727474%5Bpmid%5D+OR+36163606%5Bpmid%5D'

export-medline

Export search results as plain-text MEDLINE/PubMed records (all tagged fields: PMID, TI, AB, AU, AD, MH, DP, etc.) Params: term*, sort, filter, page, size

curl 'https://clify-dev.netlify.app/pubmed-ncbi/export-medline?term=31727474%5Bpmid%5D+OR+36163606%5Bpmid%5D'

list-pmids

Get only the PMIDs that match a search query, as a plain list (up to 200 per page); a cheap way to collect IDs for get-articles Params: term*, sort, sort_order, filter, filter2, page, size

curl 'https://clify-dev.netlify.app/pubmed-ncbi/list-pmids?term=crispr'
