techcrunch API for agents (unofficial) — JSON over curl

TechCrunch tech and startup news. This CLI lists recent articles from the site's RSS feeds by topic category, tag, or author, and looks up single articles. Each result includes title, date, author and URL.

Host: techcrunch.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

list-category-articles

List the newest articles in a TechCrunch category, such as AI or startups, via its RSS feed. Returns title, link, author, pubDate and categories. Params: category*, page Read-only

curl 'https://clify-dev.netlify.app/techcrunch/list-category-articles?category=artificial-intelligence&page=2'

list-tag-articles

List the newest articles carrying a TechCrunch tag, such as san-francisco or generative-ai, via the tag's RSS feed. Returns title, link, author and pubDate. Params: tag*, page Read-only

curl 'https://clify-dev.netlify.app/techcrunch/list-tag-articles?tag=san-francisco&page=2'

list-latest-articles

List the latest TechCrunch articles across the whole site via the main RSS feed. Returns title, link, author, pubDate and categories. Params: page Read-only

curl 'https://clify-dev.netlify.app/techcrunch/list-latest-articles?page=2'

list-author-articles

List the newest articles by one TechCrunch author via the author's RSS feed. Params: author*, page Read-only

curl 'https://clify-dev.netlify.app/techcrunch/list-author-articles?author=dominic-madori-davis&page=2'

get-article

Get one TechCrunch article by its slug (the last path segment of the article URL). Returns title, author, published date, description and canonical URL. Params: slug* Read-only

curl 'https://clify-dev.netlify.app/techcrunch/get-article?slug=ai-assistant-startup-town-nabs-unicorn-valuation-four-months-after-launch'
