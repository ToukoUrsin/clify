jsdelivr API for agents (unofficial) — JSON over curl

jsDelivr is a free open-source CDN for npm and GitHub. This CLI searches npm packages, lists package versions, files, entrypoints and readmes, and reads CDN usage statistics (per package, version and file, top packages, network, countries, browsers, platforms and proxies) through jsDelivr's public data API and its Algolia search index.

Host: jsdelivr.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-packages

Full-text search of npm packages hosted on jsDelivr (Algolia index), with optional facet filters such as module type, style type or author Params: query*, page, hitsPerPage, filters Read-only

curl 'https://clify-dev.netlify.app/jsdelivr/search-packages?query=react'

get-npm-package-info

Get full npm metadata for a package from the search index: description, latest version, version release dates, npm downloads, jsDelivr hits, repo and owner Params: name* Read-only

curl 'https://clify-dev.netlify.app/jsdelivr/get-npm-package-info?name=react-router-dom'

list-package-versions

List all versions and dist-tags of an npm package or GitHub repo hosted on jsDelivr Params: type*, name* Read-only

curl 'https://clify-dev.netlify.app/jsdelivr/list-package-versions?type=npm&name=react-router-dom'

list-package-files

Get the file tree (names, sizes, SHA-256 hashes) and default file of a specific package version Params: type*, name*, version* Read-only

curl 'https://clify-dev.netlify.app/jsdelivr/list-package-files?type=npm&name=react-router-dom&version=7.18.4'

get-package-entrypoints

Get the resolved JS/CSS entrypoint files of an npm package version (the file served by the short CDN URL) Params: name*, version* Read-only

curl 'https://clify-dev.netlify.app/jsdelivr/get-package-entrypoints?name=react-router-dom&version=7.18.4'

curl 'https://clify-dev.netlify.app/jsdelivr/get-package-readme?type=npm&name=react-router-dom'

get-package-stats

Get CDN hits and bandwidth for a package over a period, with daily breakdown, rank and previous-period comparison Params: type*, name*, period Read-only

curl 'https://clify-dev.netlify.app/jsdelivr/get-package-stats?type=npm&name=react-router-dom&period=month'
