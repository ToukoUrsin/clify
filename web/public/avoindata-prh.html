avoindata-prh API for agents (unofficial) — JSON over curl

PRH (Finnish Patent and Registration Office) open-data APIs: search and look up Finnish companies (YTJ), browse trade register notices, and fetch digital (XBRL) financial statements.

Host: avoindata.prh.fi. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-companies

Search Finnish companies (YTJ) by name, location, company form, main business line and registration date range Params: name, location, businessId, companyForm, mainBusinessLine, registrationDateStart, registrationDateEnd, page Read-only

curl 'https://clify-dev.netlify.app/avoindata-prh/search-companies?name=Nokia&location=Helsinki&companyForm=OY&mainBusinessLine=62&registrationDateStart=2023-01-01&registrationDateEnd=2024-12-31&page=2'

get-company

Get full YTJ basic details of one company by business ID (Y-tunnus) Params: businessId* Read-only

curl 'https://clify-dev.netlify.app/avoindata-prh/get-company?businessId=0112038-9'

get-company-notices

Get a company's trade register details and its list of registered notices by business ID Params: businessId* Read-only

curl 'https://clify-dev.netlify.app/avoindata-prh/get-company-notices?businessId=0112038-9'

get-notice

Get one registered trade register notice by its record year and number (record number YYYY/NNNNNN) Params: year*, number* Read-only

curl 'https://clify-dev.netlify.app/avoindata-prh/get-notice?year=2026&number=178844'

search-notices

Search companies with registered trade register notices by entry code and notice registration date range Params: entryCode, noticeRegistrationDateStart, noticeRegistrationDateEnd, page Read-only

curl 'https://clify-dev.netlify.app/avoindata-prh/search-notices?entryCode=HAL&noticeRegistrationDateStart=2026-10-01&noticeRegistrationDateEnd=2026-10-15&page=2'

list-code-descriptions

Get a YTJ code list (e.g. company forms YRMU) as tab-separated text: abbreviation, code, description Params: code*, lang Read-only

curl 'https://clify-dev.netlify.app/avoindata-prh/list-code-descriptions?code=YRMU&lang=fi'

list-financial-periods

List the fiscal periods for which a company has digital (XBRL) financial statement data Params: businessId* Read-only

curl 'https://clify-dev.netlify.app/avoindata-prh/list-financial-periods?businessId=0100379-9'

get-financial-statement

Get one company's digital financial statement (XBRL income statement and balance sheet facts) for a fiscal period end date Params: businessId*, financialDate* Read-only

curl 'https://clify-dev.netlify.app/avoindata-prh/get-financial-statement?businessId=0100379-9&financialDate=2024-12-31'

list-financials-by-period

List all companies that have digital financial statements for a given fiscal period end date Params: financialDate*, page Read-only

curl 'https://clify-dev.netlify.app/avoindata-prh/list-financials-by-period?financialDate=2024-12-31'

list-financial-statements

List filed digital financial statements (businessId, period end, registration date), optionally by registration date range Params: registrationDateStart, registrationDateEnd, page Read-only

curl 'https://clify-dev.netlify.app/avoindata-prh/list-financial-statements?registrationDateStart=2026-10-01&registrationDateEnd=2026-10-15'

get-api-schema

Get the OpenAPI (YAML) specification of one PRH open-data API, including all parameters and code meanings Params: api*, lang Read-only

curl 'https://clify-dev.netlify.app/avoindata-prh/get-api-schema?api=opendata-ytj-api&lang=fi'
