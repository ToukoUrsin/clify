hankintailmoitukset API for agents (unofficial) — JSON over curl

Hilma (hankintailmoitukset.fi) is Finland's public procurement notice service. This CLI searches tender notices and procurement plans, fetches notice, procedure and plan details, browses CPV and NUTS codes, and reads statistics and Hilma announcements.

Host: hankintailmoitukset.fi. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.
