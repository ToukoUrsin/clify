hankintailmoitukset API for agents (unofficial) — JSON over curl | clify

Hilma (hankintailmoitukset.fi) is Finland's public procurement notice service. This CLI searches tender notices and procurement plans, fetches notice, procedure and plan details, browses CPV and NUTS codes, and reads statistics and Hilma announcements.

Host: hankintailmoitukset.fi. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-notices

Full-text search of Hilma procurement notices and plans (Azure Search, Lucene syntax), with filter, sort and paging Params: query*, filter, orderby, top, skip

curl 'https://clify-dev.netlify.app/hankintailmoitukset/search-notices?query=%28%28siivous+OR+siivous*%29%29'

get-enotice

Get the full eForms notice detail (lots, buyer, criteria, deadlines) by procedureId and noticeId Params: procedureId*, noticeId*

curl 'https://clify-dev.netlify.app/hankintailmoitukset/get-enotice'

get-procedure

Get an eForms procurement procedure (overview and its notices) by procedureId Params: procedureId*

curl 'https://clify-dev.netlify.app/hankintailmoitukset/get-procedure'

get-procurement-plan

Get a procurement plan (upcoming procurement) by planId Params: planId*

curl 'https://clify-dev.netlify.app/hankintailmoitukset/get-procurement-plan'

search-organisations

Search buyer organisations by name (used by the buyer filter) Params: query*, top

curl 'https://clify-dev.netlify.app/hankintailmoitukset/search-organisations?query=turku*'

search-cpv

Autocomplete search of CPV procurement classification codes by name or code Params: query*, top

curl 'https://clify-dev.netlify.app/hankintailmoitukset/search-cpv?query=siivous*'

get-cpv-tree

Get the full hierarchical CPV code tree with labels (large response) Params: contractType, lang
