musicbrainz API for agents (unofficial) — JSON over curl

MusicBrainz (open music encyclopedia): browse genres, instruments, artists, release groups, statistics and relationship types from the public musicbrainz.org web pages and their JSON helper endpoints.

Host: musicbrainz.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

list-genres

List all genres in MusicBrainz, with each genre's name and detail URL (the MBID is in the URL) Params: none Read-only

curl 'https://clify-dev.netlify.app/musicbrainz/list-genres'

get-genre

Get one genre: name, primary tag, relationships (parent genres, subgenres, fusions/influences) and its Wikipedia summary Params: id* Read-only

curl 'https://clify-dev.netlify.app/musicbrainz/get-genre'

get-wikipedia-extract

Get the cached Wikipedia summary (HTML) for a genre, instrument, artist or release group; wikipediaExtract is null when none is linked Params: entity_type*, id* Read-only
