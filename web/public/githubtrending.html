githubtrending API for agents (unofficial) — JSON over curl

GitHub (github.com): list trending repositories and developers by language and period, browse topic repositories, and read repository metadata such as languages, contributors, releases, latest commit, branches and README.

Host: github.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

list-trending-repos

List GitHub trending repositories for a period (daily/weekly/monthly) and programming language, with description, language, total stars, forks and stars gained in the period. Params: language*, since, spoken_language_code Read-only

curl 'https://clify-dev.netlify.app/githubtrending/list-trending-repos?language=python&since=daily'

list-trending-developers

List GitHub trending developers for a period and programming language, with their most popular repository. Params: language*, since Read-only

curl 'https://clify-dev.netlify.app/githubtrending/list-trending-developers?language=python'

list-topic-repos

List repositories tagged with a GitHub topic, sortable by stars, forks or last update. Params: topic*, s, o, page Read-only

curl 'https://clify-dev.netlify.app/githubtrending/list-topic-repos?topic=python&s=updated&o=desc'

get-repo-overview

Get repository sidebar data: latest release, contributor count and top contributors, language breakdown, dependents count and sponsors. Params: owner*, repo* Read-only

curl 'https://clify-dev.netlify.app/githubtrending/get-repo-overview?owner=vllm-project&repo=vllm'

get-repo-readme

Get the repository README (rendered HTML) and other overview files for a branch. Params: owner*, repo*, branch* Read-only

curl 'https://clify-dev.netlify.app/githubtrending/get-repo-readme?owner=vllm-project&repo=vllm&branch=main'

get-latest-commit

Get the latest commit on a repository's default branch: sha, date, author, message and CI status. Params: owner*, repo* Read-only

curl 'https://clify-dev.netlify.app/githubtrending/get-latest-commit?owner=vllm-project&repo=vllm'

list-repo-refs

List all branch or tag names of a repository. Params: owner*, repo*, type Read-only

curl 'https://clify-dev.netlify.app/githubtrending/list-repo-refs?owner=vllm-project&repo=vllm&type=branch'

get-branch-tag-count

Get the number of branches and tags in a repository. Params: owner*, repo* Read-only

curl 'https://clify-dev.netlify.app/githubtrending/get-branch-tag-count?owner=vllm-project&repo=vllm'

get-tree-commit-info

Get the last commit (sha, date, message) for each top-level file and folder of a repository. Params: owner*, repo* Read-only

curl 'https://clify-dev.netlify.app/githubtrending/get-tree-commit-info?owner=vllm-project&repo=vllm'

get-repo-sponsors

Get a repository's sponsorable accounts and external funding links. Params: owner*, repo* Read-only

curl 'https://clify-dev.netlify.app/githubtrending/get-repo-sponsors?owner=vllm-project&repo=vllm'
