clevelandart API for agents (unofficial) — JSON over curl | clify

Cleveland Museum of Art online collection: search and filter artworks (keyword, artist, culture, type, medium, department, gallery, on view, recent acquisitions), autocomplete collection terms, get artwork details, related artworks, gallery locations and deep-zoom image info.

Host: clevelandart.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-artworks

Search the CMA collection by keyword, with optional filters (type, department, artist, culture, on view, recently acquired), paged by offset Params: q, skip, api_limit, type, department, artists, culture, currently_on_view, recently_acquired

curl 'https://clify-dev.netlify.app/clevelandart/search-artworks?q=monet&skip=0&api_limit=100'

get-artwork

Get full details of one artwork by accession number (title, date, artist, culture, medium, measurements, credit line, description, provenance, images) Params: accession_number*

curl 'https://clify-dev.netlify.app/clevelandart/get-artwork'

list-related-artworks

List the 'See Also' related artworks shown on an artwork's detail page Params: accession_number*

curl 'https://clify-dev.netlify.app/clevelandart/list-related-artworks'

list-gallery-locations

List the museum's gallery locations (values accepted by the gallery= filter of search-artworks) Params: none

curl 'https://clify-dev.netlify.app/clevelandart/list-gallery-locations'

get-image-zoom-info

Get deep-zoom (DZI) metadata for an artwork image: full pixel width/height, tile size and format Params: image_id*

curl 'https://clify-dev.netlify.app/clevelandart/get-image-zoom-info'
