sunrise-sunset API for agents (unofficial) — JSON over curl | clify

sunrise-sunset.org gives sunrise, sunset and twilight times for any city. This CLI searches cities, fetches today's times, browses countries, regions and cities, reads monthly calendars and queries the public sunrise/sunset JSON API.

Host: sunrise-sunset.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-cities

Search cities by name. Returns numeric city ids and labels; use the id with get-today-times. Params: q*

curl 'https://clify-dev.netlify.app/sunrise-sunset/search-cities?q=Paris'

get-today-times

Get today's and tomorrow's sunrise/sunset widget for a city, selected by numeric id. Returns JSON with pre-rendered HTML fragments. Params: id*

curl 'https://clify-dev.netlify.app/sunrise-sunset/get-today-times?id=119890'

list-popular-today

Get today's sunrise/sunset cards for the most-searched cities in the visitor's country (grid), or for the visitor's geolocated city (geo). Params: grid, geo

curl 'https://clify-dev.netlify.app/sunrise-sunset/list-popular-today?grid=1&geo=1'

get-sun-times

Public JSON API: sunrise, sunset, solar noon, day length and twilight times for a latitude/longitude on one date or across a date range. Params: lat*, lng*, date, date_start, date_end

curl 'https://clify-dev.netlify.app/sunrise-sunset/get-sun-times?lat=48.853409&lng=2.3488&date=2026-10-18&date_start=2026-10-18&date_end=2026-10-25'

get-location-page

Open a city or region page by country code and slug (e.g. fr/paris, jp/tokyo, jp/tokyo-prefecture). Returns the page heading, title and meta description. Params: country_code*, slug*

curl 'https://clify-dev.netlify.app/sunrise-sunset/get-location-page'

list-countries

List all countries on the explore page. Each link leads to a country listing of regions and cities. Params: none

curl 'https://clify-dev.netlify.app/sunrise-sunset/list-countries'

list-country-locations

List the regions and cities for a country by its full-name slug (e.g. japan). Links point to /{cc}/{slug} pages usable with get-location-page. Params: country*

curl 'https://clify-dev.netlify.app/sunrise-sunset/list-country-locations'

get-monthly-calendar

Get the monthly sunrise/sunset calendar for a location by name. Returns one item per day with the date, sunrise and sunset text. Params: location*, month

curl 'https://clify-dev.netlify.app/sunrise-sunset/get-monthly-calendar?location=Tokyo&month=2026-11'
