openverse API for agents (unofficial) — JSON over curl | clify

Openverse (openverse.org) is a search engine for openly licensed images and audio. This CLI calls its public REST API at api.openverse.org/v1 to search media, get item details and related items, fetch audio waveforms and oEmbed data, list content sources, and check the anonymous rate limit.

Host: openverse.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-images

Search openly licensed images by keyword, with filters for license, category, aspect ratio, size, source, tags and creator Params: q*, page, page_size, license, license_type, category, aspect_ratio, size, source, tags, creator

curl 'https://clify-dev.netlify.app/openverse/search-images?q=cat&license=cc0%2Cby'

get-image-oembed

Get oEmbed data for an Openverse image page URL, for embedding with attribution Params: url*

curl 'https://clify-dev.netlify.app/openverse/get-image-oembed?url=https%3A%2F%2Fopenverse.org%2Fimage%2F1c5442f6-6bb6-4ab7-b603-f598e7579dd2'

list-image-sources

List all image content sources (e.g. flickr, wikimedia) with their media counts Params: none

curl 'https://clify-dev.netlify.app/openverse/list-image-sources'

search-audio

Search openly licensed audio by keyword, with filters for category, length, file extension, license and source Params: q*, page, page_size, category, length, extension, license, license_type, source

curl 'https://clify-dev.netlify.app/openverse/search-audio?q=piano'

list-audio-sources

List all audio content sources (e.g. freesound, jamendo) with their media counts Params: none

curl 'https://clify-dev.netlify.app/openverse/list-audio-sources'

get-rate-limit

Show the current API rate-limit status for this client (requests used and remaining) Params: none

curl 'https://clify-dev.netlify.app/openverse/get-rate-limit'
