thesportsdb API for agents (unofficial) — JSON over curl

TheSportsDB: an open, crowd-sourced sports database. This CLI searches teams and players, looks up events, league tables, fixtures, squads and TV schedules through the free public JSON API (key 123) and the server-rendered HTML pages.

Host: thesportsdb.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-teams

Search teams by name via the JSON API (full team record: ids, leagues, stadium, socials, descriptions) Params: team* Read-only

curl 'https://clify-dev.netlify.app/thesportsdb/search-teams?team=Arsenal'

search-players

Search players by name via the JSON API (team, nationality, position, birth date) Params: player* Read-only

curl 'https://clify-dev.netlify.app/thesportsdb/search-players?player=Messi'

get-event

Get one event/match by its event id (teams, scores, date/time, venue, round, season) Params: id* Read-only

curl 'https://clify-dev.netlify.app/thesportsdb/get-event?id=2494069'

get-league-table

Get the league standings table for a league id and season (rank, points, W/D/L, goals, form) Params: league*, season* Read-only

curl 'https://clify-dev.netlify.app/thesportsdb/get-league-table?league=4328&season=2025-2026'

list-next-league-events

List the next upcoming events (fixtures) of a league by league id Params: id* Read-only

curl 'https://clify-dev.netlify.app/thesportsdb/list-next-league-events?id=4328'

list-team-last-events

curl 'https://clify-dev.netlify.app/thesportsdb/list-team-last-events?id=133604'

list-events-by-day

List all events on a given date, optionally filtered by sport Params: date*, sport Read-only

curl 'https://clify-dev.netlify.app/thesportsdb/list-events-by-day?date=2026-10-18&sport=Soccer'

list-team-players

curl 'https://clify-dev.netlify.app/thesportsdb/list-team-players?id=133604'

list-leagues

curl 'https://clify-dev.netlify.app/thesportsdb/list-leagues'

search-site

curl 'https://clify-dev.netlify.app/thesportsdb/search-site?query=Arsenal&sport=Soccer'
