data-gov API for agents (unofficial) — JSON over curl

data.gov.uk (National Data Library): the UK government's open data directory. The CLI searches and reads dataset metadata through the public CKAN JSON API, lists data files and previews from dataset pages, and browses the curated theme collections and their chart data.

Host: data.gov.uk. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-datasets

Search the UK open data directory (CKAN package_search). Returns dataset metadata including publisher, licence and resources. Filter with Solr fq, sort, and page by offset. Params: q*, fq, sort, rows, start Read-only

curl 'https://clify-dev.netlify.app/data-gov/search-datasets?q=air+quality'

get-dataset

Get full metadata for one dataset by its UUID or CKAN name (CKAN package_show). Includes publisher, licence, description and every resource with its URL, format and date. Params: id* Read-only

curl 'https://clify-dev.netlify.app/data-gov/get-dataset?id=bfaf890c-0ebc-42f7-954d-9cde251902a2'

list-dataset-files

List the data links shown on a dataset page on data.gov.uk: name, format, date, and the link or preview URL for each file. Params: id*, slug* Read-only

curl 'https://clify-dev.netlify.app/data-gov/list-dataset-files?id=3f5d7bbf-73af-46cd-8b9e-8e07cedb9506&slug=bristol-air-quality'

preview-datafile

Open the preview page for one data file of a dataset. Shows the file title and a preview, or a message saying no preview is available. Params: id*, slug*, file_id* Read-only

curl 'https://clify-dev.netlify.app/data-gov/preview-datafile?id=3f5d7bbf-73af-46cd-8b9e-8e07cedb9506&slug=bristol-air-quality&file_id=6d9e0be5-6917-4eb8-9337-61ea19511911'

list-filter-options

List the filter values the directory search offers (publisher names, topics and formats). Use these to build search filters. Params: none Read-only

curl 'https://clify-dev.netlify.app/data-gov/list-filter-options'

list-collections

List the curated theme collections on the data.gov.uk home page (Business and economy, Environment, etc.). Params: none Read-only

curl 'https://clify-dev.netlify.app/data-gov/list-collections'

list-collection-topics

List the topics inside a theme collection, e.g. environment has weather and air-quality. Params: theme* Read-only

curl 'https://clify-dev.netlify.app/data-gov/list-collection-topics?theme=environment'

get-collection-topic

Get a collection topic page: headline chart title, description, the chart-data download link and the external 'get the data' link. Params: theme*, topic* Read-only

curl 'https://clify-dev.netlify.app/data-gov/get-collection-topic?theme=environment&topic=weather'

download-collection-chart-data

Download the raw data behind a collection topic's headline chart, e.g. the UK annual mean temperature series. Params: theme*, topic* Read-only

curl 'https://clify-dev.netlify.app/data-gov/download-collection-chart-data?theme=environment&topic=air-quality'

data-cdc

data.cdc.gov

data.cdc.gov is the CDC's open-data portal (Socrata). This CLI searches the dataset catalog, lists categories and tags, reads dataset metadata, and queries or exports dataset rows through the public Socrata Discovery, SODA and views APIs.

data.cityofnewyork.us

NYC Open Data (Socrata catalog at data.cityofnewyork.us). The CLI searches the dataset catalog by keyword, tag, category and sort order; reads dataset metadata and columns; runs SoQL queries against rows; exports CSV; and lists change history and attachments. It needs no login.
