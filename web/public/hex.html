hex API for agents (unofficial) — JSON over curl

Hex (hex.pm), the package registry for the Erlang/Elixir/Gleam ecosystem. The CLI searches packages, reads package, release, owner and user metadata from the public JSON API, lists dependents, reads raw release files and shows per-user download stats.

Host: hex.pm. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-packages

Search Hex packages by keyword, with optional qualifiers (depends:hexpm:<pkg>, build_tool:<tool>), sorting and pagination. Params: search, sort, page Read-only

curl 'https://clify-dev.netlify.app/hex/search-packages?search=json'

list-package-dependents

List packages on the hexpm repository that depend on a given package. Params: name*, sort, page Read-only

curl 'https://clify-dev.netlify.app/hex/list-package-dependents'

get-package

Get package details: description, licenses, links, owners, latest versions, download counts, retirements, security advisories and dependency config snippets. Params: name* Read-only

curl 'https://clify-dev.netlify.app/hex/get-package'

list-package-versions

List all released versions of a package, newest first, with docs availability and publish date. Params: name* Read-only

curl 'https://clify-dev.netlify.app/hex/list-package-versions'

get-release

Get one release of a package: checksum, dependency requirements, build tools, Elixir requirement, publisher, retirement status, downloads and advisories. Params: name*, version* Read-only

curl 'https://clify-dev.netlify.app/hex/get-release'

list-package-owners

List the owners of a package, with ownership level, email and social handles. Params: name* Read-only

curl 'https://clify-dev.netlify.app/hex/list-package-owners'

get-user

Get a Hex user's public profile and the full list of packages they own. Params: username* Read-only

curl 'https://clify-dev.netlify.app/hex/get-user'

get-user-stats

Show per-package download stats for a user's packages: total, yesterday and last 7 days. Params: username* Read-only

curl 'https://clify-dev.netlify.app/hex/get-user-stats'

get-release-file

Fetch the raw contents of a file inside a package release (e.g. README.md, CHANGELOG.md, mix.exs, lib/...). Params: name*, version*, path* Read-only

curl 'https://clify-dev.netlify.app/hex/get-release-file'
