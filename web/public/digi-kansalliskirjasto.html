digi-kansalliskirjasto API for agents (unofficial) — JSON over curl

Finnish National Library's Digi service (digitized newspapers, journals, books, maps, music and more). The CLI searches full text and metadata, reads issue (binding) details and page OCR text, browses serial titles by year, searches user-made clippings, lists collections, and harvests OAI-PMH metadata.

Host: digi.kansalliskirjasto.fi. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-materials

Full-text and metadata search over digitized materials. Returns matching pages (bindings) with OCR highlights. Params: query*, format, orderBy, startDate, endDate, fuzzy, requireAllKeywords, queryTargetsOcrText, queryTargetsMetadata, offset, count Read-only

curl 'https://clify-dev.netlify.app/digi-kansalliskirjasto/search-materials'

search-articles

Search component parts (articles or sections within issues) by keyword. Returns article titles with their binding and page. Params: query*, format, orderBy, startDate, endDate, offset, count Read-only

curl 'https://clify-dev.netlify.app/digi-kansalliskirjasto/search-articles'

get-binding

Get details of one issue or volume (binding): title, date, ISSN, page list with image URLs, PDF link and citation info. Params: id* Read-only

curl 'https://clify-dev.netlify.app/digi-kansalliskirjasto/get-binding?id=407492'

curl 'https://clify-dev.netlify.app/digi-kansalliskirjasto/get-page-ocr?bindingId=407492&page=8'

curl 'https://clify-dev.netlify.app/digi-kansalliskirjasto/get-ocr-hits?page=34&term=Sibelius'
