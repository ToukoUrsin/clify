svt API for agents (unofficial) — JSON over curl

SVT (Sveriges Television) news and sport site, svt.se. This CLI lists section, local and tag feeds, reads articles and their related teasers, looks up video clip metadata and streams, and reads Text-TV pages.

Host: svt.se. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

list-section-articles

List the latest article teasers (headline, lead, URL) in a news section such as utrikes or inrikes. Params: section* Read-only

curl 'https://clify-dev.netlify.app/svt/list-section-articles?section=utrikes'

list-local-news

List the top local news teasers for an SVT region, e.g. stockholm. Params: region* Read-only

curl 'https://clify-dev.netlify.app/svt/list-local-news?region=stockholm'

get-article

Get one article's metadata (headline, description, publish date, authors, image) from its schema.org NewsArticle data. Params: category*, section*, slug* Read-only

curl 'https://clify-dev.netlify.app/svt/get-article?category=nyheter&section=utrikes&slug=stromavbrott-pa-hela-sri-lanka'

get-related-trailers

Get the related teaser groups (more from the same section or sport) shown under an article or page. Params: path* Read-only

curl 'https://clify-dev.netlify.app/svt/get-related-trailers?path=%2Fnyheter%2Futrikes%2Fstromavbrott-pa-hela-sri-lanka'

get-video

Get metadata and stream URLs (HLS/DASH, subtitles, rights, geo-block flag) for an SVT video clip by its svtId. Params: id* Read-only

curl 'https://clify-dev.netlify.app/svt/get-video?id=8Dva4VJ'

get-text-tv-page

Read an SVT Text-TV page by number (e.g. 100 news index, 101, 377 sport results); includes plain-text content and prev/next page numbers. Params: page* Read-only

curl 'https://clify-dev.netlify.app/svt/get-text-tv-page?page=101'
