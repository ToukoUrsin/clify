svt API for agents (unofficial) — JSON over curl | clify

SVT (Sveriges Television) news and sport site, svt.se. This CLI lists section, local and tag feeds, reads articles and their related teasers, looks up video clip metadata and streams, and reads Text-TV pages.

Host: svt.se. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

list-section-articles

List the latest article teasers (headline, lead, URL) in a news section such as utrikes or inrikes. Params: section*

curl 'https://clify-dev.netlify.app/svt/list-section-articles'

list-local-news

List the top local news teasers for an SVT region, e.g. stockholm. Params: region*

curl 'https://clify-dev.netlify.app/svt/list-local-news'

get-article

Get one article's metadata (headline, description, publish date, authors, image) from its schema.org NewsArticle data. Params: category*, section*, slug*

curl 'https://clify-dev.netlify.app/svt/get-article'

get-related-trailers

Get the related teaser groups (more from the same section or sport) shown under an article or page. Params: path*

curl 'https://clify-dev.netlify.app/svt/get-related-trailers'

get-video

Get metadata and stream URLs (HLS/DASH, subtitles, rights, geo-block flag) for an SVT video clip by its svtId. Params: id*

curl 'https://clify-dev.netlify.app/svt/get-video'

get-text-tv-page

Read an SVT Text-TV page by number (e.g. 100 news index, 101, 377 sport results); includes plain-text content and prev/next page numbers. Params: page*

curl 'https://clify-dev.netlify.app/svt/get-text-tv-page'
