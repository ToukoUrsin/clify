ashby API for agents (unofficial) — JSON over curl

Ashby-hosted startup job boards (jobs.ashbyhq.com/{org}): list a company's open roles with locations, compensation and apply links, browse its departments, read company info, and fetch full job details.

Host: jobs.ashbyhq.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

list-jobs

List every open job on a company's Ashby board, with title, department, location, workplace/employment type, job URL and apply URL (public Job Postings API). Params: org*, includeCompensation Read-only

curl 'https://clify-dev.netlify.app/ashby/list-jobs?org=ramp'

get-job

Get one job posting's full details: title, department, teams, location(s), workplace/employment type, compensation tiers and HTML description. Params: org*, jobId* Read-only

curl 'https://clify-dev.netlify.app/ashby/get-job?org=ramp&jobId=f564dcf9-9390-4a3f-896f-8047a5086040'

list-teams

List a company's departments/teams (id, name, parentTeamId hierarchy) as used by the board's department filter. Params: org* Read-only

curl 'https://clify-dev.netlify.app/ashby/list-teams?org=ramp'

get-company

Get company info for a job board slug: name, organization id, public website, custom careers page URL and privacy policy URL. Params: org* Read-only

curl 'https://clify-dev.netlify.app/ashby/get-company?org=ramp'
