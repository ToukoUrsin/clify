remoteok API for agents (unofficial) — JSON over curl

RemoteOK (remoteok.com) is a remote job board. This CLI searches and filters remote job listings, reads the public JSON jobs API, opens job details, lists related jobs, company jobs and country jobs, and lists the job tag catalog. No login is needed.

Host: remoteok.com. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-jobs

Search and filter remote job listings by keyword, tags, location, minimum salary, benefit and company, with sorting Params: search, tags, location, min_salary, benefits, company, order_by, offset Read-only

curl 'https://clify-dev.netlify.app/remoteok/search-jobs?search=python&tags=dev%2Cpython&location=US&min_salary=100000&benefits=401k&company=Kodland'

list-jobs-api

List the latest remote jobs as clean JSON from RemoteOK's public API, optionally filtered by one tag (includes salary, location, description and apply URL) Params: tag Read-only

curl 'https://clify-dev.netlify.app/remoteok/list-jobs-api?tag=python'

get-job

Get the details of one remote job (position, company, location, tags, full description, apply link) by its slug Params: slug* Read-only

curl 'https://clify-dev.netlify.app/remoteok/get-job'

list-related-jobs

List jobs related to a given job (same tag), excluding that job Params: except_id*, tags Read-only

curl 'https://clify-dev.netlify.app/remoteok/list-related-jobs?except_id=1137534&tags=python'

list-tags

List every job tag key with its display label (use the keys for the tags/tag params) Params: none Read-only

curl 'https://clify-dev.netlify.app/remoteok/list-tags'
