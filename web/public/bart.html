bart API for agents (unofficial) — JSON over curl

BART (Bay Area Rapid Transit) website. The CLI lists stations and returns real-time departures, station timetables, service and elevator/escalator alerts, planned advisories, accessibility options, and routes, trips and fares from BART's public API.

Host: bart.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

get-departures

Real-time departures (ETD) for a station: next trains per destination with minutes, platform, direction, length and line color (official BART API). Params: station*, platform, direction Read-only

curl 'https://clify-dev.netlify.app/bart/get-departures?station=EMBR'

list-stations

List all BART stations with name and station page URL. The slug in the URL (e.g. embr) is the station code. Params: none Read-only

curl 'https://clify-dev.netlify.app/bart/list-stations'

plan-trip

Plan a BART trip between two stations: departure/arrival times, travel time, fare and legs (official BART API). Params: orig*, dest*, date, time, before, after Read-only

curl 'https://clify-dev.netlify.app/bart/plan-trip?orig=EMBR&dest=SFIA'

get-fare

Fare between two BART stations (Clipper, cash and discount fares) from the official BART API. Params: orig*, dest* Read-only

curl 'https://clify-dev.netlify.app/bart/get-fare?orig=EMBR&dest=SFIA'

list-routes

List BART routes/lines with route number, name, abbreviation and color (official BART API). Params: none Read-only

curl 'https://clify-dev.netlify.app/bart/list-routes'

get-station

Station details: name, address, description and lines serving the station. Params: station* Read-only

curl 'https://clify-dev.netlify.app/bart/get-station?station=embr'

get-station-schedule

Full-day timetable of train departures from a station: line, train head station, departure time (official BART API). Params: station*, date Read-only

curl 'https://clify-dev.netlify.app/bart/get-station-schedule?station=EMBR'

get-current-advisories

Current BART service advisories (delays, disruptions) from the official BART API. Params: none Read-only

curl 'https://clify-dev.netlify.app/bart/get-current-advisories'

list-planned-advisories

Planned service advisories (track work, bus bridges, line cancellations) from the RSS feed, with links to the full articles. Params: none Read-only

curl 'https://clify-dev.netlify.app/bart/list-planned-advisories'

get-station-accessibility

Elevator outage options and accessible paths for a station: what to do if you can't enter or exit. Params: station* Read-only

curl 'https://clify-dev.netlify.app/bart/get-station-accessibility?station=EMBR'

get-news-article

Full text of a BART news article or planned service advisory, using the year and slug from its /news/articles/{year}/{slug} link. Params: year*, slug* Read-only

curl 'https://clify-dev.netlify.app/bart/get-news-article?year=2026&slug=news20261015'
