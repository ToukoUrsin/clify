ec-europa API for agents (unofficial) — JSON over curl

Eurostat Data Browser (ec.europa.eu/eurostat/databrowser): search and browse EU statistical datasets, inspect dataset metadata, dimensions, codelists and related tables, and fetch data through the public JSON-stat dissemination API.

Host: ec.europa.eu. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-datasets

Search Eurostat datasets by keyword (autocomplete suggestions). Returns dataset codes with highlighted titles. Params: text*, lang Read-only

curl 'https://clify-dev.netlify.app/ec-europa/search-datasets?text=unemployment'

list-all-datasets

List every Eurostat dataflow (code, title, last data/structure update). Set comext=true for the Comext (international trade) database. Large response. Params: comext, lang Read-only

curl 'https://clify-dev.netlify.app/ec-europa/list-all-datasets?comext=false'

list-themes

List top-level statistical themes (navigation tree roots). crossCutting=true returns the cross-cutting / EU-policy themes instead. Params: crossCutting, lang Read-only

curl 'https://clify-dev.netlify.app/ec-europa/list-themes?crossCutting=false'

get-theme-navtree

Get the category navigation tree under a theme (e.g. popul = Population and social conditions). Params: theme*, lang Read-only

curl 'https://clify-dev.netlify.app/ec-europa/get-theme-navtree?theme=popul'

get-full-tree

Get the full Eurostat navigation tree (categories and datasets), optionally only the branch under one category code. Params: node, lang Read-only

curl 'https://clify-dev.netlify.app/ec-europa/get-full-tree?node=une'

list-category-datasets

List the datasets in a navigation-tree category (e.g. scheme popul, category une = unemployment), with titles, update dates and links. Params: scheme*, category*, lang Read-only

curl 'https://clify-dev.netlify.app/ec-europa/list-category-datasets?scheme=popul&category=une'

get-dataset-info

Get dataset metadata: title, description, observation count, time coverage, last data/structure update, DOI, source dataset, metadata links. Params: code*, lang Read-only

curl 'https://clify-dev.netlify.app/ec-europa/get-dataset-info?code=tps00203'

get-dataset-status

Check that a dataset code exists and has data; returns its canonical id, default view id and last data/structure update timestamps (ms). Params: code* Read-only

curl 'https://clify-dev.netlify.app/ec-europa/get-dataset-status?code=une_rt_m'

get-dataset-dimensions

List a dataset's dimensions (freq, geo, sex, age, unit, ...) with all available codes and labels. Use these codes as filters in get-data. Params: code*, lang Read-only

curl 'https://clify-dev.netlify.app/ec-europa/get-dataset-dimensions?code=une_rt_m'

get-dataset-categories

Get where a dataset sits in the navigation tree (theme and category breadcrumbs). Params: code*, lang Read-only

curl 'https://clify-dev.netlify.app/ec-europa/get-dataset-categories?code=une_rt_m'

get-dataset-relations

List datasets derived from this dataset and the source dataset(s) it is derived from (code -> title). Params: code*, lang Read-only

curl 'https://clify-dev.netlify.app/ec-europa/get-dataset-relations?code=une_rt_m'

get-data

Fetch dataset values as JSON-stat from the public statistics API, filtered by dimension codes (geo, sex, age, unit, s_adj, na_item, ...) and time range. Params: dataset*, geo, sex, age, unit, s_adj, na_item, freq, sinceTimePeriod, untilTimePeriod, lastTimePeriod, lang Read-only

curl 'https://clify-dev.netlify.app/ec-europa/get-data?dataset=une_rt_m&geo=DE&sex=T&age=TOTAL&unit=PC_ACT&s_adj=SA&lastTimePeriod=3'

get-codelist

Get all codes and labels of a Eurostat codelist (e.g. geo = countries/regions/aggregates). Params: codelist*, lang Read-only

curl 'https://clify-dev.netlify.app/ec-europa/get-codelist?codelist=geo'
