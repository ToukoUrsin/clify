data-europa API for agents (unofficial) — JSON over curl

data.europa.eu (the official EU open data portal): search EU and national open datasets, catalogues and data services, read dataset and catalogue metadata, find similar datasets, and export DCAT metadata.

Host: data.europa.eu. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-datasets

Keyword search over open datasets, with optional facet filters, sorting and pagination Params: q, sort, facets, api_limit, page Read-only

curl 'https://clify-dev.netlify.app/data-europa/search-datasets?q=air+quality&facets=%7B%22country%22%3A%5B%22nl%22%5D%7D'

count-results

Count matches for a query across all indexes (datasets, catalogues, data services, dataset series, editorial content) Params: q* Read-only

curl 'https://clify-dev.netlify.app/data-europa/count-results?q=air+quality'

search-catalogues

List or search the data catalogues (national and EU portals) that publish datasets Params: q, sort, api_limit, page Read-only

curl 'https://clify-dev.netlify.app/data-europa/search-catalogues?q=geodata'

list-countries

List the country vocabulary (ids and multilingual labels) used for the country facet Params: api_limit Read-only

curl 'https://clify-dev.netlify.app/data-europa/list-countries'

get-dataset

Get full metadata for one dataset: title, description, catalogue, country, keywords, distributions/download links Params: id* Read-only

curl 'https://clify-dev.netlify.app/data-europa/get-dataset'

get-catalogue

Get metadata for one catalogue (publisher portal): title, description, homepage, country Params: id* Read-only

curl 'https://clify-dev.netlify.app/data-europa/get-catalogue'

get-similar-datasets

Find datasets similar to a given dataset (lower distance = more similar) Params: id* Read-only

curl 'https://clify-dev.netlify.app/data-europa/get-similar-datasets'

get-dataset-jsonld

Get a dataset's full DCAT-AP metadata as a JSON-LD graph (distributions, licences, spatial coverage, contacts) Params: id* Read-only

curl 'https://clify-dev.netlify.app/data-europa/get-dataset-jsonld'

export-dataset-metadata

Export a dataset's DCAT-AP metadata as raw RDF text (RDF/XML, Turtle, N3 or N-Triples) Params: id*, format Read-only

curl 'https://clify-dev.netlify.app/data-europa/export-dataset-metadata'

get-dataset-feed

Get the RSS feed for a dataset, which tracks updates to its metadata and distributions Params: id* Read-only

curl 'https://clify-dev.netlify.app/data-europa/get-dataset-feed'

data.gov.uk

data.gov.uk (National Data Library): the UK government's open data directory. The CLI searches and reads dataset metadata through the public CKAN JSON API, lists data files and previews from dataset pages, and browses the curated theme collections and their chart data.

data-cdc

data.cdc.gov

data.cdc.gov is the CDC's open-data portal (Socrata). This CLI searches the dataset catalog, lists categories and tags, reads dataset metadata, and queries or exports dataset rows through the public Socrata Discovery, SODA and views APIs.

data-cityofnewyork

data.cityofnewyork.us

NYC Open Data (Socrata catalog at data.cityofnewyork.us). The CLI searches the dataset catalog by keyword, tag, category and sort order; reads dataset metadata and columns; runs SoQL queries against rows; exports CSV; and lists change history and attachments. It needs no login.
