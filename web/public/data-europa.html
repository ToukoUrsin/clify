data-europa API for agents (unofficial) — JSON over curl | clify

data.europa.eu (the official EU open data portal): search EU and national open datasets, catalogues and data services, read dataset and catalogue metadata, find similar datasets, and export DCAT metadata.

Host: data.europa.eu. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-datasets

Keyword search over open datasets, with optional facet filters, sorting and pagination Params: q, sort, facets, api_limit, page

curl 'https://clify-dev.netlify.app/data-europa/search-datasets?q=air+quality&facets=%7B%22country%22%3A%5B%22nl%22%5D%7D'

count-results

Count matches for a query across all indexes (datasets, catalogues, data services, dataset series, editorial content) Params: q*

curl 'https://clify-dev.netlify.app/data-europa/count-results?q=air+quality'

search-catalogues

List or search the data catalogues (national and EU portals) that publish datasets Params: q, sort, api_limit, page

curl 'https://clify-dev.netlify.app/data-europa/search-catalogues?q=geodata'

list-countries

List the country vocabulary (ids and multilingual labels) used for the country facet Params: api_limit

curl 'https://clify-dev.netlify.app/data-europa/list-countries'

get-dataset

Get full metadata for one dataset: title, description, catalogue, country, keywords, distributions/download links Params: id*

curl 'https://clify-dev.netlify.app/data-europa/get-dataset'

get-catalogue

Get metadata for one catalogue (publisher portal): title, description, homepage, country Params: id*

curl 'https://clify-dev.netlify.app/data-europa/get-catalogue'

get-similar-datasets

Find datasets similar to a given dataset (lower distance = more similar) Params: id*

curl 'https://clify-dev.netlify.app/data-europa/get-similar-datasets'

get-dataset-jsonld

Get a dataset's full DCAT-AP metadata as a JSON-LD graph (distributions, licences, spatial coverage, contacts) Params: id*

curl 'https://clify-dev.netlify.app/data-europa/get-dataset-jsonld'

export-dataset-metadata

Export a dataset's DCAT-AP metadata as raw RDF text (RDF/XML, Turtle, N3 or N-Triples) Params: id*, format

curl 'https://clify-dev.netlify.app/data-europa/export-dataset-metadata'

get-dataset-feed

Get the RSS feed for a dataset, which tracks updates to its metadata and distributions Params: id*

curl 'https://clify-dev.netlify.app/data-europa/get-dataset-feed'
