govinfo API for agents (unofficial) — JSON over curl

GovInfo (U.S. Government Publishing Office): browse collections such as Congressional Bills and the Federal Register, read daily Federal Register tables of contents, look up document details, related documents, committee publications and government authors, and fetch document text and MODS metadata.

Host: govinfo.gov. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call a site command. Responses are one JSON object. The hosted MCP and GitHub repo are also available.
