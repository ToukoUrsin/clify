huggingface API for agents (unofficial) — JSON over curl

Hugging Face Hub (huggingface.co): search and inspect public models, datasets, Spaces and organizations, read model/dataset metadata, file listings, security scans and dataset statistics, without logging in.

Host: huggingface.co. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Start with San Francisco and U.S. agent tasks: events, startup jobs, BART and Muni departures, Craigslist listings, local news, public datasets and prediction markets. Example: curl 'https://clify-dev.netlify.app/search?q=SF+tech+events'. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Machine-readable command schema · Source website

Commands

search-models

Search and filter Hub models by keyword, task, library, app, parameter count, inference provider or license, with sorting and pages Params: search, pipeline_tag, library, apps, num_parameters, inference_provider, license, sort, p Read-only

curl 'https://clify-dev.netlify.app/huggingface/search-models?search=llama&pipeline_tag=text-generation&library=gguf&apps=llama.cpp&num_parameters=min%3A0%2Cmax%3A6B&sort=downloads'

quick-search

Autocomplete-style quick search that returns matching models, datasets, Spaces, orgs and users together Params: q* Read-only

curl 'https://clify-dev.netlify.app/huggingface/quick-search?q=llama'

full-text-search

Full-text search inside model, dataset or Space cards (README content), with highlighted matches Params: q*, type, api_limit, skip Read-only

curl 'https://clify-dev.netlify.app/huggingface/full-text-search?q=quantization&type=model'

list-model-tags

List all model license tag ids (e.g. license:apache-2.0) usable in search-models --license Params: none Read-only

curl 'https://clify-dev.netlify.app/huggingface/list-model-tags'

get-model

Get full public metadata for a model: tags, downloads, likes, config, card data, file list (siblings), parameter counts, gating Params: owner*, name* Read-only

curl 'https://clify-dev.netlify.app/huggingface/get-model?owner=meta-llama&name=Llama-3.1-8B-Instruct'

get-model-scan

Get the security (malware/pickle) scan status of a model repository's files Params: owner*, name* Read-only

curl 'https://clify-dev.netlify.app/huggingface/get-model-scan?owner=NousResearch&name=Hermes-3-Llama-3.1-8B'

list-model-files

List files on a model repository's main branch with sizes, last commit message, date and download links Params: owner*, name* Read-only

curl 'https://clify-dev.netlify.app/huggingface/list-model-files?owner=NousResearch&name=Hermes-3-Llama-3.1-8B'

get-model-file

Download the raw text of a file from a model repository's main branch, e.g. README.md or config.json Params: owner*, name*, file* Read-only

curl 'https://clify-dev.netlify.app/huggingface/get-model-file?owner=NousResearch&name=Hermes-3-Llama-3.1-8B&file=README.md'

search-datasets

Search and filter Hub datasets by keyword, modality and format, with sorting and pages Params: search, modality, format, sort, p Read-only

curl 'https://clify-dev.netlify.app/huggingface/search-datasets?search=wikipedia&modality=modality%3Atext&sort=downloads'

get-dataset

Get a dataset's Croissant metadata (name, description, license, splits, fields, file distribution) from its page Params: owner*, name* Read-only

curl 'https://clify-dev.netlify.app/huggingface/get-dataset?owner=HuggingFaceFW&name=clean-wikipedia'

get-dataset-scan

Get the security scan status of a dataset repository's files Params: owner*, name* Read-only

curl 'https://clify-dev.netlify.app/huggingface/get-dataset-scan?owner=HuggingFaceFW&name=clean-wikipedia'

check-dataset-viewer

Check which dataset-viewer features (viewer, preview, search, filter, statistics) are available for a dataset split Params: dataset*, config, split Read-only

curl 'https://clify-dev.netlify.app/huggingface/check-dataset-viewer?dataset=HuggingFaceFW%2Fclean-wikipedia&config=default&split=train'

get-dataset-statistics

Get per-column statistics (types, null counts, unique values, label frequencies, length histograms) for a dataset split Params: dataset*, config, split Read-only

curl 'https://clify-dev.netlify.app/huggingface/get-dataset-statistics?dataset=HuggingFaceFW%2Fclean-wikipedia&config=default&split=train'

search-spaces

Search Hugging Face Spaces (AI demo apps) by keyword, with sorting Params: search, sort Read-only

curl 'https://clify-dev.netlify.app/huggingface/search-spaces?search=chatbot&sort=likes'

get-organization

List the repositories shown in an organization's or user's profile collections (models and datasets with stats) Params: org* Read-only

curl 'https://clify-dev.netlify.app/huggingface/get-organization?org=NousResearch'
