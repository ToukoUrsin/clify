fred-stlouisfed API for agents (unofficial) — JSON over curl | clify

FRED (Federal Reserve Economic Data, St. Louis Fed): search economic time series and read their metadata and latest observations, and browse categories, tags, releases, release tables, the release calendar and data sources.

Host: fred.stlouisfed.org. Call these verified read commands with plain curl; no install, key, or account. Use the public JSON API with plain curl. No install, key, account, or browser is needed. Example: curl 'https://clify-dev.netlify.app/sites.json'. Start with /search?q=weather, then call /abc/COMMAND. Responses are one JSON object. The hosted MCP and GitHub repo are also available.

Commands

search-series

Search FRED series by keyword (the header autocomplete); returns series IDs, titles, frequency, units and date coverage Params: q*

curl 'https://clify-dev.netlify.app/fred-stlouisfed/search-series'

get-series

Get chart metadata for a series by ID: title, frequency, observation date range, units, seasonal adjustment and available transformations Params: id*

curl 'https://clify-dev.netlify.app/fred-stlouisfed/get-series?id=GDPC1'

get-series-recent-observations

Get the most recent observations (date and value) shown on a series page Params: id*

curl 'https://clify-dev.netlify.app/fred-stlouisfed/get-series-recent-observations'

list-categories

List the top-level FRED data categories and their main subcategories, with category IDs (in the url) and series counts Params: none

curl 'https://clify-dev.netlify.app/fred-stlouisfed/list-categories'

list-category-series

List series in a category (by category ID), with optional tag filter, sorting and paging Params: id*, t, ob, od, pageID

curl 'https://clify-dev.netlify.app/fred-stlouisfed/list-category-series?ob=lu'

list-series-by-tag

List all series or series matching tags (e.g. 'inflation'), sorted by popularity or last update; with no tag and ob=pv this lists the most popular series Params: t, ob, od, pageID

curl 'https://clify-dev.netlify.app/fred-stlouisfed/list-series-by-tag?t=inflation&ob=lu'

search-tags

List or search FRED tags (concepts, geographies, frequencies, sources, ...) with series counts; tag slugs feed list-series-by-tag Params: st, tg, pageID

curl 'https://clify-dev.netlify.app/fred-stlouisfed/search-tags?st=inflation'

list-releases

List FRED data releases alphabetically (50 per page) with release IDs (rid in the url) Params: pageID

curl 'https://clify-dev.netlify.app/fred-stlouisfed/list-releases'

list-release-series

List series in a data release (by release ID), with optional tag filter, sorting and paging Params: rid*, t, ob, od, pageID

curl 'https://clify-dev.netlify.app/fred-stlouisfed/list-release-series?rid=194'

list-release-tables

Browse a release's table tree: list the table sections/elements under a release (or under a given element ID) with element IDs (eid in the url) and series counts Params: rid*, eid

curl 'https://clify-dev.netlify.app/fred-stlouisfed/list-release-tables?rid=194&eid=1232736'

get-release-calendar

Get the release calendar for a date range (all releases or one release ID) as per-day events, e.g. '33 releases' on 2026-10-19 Params: vs, ve, rid

curl 'https://clify-dev.netlify.app/fred-stlouisfed/get-release-calendar?vs=2026-10-18&ve=2026-10-24'

list-sources

List the data sources (agencies and organizations) that FRED series come from, with source IDs (soid in the url) Params: pageID

curl 'https://clify-dev.netlify.app/fred-stlouisfed/list-sources'

list-source-releases

List the releases published by a data source (by source ID) Params: soid*

curl 'https://clify-dev.netlify.app/fred-stlouisfed/list-source-releases?soid=42'
