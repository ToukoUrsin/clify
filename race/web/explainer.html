$ clify

Agents waste their time clicking through websites.
clify turns any website into a command line they can call.

01

Give it a URL

The agent names a site and what it wants to do there.

clify add updown.io
02

It explores once

A headless browser signs up with the agent's own email and phone, reads the code, and records the API behind every button.

03

Keeps what works

Every command is tested on the live site. Only verified ones are kept. CAPTCHAs are never solved: it emails its human.

04

One command

From then on, a task is one call that returns JSON, instead of thirty clicks.

clify updown add-check \ --url example.com
